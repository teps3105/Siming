# 《司業命緣》GDD 索引

> 你是司命——執掌因果與輪迴的星君。你種下的每一個因，都會在某一世結果。

這是《司業命緣》（*Siming: Karma & Fate*）的遊戲設計文件，共九章：前五章定義遊戲本身，第六章定義 Godot 加 Rust 的技術架構，其後是附錄、素材與發行。本頁列出專案概況、閱讀順序與每一節的連結。

| 項目 | 內容 |
|---|---|
| 產品名 | 《司業命緣》／*Siming: Karma & Fate*（司、業、命、緣為作品核心，見 1.1） |
| 專案代號 | Siming |
| 技術 | Godot 4.7（呈現）加 Rust 模擬核心，以 GDExtension 相連（6.1） |
| 最終目標 | Steam Demo（第 9 章） |
| 文件規則 | 結構為 `N-章/N.M-節.md`，最多兩層；文件為準，衝突先改文件；數值以 7.1 為準；決策只在 6.10 追加 |

## 閱讀順序

- 第一次閱讀：1.1 → 1.3 → 2.1 → 2.7 → 3.1–3.3 → 4.1–4.2 → 5.4 → 6.1 → 9.1。
- 實作某個系統：先讀該系統在第 2–5 章的節，再讀 6.1–6.4 找到它在程式中的位置，數值查 7.1。
- 文中的 M1 到 M7 是路線圖的階段代號，定義見 1.6。
