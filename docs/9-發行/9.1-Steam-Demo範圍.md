# 9.1 Steam Demo 範圍

Steam Demo 是本專案的最終目標：一個免費、可完整體驗兩運的試玩版。包住遊戲的那一層——封面、主選單、開新世界、存讀檔、設定、遊戲中選單與新手引導——已經做好，目前開放全部選項；Demo 要鎖哪些、結束畫面與 Steam 整合留到上架前（路線圖 M7，完成標準見路線圖的「M7 Steam Demo」）。本節依序回答：Demo 給玩家什麼、上架時與正式版差在哪、現在的建置有哪些畫面、還缺什麼。

## Demo 給玩家什麼

免費 Demo 用來收集願望清單（主要指標）、驗證「因果輪迴沙盒」的核心體驗是否成立、參加 Steam 新品節（Next Fest）。

玩家走過的路：

1. 封面與主選單。
2. 開新世界，或繼續上次的世界。
3. 第一運：觀、牽、果，第一次量劫與結算。
4. 第二運：帶著天機與對世界的理解，主動牽動因果，第二次量劫。
5. Demo 結束畫面。

兩運共 720 年。1× 速度約 70 分鐘；玩家可加速，實際約 40–90 分鐘。

## 上架時與正式版的差別

下表是上架時的目標；目前的建置還沒有鎖，開局選項與存檔欄位都照正式版開放。

| 項目 | 正式版 | Demo |
|---|---|---|
| 系統 | M1–M6 全部 | M1–M6 全部（Demo 即是完整核心循環的切片） |
| 大陸尺寸 | 小、中、大 | 只有中 |
| 開局時代 | 上古、中古、末法 | 只有中古；其他兩個在選單中顯示為「正式版開放」 |
| 遊玩長度 | 無盡 | 第二運結算後結束 |
| 種子 | 任意 | 任意（鼓勵分享種子） |
| 司命之權 | 全部 | 全部 |
| 天書 | 全部條目 | 全部條目皆可達成；收藏冊標示「Demo 達成」 |
| 存檔 | 10 欄 + 自動 | 3 欄 + 自動；不保證可帶入正式版 |
| 分享碼 | 匯入、匯出 | 匯入、匯出（只接受 Demo 版本的分享碼） |
| 語言 | 繁中、簡中、英文（另議） | 繁中、簡中 |
| 平台 | Windows、Steam Deck、Linux、macOS（另議） | Windows 與 Steam Deck（皆必要，Deck 目標「已驗證」）；Linux（可遊玩） |

Demo 不放 Steam 成就（避免與正式版成就混淆；正式版以天書對應成就，9.2）、遙測與分析資料回傳、創意工坊與模組。

## 現在的建置有哪些畫面

選單各頁都是同一種選單紙面（5.7），鍵鼠與搖桿都能走完；字串與版面的檢查方式見 6.7。

### 封面

一張白描設色的山水，每次啟動換一個種子：背景的山取自那個種子生成的小尺寸世界，人物的長相也跟著種子變。

| 位置 | 內容 |
|---|---|
| 右上 | 標題「司業命緣」與朱印，底下是主選單 |
| 背景 | 七層山影，由世界的高度資料取由近到遠的山稜剖面畫成；整個畫面寬度都有山，主峰在中間偏左。越遠的層越淡，整幅共用一片慢慢流動的霧，山腰以下霧較重。不畫河流 |
| 左下 | 松樹與崖上石台。石台三人：兩人對弈、一名老道在旁指點；另有香爐與棋枰 |
| 山水之間 | 五個人各做各的事：山徑上拄杖的貧叟、山腰石臺打坐的僧人、水岸持蓮的女子、霧裡小舟上垂釣的漁翁、土坡上吹笛的童子 |
| 左上天空 | 一名御劍者飛過 |

八個站坐的人加上御劍者，男女、老中幼、貧平富、儒釋道與無門派都有人。標題與主選單後方不放人。

人物由演算法畫成，身分四項（性別、年紀、貧富、門派）決定剪影、配件與顏色的範圍，種子在範圍內取值：

- 女子（僧尼除外）穿上襦下裙：上襦淡色、裙濃色，裙繫在胸下、往下放開，比男子的袍擺寬；肩比男子窄；非貧者兩臂掛披帛、眉心點花鈿；高髻簪花插步搖，長髮垂到背後。
- 僧尼剃髮穿僧衣；貧者衣色褪向麻色、有補丁，男子穿短褐赤足。
- 站著拿笛的人把笛橫在嘴邊吹。

### 主選單

| 項目 | 行為 |

| 新世界 | 進開新世界頁 |
| 繼續 | 讀最近的一份存檔；列上寫世界名與日期。沒有存檔時不能選 |

### 開新世界

4.6 的七項：世界名、種子、星球尺寸、陸地比例、山勢、濕潤度、開局時代。世界名預設由種子取（7.3）；玩家改過名字之後，換種子不再改名。「換一個種子」擲一個新種子。按「開天」後顯示進行中的紙面，完成即進入遊戲並播開場運鏡。

### 設定

改了立刻生效並寫入 `user://settings.cfg`。

| 項目 | 值 | 預設 |
|---|---|---|
| 全螢幕 | 開／關 | 關 |
| 視窗大小 | 1280×720、1600×900、1920×1080、2560×1440 | 1920×1080 |
| 垂直同步 | 開／關 | 開 |
| 介面縮放 | 80–150%，每格 5% | 100% |
| 邊緣捲動 | 開／關 | 關 |
| 語言 | 繁體中文 | 繁體中文 |
| 重看引導 | 按下後引導簽從第一句重來 | — |

### 遊戲中選單

`Esc`（沒有卡片開著時）或搖桿 Start 開啟，題簽是「司命案頭」。開著的時候時間暫停、地圖不收輸入、畫面壓暗；關掉後時間回到開啟前的行止。

| 項目 | 行為 |
|---|---|
| 回到世界 | 關閉選單 |
| 存檔 | 10 個手動欄位（4.8） |
| 載入 | 同主選單 |
| 分享碼 | 複製這個世界的分享碼，或從剪貼簿匯入 |
| 設定 | 同主選單 |
| 回主選單 | 先問；沒存的進度會丟掉 |
| 離開 | 先問 |

### 新手引導

第一次進世界時，畫面下方出現引導簽（5.7），一次一句，教現有的六個操作：移動地圖、拉近拉遠、換星球視角、停走時間、換地圖模式、點州郡看命簿。玩家做到了就換下一句；六句做完不再出現，進度存在設定裡，關掉遊戲再開會接著教。引導簽不擋操作，選單開著或開場運鏡中不顯示。

人物、關注、宿緣的引導（4.1 的開局節拍）等那些畫面做出來再接上。

## 還缺什麼

| 功能 | 說明 |
|---|---|
| Demo 的鎖定 | 「上架時與正式版的差別」表中「Demo」欄的限制 |
| 設定的自動暫停 | 4.7 的自動止／緩做出來之後，在設定頁加上各類事件的開關 |
| 簡體中文 | 語言選項加一項（9.5） |
| Demo 結束畫面 | 第二運結算後顯示：本次的兩運回顧、天書達成數、[加入願望清單] [分享本世界] [回饋意見] [繼續觀看（不再推進時間）] |
| 回饋意見 | 開啟外部表單網址（不在遊戲內收集資料） |
| 當機紀錄 | 寫入本機紀錄檔；下次啟動時提示可附在回饋中 |
