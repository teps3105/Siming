# 9.1 Steam Demo 範圍

Steam Demo 是本專案的最終目標：一個免費、可完整體驗兩運的試玩版。本節定義 Demo 的目的、體驗流程、與正式版的內容差異、Demo 專屬功能與完成標準。

## 目標

在 Steam 上架一個免費 Demo，用來：
1. 收集願望清單（主要指標）。
2. 驗證「因果輪迴沙盒」的核心體驗是否成立。
3. 參加 Steam 新品節（Next Fest）。

## Demo 的體驗

玩家在 Demo 中完整體驗**兩運**（720 年）：
- 開天。
- 第一運：觀、牽、果，第一次量劫與結算。
- 第二運：帶著天機與對世界的理解，主動牽動因果，第二次量劫。
- Demo 結束畫面。

1× 速度約 70 分鐘；玩家可加速，實際約 40–90 分鐘。

## 內容範圍

| 項目 | 正式版 | Demo |
|---|---|---|
| 系統 | M1–M6 全部 | M1–M6 全部（Demo 即是完整核心循環的切片） |
| 大陸尺寸 | 小、中、大 | 只有中 |
| 開局時代 | 上古、中古、末法 | 只有中古；其他兩個在選單中顯示為「正式版開放」 |
| 遊玩長度 | 無盡 | 第二運結算後結束 |
| 種子 | 任意 | 任意（鼓勵分享種子） |
| 司命之權 | 全部 | 全部 |
| 天書 | 全部條目 | 全部條目皆可達成；收藏冊標示「Demo 達成」 |
| 存檔 | 10 欄 + 自動 | 3 欄 + 自動；不保證可帶入正式版 |
| 分享碼 | 匯入、匯出 | 匯入、匯出（只接受 Demo 版本的分享碼） |
| 語言 | 繁中、簡中、英文（另議） | 繁中、簡中 |
| 平台 | Windows、Steam Deck、Linux、macOS（另議） | Windows 與 Steam Deck（皆必要，Deck 目標「已驗證」）；Linux（可遊玩） |

## Demo 專屬功能

| 功能 | 說明 |
|---|---|
| 主選單 | 新世界、繼續、載入、分享碼、設定、天書、製作群、離開 |
| 設定 | 解析度、全螢幕或視窗、垂直同步、介面縮放（80–150%）、語言、自動暫停（4.7）、邊緣捲動 |
| 新手引導 | 4.1 的第一次遊玩節奏，以非強制的提示呈現；可在設定中重看 |
| Demo 結束畫面 | 第二運結算後顯示：本次的兩運回顧、天書達成數、[加入願望清單] [分享本世界] [回饋意見] [繼續觀看（不再推進時間）] |
| 回饋意見 | 開啟外部表單網址（不在遊戲內收集資料） |
| 當機紀錄 | 寫入本機紀錄檔；下次啟動時提示可附在回饋中 |

## 不在 Demo 中

- Steam 成就（避免與正式版成就混淆；正式版以天書對應成就，9.2）。
- 遙測、分析資料回傳。
- 創意工坊、模組。
