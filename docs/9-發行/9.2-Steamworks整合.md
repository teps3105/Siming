# 9.2 Steamworks 整合

遊戲透過 Steamworks 取得 Overlay、雲端存檔、Rich Presence 等功能。本節分開列出必須由專案擁有者本人辦理的事項，以及程式端的整合方式與用到的功能。

## 前提（由專案擁有者處理）

以下事項需要專案擁有者本人操作，開發端無法代為完成：
- Steamworks 合作夥伴帳號與上架費。
- 建立正式版 App 與 Demo App，取得 App ID。
- 稅務與銀行資料。
- 商店頁審核、新品節報名。
- 上傳建置所需的帳號與 Steam Guard。

## 技術方案

| 項目 | 方案 |
|---|---|
| 綁定套件 | `steamworks`（steamworks-rs，MIT / Apache-2.0）；放在橋接 crate `siming-gdext`，以 cargo feature `steam` 開關，預設關閉（6.1） |
| 平台 | 只在 Steam 版建置啟用；無 Steam 的建置不連結 |
| 初始化 | 啟動時 `Client::init_app(APP_ID)`；失敗時（未從 Steam 啟動）照常執行，停用 Steam 功能，不強制重啟到 Steam |
| 回呼 | 每幀由 Godot 端的 `_process` 經橋接呼叫 `run_callbacks()` |
| 再發行檔 | `steam_api64.dll`（Windows）、`libsteam_api.so`（Linux），隨建置發佈（Steamworks SDK 再發行條款） |

## 使用的功能

| 功能 | Demo | 正式版 | 說明 |
|---|---|---|---|
| Overlay | ✔ | ✔ | 在 Godot Forward+ 渲染下驗證 Overlay 可正常顯示 |
| 願望清單 | ✔ | — | 結束畫面以 Overlay 開啟正式版商店頁 `ActivateGameOverlayToStore(正式版 App ID)` |
| Steam Cloud | ✔ | ✔ | 以 Auto-Cloud 設定同步 `saves/` 與 `book.dat`（收藏冊），不需程式碼 |
| Rich Presence | ✔ | ✔ | 「{世界名}・第 N 運」 |
| 語言 | ✔ | ✔ | 首次啟動依 `GetCurrentGameLanguage()` 選擇繁中或簡中 |
| 成就 | — | ✔ | 天書條目對應成就；收藏冊同步時解鎖（只讀模擬結果，不影響確定性） |
| Steam Deck | 目標「已驗證」 | 「已驗證」 | Demo 即支援搖桿與 Deck 版面（5.9）；以 Steam Input 的預設手把設定映射；`IsSteamRunningOnSteamDeck()` 用於預設 Deck 版面 |
| Steam Input API | — | 另議 | 進階動作集與 Steam 內建按鍵設定介面 |

## 確定性

Steam 的任何回應都不得進入模擬核心；`siming-sim` 不依賴 `steamworks`（1.4 規則 6）。
