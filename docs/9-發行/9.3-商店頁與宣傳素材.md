# 9.3 商店頁與宣傳素材

本節列出 Steam 商店頁要求的圖片、影片與文案規格，以及必拍的截圖、攝影模式與預告片腳本，供製作上架素材時逐項對照。

## 商店頁素材規格（Steam 要求）

| 素材 | 尺寸 | 數量 | 來源 |
|---|---|---|---|
| Header Capsule | 920×430 | 1 | 攝影模式截圖 + 標題字 |
| Small Capsule | 462×174 | 1 | 同上，標題字為主 |
| Main Capsule | 1232×706 | 1 | 同上 |

| Library Capsule | 600×900 | 1 | 同上 |

| Library Logo | 1280×720，透明背景 | 1 | 標題字 |
| 截圖 | 1920×1080 | ≥ 5 | 攝影模式 |
| 預告片 | 1920×1080，60 秒內 | 1 | 遊戲錄影 + 字卡 |

## 標題字

- 「司業命緣」四字以書法風格呈現：以字型為底，加上筆刷雜訊與飛白；四字可作 2×2 方塊排列（適合方形與直式膠囊圖）或一列排列（橫式）。
- 搭配朱紅印章，以 印章繪製函式 產生後放大重繪。
- 英文標題「Siming: Karma & Fate」排在中文標題下方，作為副標；Library Logo 與商店頁的英文區使用英文標題為主。
- 授權：只使用 8.10 登記的素材。

## 攝影模式（開發需求）

- F11：隱藏所有介面。
- 自由鏡頭：解除俯角限制、可調視角（20°–60°）。
- 暫停時可移動鏡頭。
- 截圖：F12 改為除錯面板以外的組合鍵 Ctrl+F12；可設定 1×、2×、4× 超解析度輸出 PNG。

## 預告片腳本（60 秒）

| 時間 | 內容 |
|---|---|
| 0–8 秒 | 霧中浮現大陸，字卡「你是司命」 |
| 8–20 秒 | 地圖上的戰爭、飛升、屠城 |
| 20–35 秒 | 切入因果模式：一條赤線跨三世，最後燃盡；字卡「你種下的因」 |
| 35–50 秒 | 司命落印、天道之秤傾斜、量劫降臨；字卡「都會在某一世結果」 |
| 50–60 秒 | 標題、Demo 上架資訊、願望清單 |

## 商店文案要點

- 一句話：「司業命緣——你是司命。看一個會自己寫歷史的修仙世界，牽動跨越輪迴的因果。」
- 四個賣點，對應司業命緣：司——你司掌天下因果；業——善惡終有報；命——你命定眾生之緣，也承擔其代價；緣——冤家路窄，恩怨跨世。
- 標籤：Simulation、God Game、Sandbox、Strategy、Grand Strategy、Procedural Generation、Cultivation（修仙）、Chinese Mythology。
