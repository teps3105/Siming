# 9.4 平台與最低配備

Demo 支援 Windows 與 Steam Deck，Linux 可遊玩。本節定義平台優先序、商店頁刊登的最低與建議配備、效能目標與畫質選項。

## 平台優先序

| 平台 | Demo | 說明 |
|---|---|---|
| Windows 10/11 x64 | **必要** | 桌機鍵鼠為主（亦支援 Xbox 手把）；Godot Forward+ 渲染 |
| Steam Deck | **必要**；目標「已驗證」（Verified） | 原生 Linux 建置（非 Proton）；搖桿與 Deck 版面（5.9）；800p 30 fps 以上 |
| Linux x64 | 可遊玩 | 與 Steam Deck 同一份 Linux 建置；Vulkan |
| macOS | 不提供 | 正式版另議（Metal） |

## 系統需求（商店頁刊登）

| 項目 | 最低 | 建議 |
|---|---|---|
| 作業系統 | Windows 10 64 位元 | Windows 11 64 位元 |
| 處理器 | 4 核心，2.5 GHz（Intel i5-6500 / Ryzen 3 1200 等級） | 6 核心，3.5 GHz |
| 記憶體 | 8 GB | 16 GB |
| 顯示卡 | 支援 DX12 或 Vulkan、2 GB 顯示記憶體（GTX 960 / Intel UHD 620 等級） | GTX 1660 / RX 580 等級 |
| 儲存空間 | 500 MB | 500 MB |
| 解析度 | 1280×720 | 1920×1080 以上 |

## 效能目標

| 配備 | 目標 |
|---|---|
| 最低配備，1080p，預設畫質 | 30 fps 以上；100× 速度可運作 |
| 建議配備，1080p | 60 fps；100× 速度不掉幀（6.8） |
| Steam Deck，800p | 30 fps 以上 |

## 畫質設定

| 選項 | 低 | 中（預設） | 高 |
|---|---|---|---|
| 地形 LOD 距離 | 0.6× | 1× | 1.5× |
| 特效粒子上限 | 0.5× | 1× | 1× |
| 業氣煙霧貼片 | 關 | 開 | 開 |
| 抗鋸齒 | 無 | FXAA | MSAA 4× |
| 渲染解析度 | 75% | 100% | 100% |

## 驗證方式

- CI 的 Windows runner 產出建置並跑自動測試。
- 在最低配備等級的實體或雲端機器上，以除錯面板（6.7）記錄 1 運的平均與 1% low 幀率，作為 Demo 的驗收證據。
