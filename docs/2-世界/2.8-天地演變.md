# 2.8 天地演變

世界生成之後，山河不是定死的：氣候有寒暖、靈氣有漲落、草木隨人消長、江河淤地改道、地殼偶爾震動。本節定義這五種自然過程的慢變量、每一代人結算一次的規則、它們對人間的影響，以及哪些變化算世界大事並開啟新紀元（2.6）。已實作的只有三個全球慢變量——寒暖、海平面偏移、靈潮——的每世更新（`crates/sim/src/evolution.rs`），它們還沒有接到地形、海陸與靈氣上，也還不觸發世界大事；其餘各節是待實作的規格（6.10 #48）。

## 原則

- **慢**：天地每世（30 年）結算一次，一次只推進一小步；玩家看到的是海岸慢慢移動、雪線慢慢下壓，不是瞬間換一張地圖。
- **自己會動**：不需要司命動手，也不等量劫。司命的移山、開脈（4.2）與量劫的損脈（3.11）是另外疊在上面的外力，走同一條重算鏈（2.7）。
- **同種子同結果**：週期的長度與相位由世界種子決定，其餘由世界狀態推得；隨機抽樣用獨立的 `evolution` 子流（6.5）。
- **留下紀錄**：每一次看得見的改變都寫入因果帳（7.2）；慢變量跨過門檻就是世界大事，開啟新紀元。

## 慢變量

| 代號 | 意義 | 值域 | 怎麼變 |
|---|---|---|---|
| `warmth` | 全球寒暖 | −1（極寒）..1（極暖） | 兩個長週期疊加：`0.6·sin(2π·年/P₁ + φ₁) + 0.4·sin(2π·年/P₂ + φ₂)`，`P₁` 取 480–720 年、`P₂` 取 1,200–1,800 年，週期與相位由種子定；開天時的值就是第 0 年的週期值。魔劫期間另減 0.25（魔氛蔽日），平息後每世回復 0.05 |
| `sea_shift` | 海平面的偏移（高度單位，2.2） | −0.03..0.03 | 開局為 0（生成時的海岸就是開局的海岸）；每世向 `0.03 × warmth` 靠近一半：暖則海進，寒則海退，比氣溫晚一步 |
| `tide` | 靈潮：天地靈氣的倍率，取代 2.4 原本固定的時代倍率 | 0.5..1.4 | 週期值 `1.0 + 0.3·sin(2π·年/P₃ + φ₃)`，`P₃` 取 700–1,100 年；每世向週期值靠近 20%。量劫強度 `I`（3.11）使 `tide` 立即減 `0.1 × I`。開局選項「時代」（4.6）決定初值與相位：上古 1.3 且在高點、中古 1.0 且正在退、末法 0.6 且在低點 |
| `cultivation` | 每州的墾殖程度 | 0..1 | 每世向 `clamp(人口 / 承載, 0, 1)` 靠近 25% |
| `silt` | 每條江（等級 3）河口累積的泥沙 | ≥ 0 | 每世加 `0.004 ×（流域內 cultivation 的平均 + 0.5）`；淤出新地時歸零 |
| `stress` | 每段板塊聚合邊界累積的地壓 | ≥ 0 | 每世加該段兩側板塊的相對速度（2.2 步驟 1）；釋放時歸零 |

## 每世結算

依序執行，在 6.3 每世的步驟（天機收入、自動存檔）之前。

1. **更新慢變量**（上表）。
2. **寒暖**：
   - 有效溫度 = 生成時的溫度（2.2 步驟 4）+ `0.18 × warmth`；有效濕度 = 生成時的濕度 ×（1 + `0.15 × warmth`）——暖則濕，寒則乾。
   - 以有效溫度與濕度重跑 2.2 步驟 5 的地形判定，只改氣候地形（雪原、沙漠、森林、沼澤、平原），山脈與丘陵不動。
   - 有效海平面 = 生成時的海平面 + `sea_shift`：高度低於它的陸格成為海，高於它的海格成為陸（新地先是沼澤，下一世起依氣候判定）。
   - **一世一步**：一格只有在與「它將變成的那一類」相鄰時才改，所以雪線、沙漠邊緣與海岸一世最多推進一格。
3. **草木**（人改天地）：
   - `cultivation > 0.7` 的州：州內 5% 的森林格轉為平原，離治所近的先轉。
   - `cultivation < 0.3` 的州：生成時原是森林、後來被墾為平原的格，5% 長回森林。
   - 沙化：有效濕度低於 0.25 且 `cultivation > 0.8` 的州，3% 的平原格轉為沙漠。
4. **水土**：
   - 淤地：`silt` 達 0.02 的河口，把緊鄰河口、最淺的一個海格抬到海平面以上，成為沼澤。
   - 改道：每條大河與江每世以機率 `0.03 ×（warmth > 0.5 時為 2，否則 1）` 改道——在平原段任取一格，把流向改往次陡的鄰格，自該格起重算下游（2.2 步驟 6）。
   - 湖：有效濕度低於 0.3 的湖，每世由外緣縮一圈；縮盡即消失。
5. **地動**：
   - `stress` 超過該段門檻（門檻使每段平均 400–800 年釋放一次；全世界每世最多一次，取 `stress` 超出最多的那段）就釋放。
   - 震央取該段中點：半徑 3 格內的高度加 0.02–0.05（山更高；海底夠淺處浮出新島）。
   - 震央所在州殘破 +0.4、人口減 5–20%；半徑 6 格內的洞天福地各以機率 0.5 靈脈改道（重連到最近的其他節點）。
6. **靈潮**：
   - 格點靈氣改以 `tide` 為倍率重算（2.4）。
   - `tide < 0.7`：每個洞天福地每世以機率 0.1 降一級（福地則沉寂，不再計入靈氣）。
   - `tide > 1.1`：降過級或沉寂的節點每世以機率 0.1 回復一級，至多回到生成時的等級。
7. **重算**（2.7 的重算鏈）：河流與 `downstream` → 宜居度（格、州）→ 承載；州郡的 `terrain_mix`、`cells`、`neighbors`、`sea_neighbors`。
   - 被海淹沒的格移出州郡；新浮出的陸格併入相鄰格數最多的州郡，無相鄰州郡者（新島）暫不屬任何州。
   - 治所被淹或變成不可居：治所遷到州內宜居度最高的格，治所名不變（7.3）。
   - 州郡的格全數沒入海中：州郡消失，人口依遷徙規則（2.3）移往海鄰與陸鄰，容不下的折損。
8. **記事與紀元**（下節）。

## 對人間的影響

天地演變不直接殺人、不直接賜福，只改場；人間照既有規則回應：

- 承載變了 → 人口成長、饑荒、遷徙（2.3）。大寒時高緯州郡承載下降，人往南走；海退露出的新地承載由零長起。
- 靈氣變了 → 修煉速度、突破機率、宗門選址（3.5、3.6）。末法時高境界修士難以再進，洞天福地成為必爭之地。
- 河流改道、陸橋浮沉 → `downstream`、陸鄰與海鄰改變，連帶改變業氣順流、行軍路線與遷徙方向（2.7）。

## 世界大事與紀元

慢變量跨過門檻時寫入一筆世界大事，並開啟新紀元（2.6）。進入與離開用不同的門檻，免得在門檻附近反覆；兩次改元至少相隔 60 年，期間再跨門檻的只記事、不改元。

| 世界大事 | 進入條件 | 結束條件 | 時間段的性質（紀元名首字的取字範圍，2.6） |
|---|---|---|---|
| 開天 | 開局 | — | 始、大、未分 |
| 大寒 | `warmth ≤ −0.6` | `warmth ≥ −0.3` | 寒、凝、閉 |
| 大暖（海進） | `warmth ≥ 0.6` | `warmth ≤ 0.3` | 洪、澤、漫 |
| 末法 | `tide ≤ 0.7` | `tide ≥ 0.9` | 衰、隱、竭 |
| 靈氣復甦 | 末法結束，或 `tide ≥ 1.2` | `tide ≤ 1.0` | 興、盛、通 |
| 天崩地裂 | 一次地動使全世界人口減少 3% 以上 | 即時事件：開啟的紀元持續到下一件世界大事 | 裂、崩、易 |
| 魔劫 | 魔劫起（7.2 `CataclysmBegan`） | 魔劫平息 | 暗、亂、失序 |
| 重光 | 魔劫平息（`CataclysmEnded`） | 下一件世界大事 | 明、復、清 |
| 浩劫之後 | 量劫結算評價為「浩劫」或「天道自誤」（3.11） | 下一件世界大事 | 殘、荒、寂 |

- 大寒、大暖、末法、靈氣復甦結束而沒有別的大事接上時，開啟「承平」的紀元（取字範圍：和、平、常）。
- 只記事、不改元的變化：某州的森林墾盡、沙化、河口淤出新地、大河改道、湖泊乾涸、治所遷移、陸橋浮現或沉沒、洞天福地升降級。
- 紀元年表（天書，4.5）每筆寫：紀元名、元年（開天以來第幾年）、起因的世界大事。

## 畫面

- 每世結算後，橋接重新烘焙有變動的地圖貼圖（5.3、8.3），在背景分批完成，再以約 3 秒的漸變換上；海岸、雪線、森林邊緣與河道因此是「慢慢變了」。
- 州界、治所、標籤與州郡卡的地形組成隨重算更新。
- 世界大事進傳聞簽並置頂（5.7）；只記事的變化以一般傳聞出現，點了飛往該地。
- 寒暖與靈潮目前的位置以一個小儀表顯示在天時儀旁，樣式在實作時依 5.7 原則 7 設計。

## 確定性與存檔

- 慢變量、每格目前的地形與海陸、生成時的森林遮罩、節點目前的等級、紀元表，都進存檔與世界雜湊（6.5）。
- 生成時的高度、溫度、濕度保留為基準，不被覆寫；地動改的是高度基準本身。
- 結算只在每世的固定步驟執行，與畫面更新的時機無關。

## 實作分期

1. 靈潮、寒暖、草木，連同世界大事與紀元年表、地圖貼圖的分批重烘。
2. 水土、地動。

上表的數值是第一版，慢變量的部分已移入 7.1；以多種子的長跑檢查：一局三運（1,080 年）內應出現 2–6 次改元，且沒有任何一個紀元短於 60 年。

## 慢變量的實測（2026-10-11）

`siming-cli evolve --seed 1 --era <時代> --seeds 500`：500 個種子各跑三運，取每個種子的極值。

| 量 | 最小 | 中位 | 最大 |
|---|---|---|---|
| 寒暖的最高點 | 0.378 | 0.882 | 1.000 |
| 寒暖的最低點 | −1.000 | −0.889 | −0.337 |
| 靈潮的最高點（中古開局） | 1.190 | 1.217 | 1.238 |
| 靈潮的最低點（中古開局） | 0.754 | 0.769 | 0.789 |

- 寒暖：90% 的種子到過 0.6 以上，93% 到過 −0.6 以下，大寒與大暖的門檻合用。
- 靈潮：每世只向週期值靠近 20%，實際起伏約 0.77–1.22，比週期值的 0.7–1.3 小。中古與上古開局的 500 個種子沒有一個降到 0.7 以下，所以「末法」在這兩種開局不會自然發生，只有末法開局（初值 0.6）或量劫扣減才會到；「靈潮 ≥ 1.2」中古開局有 82% 的種子到過。門檻或靠近的比例要在接上世界大事時調整。
- 開天時的寒暖由相位決定，可能一開局就在門檻之外（種子 7 開局為 0.982）。開局已在門檻外時算不算一件世界大事、生成的地形要不算作那個寒暖下的地形，在接上世界大事與地形時決定。
