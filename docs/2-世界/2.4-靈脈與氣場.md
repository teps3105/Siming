# 2.4 靈脈與氣場

靈氣、業氣、功德、正氣是 [2.7 場域](2.7-場域.md) 的「冥場」；本節定義其來源與數值，傳輸運算子的精確公式（擴散、順流、衰減）與執行順序見 [6.9 場域框架](../6-開發/6.9-場域框架.md)。清濁雙極：靈氣為清、聚而不流；業氣為濁、沉而下流（順流到 `downstream` 州）；功德與正氣輕、暈而不流。

## 靈脈網

### 洞天福地（節點）
- 候選：山脈與丘陵格中，「靈性」`h × 0.6 + ridged × 0.4` 的局部極大值。
- 依靈性由高到低挑選，彼此最小距離 18 格，數量 = 目標州郡數 × 0.2（中尺寸 110 × 0.2 = 22 個）。
- 等級（依靈性分位數）：

  | 等級 | 比例 | 強度 `s` |
  |---|---|---|
  | 大洞天 | 前 15% | 1.0 |
  | 洞天 | 接下來 35% | 0.75 |
  | 福地 | 其餘 | 0.5 |

### 靈脈（邊）
- 以節點做最小生成樹，再為每個節點加上一條通往「非 MST 鄰居中最近者」的邊，使網路帶有環。
- 每條邊以 A* 沿地形描出路徑，偏好山脊：

  | 地形 | 代價 |
  |---|---|
  | 山脈 | 0.5 |
  | 丘陵 | 0.8 |
  | 其他陸地 | 1.5 |
  | 水 | 4 |

- 靈脈強度 = 兩端節點強度的平均。

## 格點靈氣

```
aura_cell = 時代倍率 × ( 地形基礎
                       + Σ 節點  s · 0.8 · exp(−d / 8)
                       + 最近靈脈格 s · 0.3 · exp(−d / 3) )
```

- 時代倍率：上古 1.3、中古 1.0、末法 0.6（4.6）。

地形基礎：

| 地形 | 基礎靈氣 |
|---|---|
| 海、湖 | 0.05 |
| 沙漠 | 0.15 |
| 平原 | 0.30 |
| 沼澤 | 0.35 |
| 雪原 | 0.40 |
| 森林、丘陵 | 0.50 |
| 山脈 | 0.70 |

結果截斷在 0..2。

## 州郡氣場

所有州郡氣場值域 0..1，地圖與介面顯示為 0–100。

| 氣場 | 意義 | 來源 | 衰減 | 擴散 |
|---|---|---|---|---|
| 靈氣 `aura` | 修煉環境 | `0.7 × 格點靈氣平均 + 0.3 × 格點靈氣最大值`（截斷 0..1） | — | — |
| 業氣 `karma_qi` | 惡業之氣 | 戰爭死傷、屠城、處決、妖魔肆虐、天罰疫病 | 每年 −3% | 每季先順流 4%（`KARMA_DRIFT`）到 `downstream` 州，再 8% 依差值流向陸鄰 |
| 功德 `merit` | 善業之氣 | 寺院、救災、度化、德政 | 每年 −2% | 每季 4% |
| 正氣 `righteous` | 浩然之氣 | 書院、大儒、德政、忠烈殉國 | 每年 −2% | 每季 4% |

靈氣只在移山（4.2）、量劫損壞靈脈（3.11）時重算（重算鏈見 2.7）。擴散為守恆的差值流：每季每州把 `k × max(0, 本州 − 鄰州) / 陸鄰數` 流給每個較低的陸鄰（6.9）；順流為每季把 `KARMA_DRIFT × 業氣` 移給下游州，下游為海時消散於海（不移動、照常衰減）。

### 濁氣

一州的「濁氣」決定妖魔滋生與天災機率：

`turbid = clamp(karma_qi − 0.5·merit − 0.5·righteous, 0, 1)`

| 濁氣 | 效果 |
|---|---|
| > 0.3 | 每年 `turbid × 0.05` 機率發生疫病：P −5–15%，業氣 +0.03，寫入「疫病」事件 |
| > 0.5 | 每年 `(turbid − 0.5) × 0.2` 機率滋生妖（見 3.10） |
| > 0.8 | 若無魔窟則形成魔窟（地圖上的黑色地標），魔門可在此立派；濁氣降到 0.4 以下時魔窟消失 |

### 業氣的主要來源（數值見 7.1）

| 來源 | 業氣增量 |
|---|---|
| 戰鬥死傷 | `死傷數 / 州郡人口 × 2` |
| 屠城 | +0.4 |
| 妖魔襲擊 | `死傷數 / 州郡人口 × 2` |
| 天罰疫病 | +0.1 |
| 處決或滅佛中被殺的有名之人 | 每人 +0.02 |
