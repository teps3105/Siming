# 2.2 世界生成

由種子與開局參數（見 [4.6 開局設定](../4-玩法/4.6-開局設定.md)）確定性地產生一顆星球：數塊彼此分離的大洲與島群、沿板塊聚合帶與古老造山帶的山脈、河流侵蝕出的谷地、依緯度與地形雨的氣候帶、沙漠與江河。全部步驟只使用種子派生的 `worldgen` 隨機流。

地形採**板塊＋噪聲＋模板＋侵蝕**的分層混合管線（決策 [#32](../6-開發/6.10-決策紀錄.md)；各層的來源與取捨見 [7.4 既有地圖生成器研究](../7-附錄/7.4-既有地圖生成器研究.md) §3.0）：板塊決定「有幾塊、在哪、之間是海、山脈在哪條帶」，模板（大陸核）決定大洲骨架，噪聲決定「看起來自然」的海岸與起伏，侵蝕給出樹枝狀水系與山谷。每一步標明所採用的既有技術與出處。

以上輸出是 [2.7 場域](2.7-場域.md) 的「基底場」（格域、靜態）；它們作為場被讀取、被移山改寫與被量劫損壞時的重算鏈見 2.7，統一的讀寫入口見 6.9。州郡的 `downstream`（業氣順流的下游州）由河流流向推得，定義見 2.3 與 2.7。

## 尺寸

**地理解析度**（決策 #35）：步驟 1–6 在每軸 `WG_GEO_SCALE` = 2 倍（4 倍格數）的細格上進行，遊戲格由 2×2 降採樣：高度取平均（海格不高於海平面、陸格不低於海平面）、地形取多數（海／陸平手依 `(x + y)` 奇偶決定，不偏向任一方）、河流等級取陸地細格的最大值、過小的粗格湖（< `WG_LAKE_MIN`）改為格內最多的非水地形；幹流映射到粗格後合併連續重複並去掉尾端的海格。距離單位仍為遊戲格（細格球面以遊戲格寬為半徑），所有「格」參數不變；每格的增減量（氣團濕度）按 1/解析度換算；湖的最小面積乘解析度²。細格資料保留為 `World::fine`（`FineGeography`：高度 u16、地形、河流等級、流量對數刻度 0..255、溫度與濕度 0..255），供渲染（6.4）；納入世界雜湊；存檔不存（重生成即得）。

格點是星球的等距圓柱投影：`W = 2H`，x 東西環繞（x = W − 1 與 x = 0 相鄰），y = 0 為北極側、y = H − 1 為南極側。格心對應單位球上的點：

```
lon = 2π (x + 0.5) / W
lat = π/2 − π (y + 0.5) / H
```

| 開局選項 | 格點 W×H | 目標州郡數 | 板塊數 | 侵蝕迭代數 |
|---|---|---|---|---|
| 小 | 256×128 | 60 | 10 | 10 |
| 中（預設） | 384×192 | 110 | 14 | 6 |
| 大 | 512×256 | 180 | 18 | 8 |

- **面積**：一格的面積權重為 `cos(lat)`；凡「面積」「比例」（陸地比例、地形組成、州郡與島嶼面積、宜居度）皆為面積加權，單位為「赤道格」。
- **距離**：球面距離，以赤道上一格的寬度為單位，取弦長 `|p − q| × W / 2π` 近似大圓弧長；用於州郡種子間距、海鄰、洞天福地間距、靈氣衰減。
- **雜訊**：全部在單位球上以三維梯度雜訊（Perlin 2002 改良版；自寫 `noise.rs`，7.4 §3.8：為逐位元決定性不用外部 crate）取樣（無接縫、極區不擠壓）；fBm 間隙度 2、增益 0.5；頻率以「特徵尺度：赤道格數」表示。domain warp 的偏移是三維向量（不是經緯度偏移），板塊、風場、流向也都以三維球面點與球面步長計算，極列沒有方位圖樣（漩渦）。
- **球面步長**：相鄰兩格的距離，東西向為 `cos(lat)`、南北向為 1、對角為兩者的平方和開根號；用於坡度、流向與侵蝕。
- **三角函數**：只用基本運算的多項式實作（6.5 規則 4）。

赤道一格約二十里；赤道周長約七千七百里（中尺寸）。

## 步驟

步驟依序執行；每一步只依賴前面步驟的結果。

### 1. 板塊、大陸核、噪聲與隆起（L1–L4）

1. **板塊（L1；Tectonics.js／WorldEngine 的結果形態，Civ 地圖腳本的大洲分離保證）**：`WG_PLATES` 個球面隨機點為板塊中心，彼此夾角 ≥ 36°（`WG_PLATE_SEP`；拒絕取樣，連續失敗 32 次後間距乘 0.9）；每格以兩層 domain warp 扭曲後的座標 `p′`（三維梯度雜訊各三個分量，特徵 140、40 格，振幅 40、22 格，`WG_WARP`）取最近中心為所屬板塊（球面 Voronoi，邊界曲折）。每個板塊有隨機運動向量（中心切平面上的隨機方向，速率 0.5–1.0，`WG_PLATE_SPEED`）。隨機順序逐一標為大陸板塊，直到大陸板塊面積 ≥ 陸地比例 × 1.0 的球面（`WG_PLATE_CONT_OVER`）：第一輪只取與已選大陸板塊不相鄰者（大洲彼此分離），不足時第二輪每次取與已選者相鄰數最少的板塊；其餘為海洋板塊。每格記錄到板塊邊界的距離 `b`（與第二近板塊中心的中垂面距離，赤道格）與鄰接板塊 `j`；邊界類型由兩板塊的相對運動決定：相對速度在兩中心連線方向的分量 ≥ 相對速率的 0.2 為聚合、≤ −0.2 為張裂、其餘為轉形（`WG_PLATE_CONV_FRAC`）。
2. **大陸核（L2；Azgaar 的 Hill 模板）**：每個大陸板塊一個核：中心自板塊中心沿隨機切向偏移 `U(0, 0.35)·Rp`（`Rp = sqrt(板塊面積 / π)`，`WG_CORE_OFFSET`），半徑 `R = Rp × U(0.7, 0.95)`（`WG_CORE_RADIUS`），另有 2–4 個葉（`WG_CORE_LOBES`）：中心偏移 `U(0.4, 1.0)·R`、半徑 `U(0.5, 0.8)·R`（`WG_LOBE_OFFSET`、`WG_LOBE_RADIUS`）。核與葉的振幅為極區衰減 `1 − 0.7·smoothstep(60°, 85°, |中心緯度|)`（`WG_POLAR_FADE`；Azgaar 的邊緣遮罩）。大陸層 `cont = max(振幅 × exp(−(d/R)²))`（d 為 `p′` 到丘中心的弦距），乘**板塊邊緣門**（Civ 的 rift／Azgaar 的 Strait：大陸不越過板塊邊界）：張裂、轉形、被動與隱沒邊界 `smoothstep(0, 12·(0.5 + shape), b)`（`WG_PLATE_EDGE`；門寬隨輪廓雜訊起伏，海峽曲折）；陸陸碰撞縫合線只設半門 `0.5 + 0.5·smoothstep(0, 12·(0.5 + shape), b)`（`WG_COLLISION_GATE`：核強者相連成一洲、山脈帶在縫合線上，否則為窄海）；海洋板塊為 0。再乘輪廓調變 `0.7 + 0.6·shape`（`WG_SHAPE`：特徵 70 格、3 八度的 fBm，以原座標取樣，拉伸到 0..1）。
3. **基底（L4；fBm 與 domain warp 的海岸碎形，mapgen4 的「種子距離 + 噪聲」）**：`base = 0.42·cont + 0.58·detail + 0.35·smoothstep(0.68, 1, island) + 海洋邊界作用`（`WG_CONT_WEIGHT`、`WG_ISLAND`）。`detail` 為 7 八度、特徵 48 格、增益 0.6 的 fBm（`WG_FBM`），`island` 為 4 八度、特徵 40 格的 fBm，皆以 `p′` 取樣並拉伸到 0..1；細節的高八度給出半島、海灣、岬角與群島，核外的細節高點與島群項成為小島。海洋邊界作用（帶形 `g(b, w) = exp(−(b/w)²)`，`WG_BAND`）：

   | 邊界 | 作用（加到 `base`） |
   |---|---|
   | 洋陸聚合，海洋側 | 海溝 `−0.08·g(b, 5)`（`WG_TRENCH`） |
   | 洋洋聚合 | 仰衝側（索引較小者）島弧 `+0.20·g(b, 4)·ridged·smoothstep(0.5, 0.8, oro)`（`WG_ARC`；沿帶斷續成島鏈）；另一側海溝 `−0.08·g(b, 5)` |
   | 陸陸張裂 | 裂谷 `−0.20·g(b, 6)`（`WG_RIFT`） |
   | 洋洋張裂 | 洋脊 `+0.05·g(b, 6)`（`WG_OCEAN_RIDGE`） |
   | 陸陸轉形 | 淺裂谷 `−0.08·g(b, 6)`（`WG_TRANSFORM_RIFT` = 裂谷的 0.4 倍） |
   | 洋陸張裂、其餘轉形 | 無作用 |

4. **暫定海平面**：`sea₀` 為 `base` 的面積加權分位數（步驟 2 的方法）；陸地基底 `lb = (base − sea₀)/(1 − sea₀)`，內陸門 `inland = smoothstep(0, 0.12, lb)`（`WG_INLAND_GATE`，海岸帶不起山）。
5. **造山帶（L3；mapgen4 的「到山脊的距離場 × 脊狀雜訊」，脊線取自板塊聚合邊界）**：造山雜訊 `oro`（3 八度、特徵 130 格的 fBm，以 `p′` 取樣，拉伸到 0..1，`WG_OROGENY`）。
   - 板塊帶：陸陸碰撞 `A = 1.0, w = 10`（`WG_UPLIFT_COLLISION`、`WG_BAND_COLLISION`）；洋陸隱沒的大陸側海岸山脈 `A = 0.85, w = 7`，帶心自邊界內移 12 格（`WG_UPLIFT_COAST`、`WG_BAND_COAST`、`WG_BAND_COAST_INSET`；山脈在岸上而非海溝裡）。`plate_core = A·g(|b − inset|, w)·smoothstep(0.25, 0.6, oro)`（`WG_BELT_ORO`：沿帶斷續，形成分段的山脈與隘口）；山麓帶 `plate_foot = A·g(|b − inset|, 3.0w)·(1 − g(|b − inset|, w))`（`WG_FOOTHILL_BAND`）。
   - 板塊內帶（古老山系）：`belt = max(1 − min(|oro − 0.35|, |oro − 0.68|) / 0.18, 0)`（兩條等值線附近的曲折長帶，`WG_OROGENY_ISO`、`WG_OROGENY_HALF`），`noise_core = 0.8·smoothstep(0.25, 1, belt)`、`noise_foot = 0.8·smoothstep(0, 0.25, belt)·(1 − smoothstep(0.25, 1, belt))`（`WG_INTRAPLATE`、`WG_OROGENY_CORE`）。
   - `core = max(plate_core, noise_core)`，`foot = max(plate_foot, noise_foot)`。
6. **隆起圖與初始高度**：陸地的地勢 `e = clamp(0.15·lb + 山脈 + max(山麓, 丘陵), 0, 1)`（`WG_LOWLAND_RISE`）：
   - 山脈 `= 1.7 × relief × 2 × core × inland × ridged²`（`WG_MOUNTAIN_AMP`、`WG_RELIEF_SCALE`；`ridged` 為 Musgrave 脊狀多重碎形：5 八度、特徵 24 格、銳化 1.3、八度加權 2，`WG_RIDGE`，以 `p′` 取樣並拉伸到 0..1）。
   - 山麓 `= 0.20 × foot × inland × hills`（`WG_FOOTHILL`；`hills` 為 3 八度、特徵 22 格的 fBm，以 `p′` 取樣，`WG_HILL`）。
   - 丘陵 `= 0.08 × smoothstep(0.55, 0.80, hill_mask) × inland × hills`（`WG_HILL_MASK`：3 八度、特徵 110 格，以原座標取樣；`WG_HILL_AMP`）。
   - 初始高度 `h = sea₀ + (1 − sea₀)·e`；海格保留 `base`（海床起伏）。`e` 同時是**隆起圖** `U`（Cordonnier et al. 2016：大尺度地形 = 隆起圖 + 河流侵蝕）。
7. **河流侵蝕（Braun & Willett 2013 的隱式 stream-power 解法）**：迭代 `WG_EROSION_ITERS` 次（依尺寸 10／6／8；流向每 `WG_EROSION_ROUTE_EVERY` = 2 次迭代重算），每次：
   1. 以 Priority-Flood（步驟 3 的演算法）在目前高度上求每格的 receiver（流向）與拓撲順序；
   2. 沿逆序累積集水面積 `A`（面積權重 `cos(lat)`；海格不累加）；
   3. 依順序（receiver 先於上游）隱式求解 `dh/dt = U − K·A^m·S^n`（`m = 0.5`、`n = 1`）：`h_i ← (h_i + U_i·u·dt + f·h_r) / (1 + f)`，`f = K·sqrt(A_i)·dt / d(i, r)`，`d` 為球面步長；`dt = 1`、`K = 0.02`、`u = 0.01`（`WG_EROSION_DT`、`WG_EROSION_K`、`WG_EROSION_UPLIFT`）。只在 receiver 較低時下切（窪地保留，最後成湖）；無 receiver 或 receiver 較高者只隆起；海格為基準面不變；陸格可被侵蝕到海平面以下（海岸切割）。
   解法無條件穩定、每次迭代 O(n log n)（受 Priority-Flood 的堆限制），迭代數依 [6.8 效能預算](../6-開發/6.8-效能預算.md)（中尺寸 ≤ 1.5 秒）選定。
8. **海床（L5；海平面以下的高度有物理意義，供海深渲染與海路）**：侵蝕與最終海平面之後，以陸地遮罩對每個海格塑形（侵蝕不動海格）。`d` 為到最近陸格的球面距離（遊戲格；Dijkstra、步長為球面步長）：
   - **大陸棚**：棚寬 `Ws = 2·(0.5 + shape)`（`WG_SHELF_W`；被動邊緣寬），海溝側（隱沒帶海洋側、島弧非仰衝側）× 0.3（`WG_SHELF_SUBDUCTION`），最近陸塊面積 < 300 格者乘 `sqrt(面積/300)`（下限 0.25，`WG_SHELF_FULL_AREA`；小島的棚窄）。`d ≤ Ws`：深度自 0.02 線性到棚緣 0.05（`WG_SHELF_DEPTH`、`WG_SHELF_EDGE_DEPTH`）。
   - **大陸坡與深海平原**：`d > Ws`：深度 `0.05 + 0.30·s + 0.03·(2·detail − 1)·s`，`s = smoothstep(Ws, Ws + 4, d)`（`WG_SLOPE_W`、`WG_ABYSS_DEPTH`、`WG_ABYSS_NOISE`）。
   - **洋脊**（洋洋張裂邊界）：深度 `−0.15·g(b, 6)·s`（`WG_RIDGE_RISE`）；**海溝**（海溝側）：`+0.10·g(b, 4)·s`（`WG_TRENCH_DEEPEN`）；**島弧淺灘**（仰衝側，`g(b, 4)·斷續門 > 0.3`）：深度上限 0.06（`WG_ARC_BANK_DEPTH`）；**封閉海**（海的八鄰連通分量面積 < 150 格）：深度上限 0.08（`WG_ENCLOSED_SEA`）。
   - 海格高度 = 海平面 − 深度（深度下限 0.01）。

### 2. 海平面（L6）

侵蝕之前先取初始高度 `h` 的面積加權分位數，使陸地面積比例等於開局參數「陸地比例」，預設 0.40（範圍 0.25–0.55）；侵蝕之後再取一次。

**補救優先於重抽**（7.4 §3.1；Civ 的 rift、Azgaar 的 Strait）：海平面定出後，若最大八鄰連通陸塊占陸地 > 0.6（`WG_STRAIT_MAX_SHARE`），在該陸塊內「帶內陸地格最多」的板塊邊界（無序板塊對）上切一道海峽：該對邊界兩側的格 `h −= 0.5·g(b, 8)`（`WG_STRAIT_DEPTH`、`WG_STRAIT_W`），重取海平面；最多 6 次（`WG_STRAIT_TRIES`）。仍不合格者由品質檢查以混合後的種子重抽。

### 3. 填窪與湖

1. 以 Priority-Flood（Barnes, Lehman & Mulla 2014）對陸地填窪；海格與極區列（y = 0、H − 1）為排出口。堆的彈出順序即拓撲順序（流向目標一定先彈出），直接供河流累積與侵蝕使用（mapgen4 的作法）；平地與湖面的流向取 flood 的來源方向（等同 ε 變體：每格都能流出）；坡度以球面步長計。
2. 填平後水深（等於填平高度 − 原高度）≥ 0.01（`WG_LAKE_DEPTH`）且面積 ≥ 6 格的窪地標記為湖；其餘（淺或小的）窪地視為填平。

### 4. 氣候（L7）

- **溫度**：`t = 1.0 − 1.1·|lat|/90° − 0.3·陸高 + 0.22·(noise − 0.5)`（`WG_TEMP`；陸高 = `(h − sea)/(1 − sea)`，赤道熱、兩極冷）。
- **風帶**（三圈環流，`WG_WIND`）：|lat| < 30° 信風自東來；30°–60° 西風帶自西來；> 60° 極地東風自東來；風帶邊界 ±4° 內兩方向的結果以 smoothstep 混合（`WG_WIND_BLEND`，避免條帶斷裂）。
- **氣團濕度** `m`（mapgen4 的地形雨）：每列分別自東、自西掃描兩圈（第一圈只建立起始狀態，起始 0.5）：經海格 `+0.15`（上限 1）；經陸格：空氣含水上限 `cap = 1 − 0.9·陸高`，超過者降下 `rain = 0.5·(m − cap)`，再 `−0.012`，下限 0（`WG_MOIST`、`WG_OROG`）。迎風坡多雨、背風坡乾，山越高越明顯，不設山脈硬門檻。兩方向依風帶權重混合後，每欄取上下各 4 列的平均（`WG_MOIST_SMOOTH`，消除逐列掃描的條紋）。
- **濕度**：`q = 0.4·noise + 0.4·m + 0.2·coast − dry`（`WG_HUMID_MIX`），`coast = exp(−d/10)`（d 為到海的八鄰步數，`WG_COAST_DECAY`），`dry = 0.12·exp(−((|lat| − c)/20°)²)·(0.3 + 1.4·noise)`（副熱帶乾燥帶，中心 `c = 25° ± 10°·(2·wobble − 1)` 隨 2 八度、特徵 160 格的低頻雜訊擺動，強度隨濕度雜訊起伏成片狀，`WG_DRY_BELT`）。最後乘上開局參數「濕潤度」，下限 0。
- 氣候雜訊：溫度 3 八度、濕度 4 八度，特徵 110 格（`WG_CLIMATE_NOISE`），拉伸到 0..1；使生態區呈片狀而非帶狀。
- **連續性**：溫度與濕度場各做一次方框平滑（半徑 2 格，`WG_BIOME_SMOOTH`），生態區由連續的氣候梯度分類，過渡為漸層而非硬邊（渲染端以 `fine.temperature`／`fine.moisture` 混色）。

### 5. 地形

| 代碼 | 地形 | 判定（依序，先符合者優先） |
|---|---|---|
| 0 | 海 | `h < sea` |
| 1 | 湖 | 第 3 步標記 |
| 4 | 山脈 | 陸地高度 `(h−sea)/(1−sea) > 0.55` |
| 6 | 雪原 | `t < 0.23` |
| 3 | 丘陵 | 陸地高度 > 0.25 |
| 7 | 沙漠 | `q < 0.22` 且 `t > 0.3`（含溫帶的寒漠） |
| 8 | 沼澤 | `q > 0.74` 且陸地高度 < 0.12 |
| 5 | 森林 | `q > 0.55` |
| 2 | 平原 | 其餘 |

**去斑**（陸地連續性）：分類後，氣候地形（平原、森林、沙漠、沼澤、雪原、丘陵）面積 < 12 格（`WG_BIOME_MIN_PATCH`；細格乘解析度²）的八鄰連通斑塊，改為斑塊邊界外最多的氣候地形，做兩輪；山脈、湖、海不動。丘陵帶的獨立起伏振幅降為 0.08、山麓帶寬 × 3（`WG_HILL_AMP`、`WG_FOOTHILL_BAND`），使高度自海岸 → 平原 → 山麓 → 山脈連續，而非孤立的丘塊。

「荒野格」指森林、山脈、沼澤、雪原，以及與海相鄰的陸地格（3.10）。

### 6. 河流

1. 在填窪後的高度上，以 D8 最陡下降求流向（八鄰含 x 環繞）；湖視為一個節點，從最低出口流出。
2. 依流向累積降水量（每格降水 = `q`）。
3. 累積量分級，閾值為陸地格累積量的分位數：
   - 前 10% 為小河
   - 前 5% 為大河
   - 前 1.5% 為江

   分位以遊戲格定義；在細格上計算時分位除以解析度（細格河道格數約為解析度倍），降採樣後的河網密度相同。
4. 每條入海的江河，取其最長幹流命名（7.3）；江級幹流短於 20 格（`WG_JIANG_MIN_LEN`）者不命名。粗格幹流的出海口須鄰海。

### 7. 州郡

1. **宜居度**（每格）：見 [2.3 州郡與人口](2.3-州郡與人口.md)，再乘面積權重 `cos(lat)`。
2. **種子點**：在陸地上以宜居度加權的 Poisson-disk 取樣，最小間距 `sqrt(陸地面積 / 目標州郡數) × 0.8`（球面距離），直到數量達到目標州郡數。
3. **成長**：多源 Dijkstra（八鄰含 x 環繞；兩側皆為水的對角縫不可通過；對角步的代價乘 √2），每格代價：

   | 項目 | 代價 |
   |---|---|
   | 基本 | 1 |
   | 丘陵 | +1.5 |
   | 山脈 | +3 |
   | 進入大河／江格 | +6（在格的代價上加；河格本身的地形代價照算） |
   | 海、湖 | 不可通行 |

4. **小島**：面積 < 120 的島嶼，併入最近的沿岸州郡（該州郡可不連通，也可因此含有另一大洲的小島）；≥ 120 的島嶼至少有一個自己的州郡。州郡不跨大洲（小島併入除外）。
5. **合併過小者**：面積 < 平均 35% 的州郡，併入代價最低的鄰居。
6. **相鄰**：共享邊界格的州郡互為陸鄰（含跨 x 接縫）；隔海、球面距離 ≤ 12 的沿岸州郡互為海鄰（海路）。
7. **治所**：每州宜居度最高的格點，城池模型放在這裡。

### 8. 靈脈

見 [2.4 靈脈與氣場](2.4-靈脈與氣場.md)。距離為球面距離；A* 的啟發式為環繞下的 Chebyshev 步數 × 最低代價。

### 9. 命名與大洲

- **大洲**：八鄰連通的陸塊（非海格，湖算陸地）中面積 ≥ 120（`WG_CONTINENT_MIN`）者，依面積由大到小編號並命名（[7.3 大洲命名](../7-附錄/7.3-命名規則.md)：儒、釋、道三教輪流；面積 ≥ 陸地 5% 者稱洲，較小者稱島）。更小的陸塊不命名，`continent_of` 為 `u16::MAX`。
- **山脈**：山脈格依「所屬板塊、最近的鄰接板塊、沿邊界每 48 格的段號」（`WG_RANGE_SEGMENT`）分組，各組內八鄰連通且格數 ≥ 12 者為一條山脈——長帶因此依板塊對、邊界兩側與段落分為數脈；板塊內的古老山系同樣以此鍵分段；最高者稱「嶽」。
- 州郡的方位字以所屬大洲的中心為準。
- 州郡、江河、山脈、洞天的命名見 [7.3 命名規則](../7-附錄/7.3-命名規則.md)。

## 地形組成目標

世界生成的演算法與係數，以下列可量測的目標校準（中尺寸、預設開局參數，20 個種子的面積加權平均；每個種子的地勢項——平原、森林、丘陵、山脈——至少達下限的一半；雪原、沙漠、沼澤取決於陸地落在哪個氣候帶，只看平均）：

| 項目 | 目標 |
|---|---|
| 平原 | 陸地的 25–40% |
| 森林 | 15–30% |
| 丘陵 | 10–20% |
| 山脈 | 8–15%，且沿板塊聚合帶與造山帶呈「脈」狀：至少 3 條已命名山脈，最大一條不超過山脈面積的 50% |
| 雪原 | 5–15%（高緯與高山） |
| 沙漠 | 3–12%（副熱帶、雨影與內陸） |
| 沼澤 | 1–6% |
| 江河 | 地圖上清楚可見：大河與江的格數總和 ≥ 1.5 × W |
| 大洲 | 至少 2 塊各 ≥ 陸地 5%；最大陸塊 ≤ 陸地 70% |
| 海岸曲折度 | 每塊 ≥ 5% 的大洲：海岸線長（真實長度）÷ 等面積圓周長 `2·sqrt(π·A)` ≥ 1.4（海岸由噪聲決定，不是光滑的板塊輪廓） |
| 小島 | 每個世界至少 6 塊面積 < 陸地 1% 的陸塊 |
| 生態區邊界方向比 | 森林、沙漠各自的陸上邊界中，南北走向的長度 ≥ 全部的 30%（片狀而非純緯度條紋） |
| 極列 | 極列（y = 0、H − 1）高度的相鄰差 < 赤道列的 35%（無方位圖樣） |

後六項為每個種子都須滿足；地勢項的下限每個種子須達一半；其餘看 20 個種子的平均。

## 對照成熟生成器的指標

與 Azgaar、mapgen4、WorldEngine 等成熟生成器對照的可量測指標（7.4），每個種子（中尺寸、預設參數）都須滿足；皆由測試在遊戲格與細格上計算：

| 指標 | 定義 | 目標 | 依據 |
|---|---|---|---|
| 海岸線碎形維度 | 細格海陸邊界格的盒計數維度：盒邊 2、4、8、16 細格，對 log(盒數) ~ log(1/邊) 做最小平方斜率 | 1.05–1.45 | 真實海岸線約 1.2–1.3（Mandelbrot）；盒邊只有 2–16 格時格點生成器的海岸多落在 1.1–1.3 |
| 島嶼面積分布 | 遊戲格的八鄰連通陸塊依面積降冪；陸塊數 ≥ 12，且面積 < 陸地 1% 的小島 ≥ 6 | 粗略冪律：第 2–4 名之和 ≥ 第 1 名的 0.4 倍；小島數 ≥ 大洲數 | Azgaar「大陸＋群島」的面積層次 |
| 山系伸長比 | 遊戲格上八鄰連通的山脈格（山系，≥ 12 格）的主軸長 ÷ 次軸長（格座標的協方差主成分近似，x 以 cos(lat) 修正） | 山系面積加權平均 ≥ 1.5；最大山系 ≥ 1.3（初版門檻；山系交會成網時伸長比偏低） | 真實山脈為線狀帶而非團塊（mapgen4 距離場山脊） |
| 山脊連續度 | 每條已命名山脈的山脈格八鄰連通分量數 | 每條 ≤ 3 | 一條脈不應碎成數塊 |
| 河網 | 細格全部陸地格依高度最陡下降建立的流域樹（河流格是其中流量最大的部分），Strahler 階 | 最大的大洲最大 Strahler 階 ≥ 4，其餘 ≥ 5% 陸地的大洲 ≥ 3；已命名的江每條長度 ≥ 20 遊戲格 | 樹枝狀水系（Braun–Willett 侵蝕、O'Leary） |
| 生態區斑塊 | 遊戲格上森林、沙漠、雪原的八鄰連通斑塊 | 森林斑塊數 ≥ 8；沙漠 ≥ 陸地 4% 時最大沙漠斑塊 ≤ 沙漠面積的 75%；邊界方向比 ≥ 0.30（無緯度條紋） | Whittaker 式的片狀生態區而非帶狀 |
| 大陸棚比例 | 細格海面積中深度 < 0.055 者的比例 | 4–25% | 地球約 7–10%；本星球海岸線較地球密（大洲多、海岸碎形），比例偏高 |
| 斑塊度（陸地連續性） | 遊戲格陸地格中，八鄰（只算陸格）多數地形（≥ 5 格）與自身不同者的比例；氣候地形（平原、森林、沙漠、沼澤、雪原、丘陵）八鄰連通斑塊的平均大小 | ≤ 6%；平均 ≥ 15 格 | 無鹽椒格、生態區成片 |
| 極區 | 極列高度相鄰差 < 赤道列的 35% | — | 無漩渦／方位圖樣 |

指標以 `siming-cli gen --layer atlas` 的對照圖（山體陰影、生態漸層、依流量的河寬、海岸線）目視驗證；數值門檻為初版，依對照圖再調整（調整須同步本表與測試）。

## 品質檢查（生成後自動驗證；失敗則以 `retry_seed(seed, n)` 重試，最多重試 8 次，即最多 9 次嘗試）

重試種子 `retry_seed(seed, n)`：n = 0 為原種子，之後為 `splitmix64(seed ⊕ n·0x9e3779b97f4a7c15)`——不同輸入種子的重試鏈不會重疊（`seed + 1` 會使相鄰種子落在同一個世界）。200 個種子輪流以三種尺寸生成須全部成功且高度場兩兩不同（測試）。

- 陸地比例（面積加權）誤差 ≤ 0.02（陸地 = 非海格，湖算陸地）。
- 至少 2 塊大洲各 ≥ 陸地面積的 5%。
- 最大陸塊 ≤ 陸地面積的 70%。
- 州郡數在目標 ±15% 內，且每個州郡面積 ≥ 30。
- 至少 3 條入海的江。
- 洞天福地數 ≥ 8（數量 = 目標州郡數 × 0.2）。

重試時，存檔記錄的是最終使用的種子。
