# 2.3 州郡與人口

州郡是模擬的地理單位：人口、經濟、氣場、歸屬都以州郡計。本節的人口、殘破、教化與氣場欄位都是 [2.7 場域](2.7-場域.md) 的「州域場」，寫入經由 6.9 的統一入口，傳輸（遷徙、靠攏、擴散、順流、衰減）由 6.9 的運算核心執行。

## 宜居度（每格）

| 地形 | 宜居度 |
|---|---|
| 平原 | 1.0 |
| 森林 | 0.5 |
| 丘陵 | 0.4 |
| 沼澤 | 0.2 |
| 山脈 | 0.1 |
| 沙漠、雪原 | 0.05 |
| 海、湖 | 0 |

加成：
- 鄰接河流：小河 +0.3、大河 +0.6、江 +0.8。
- 鄰接海或湖：+0.3。

州郡宜居度 = 所屬格點宜居度總和，每格先乘面積權重 `cos(lat)`（2.2 尺寸）。

## 人口

- 初始人口：`P₀ = habitability × 1500 × 開局時代係數`（上古 0.3、中古 1.0、末法 1.2）。
- 承載上限：`K = habitability × 3000 × (1 − 0.5·devastation) × (1 − 0.3·karma_qi) × 暫時修正`。
  - 暫時修正：旱澇 × 0.5（4.2）、劫後重建 × 1.5（3.11），到期恢復 1。
- 每年：
  - 成長：`P += P × r × (1 − P/K)`，r = 0.008（盛世 × 1.5）。P > K 時為負成長。
  - **饑荒**：P > 1.05K 時，額外死亡 `(P − K) × 0.5`，並寫入「饑荒」事件；業氣 +0.02。
  - 遷徙：P > 0.9K 的州郡，把 1% 人口移往承載比 `P/K` 最低的陸鄰；只在該鄰州的承載比低於本州時遷徙。
- 年度順序：
  1. 以年初的殘破度計算 K。
  2. 成長。
  3. 饑荒。
  4. 遷徙：以成長、饑荒後的人口為準，所有州同時計算後一起套用；承載比相同時取 ID 小者。
  5. 殘破恢復。
  6. 城池等級。
- 殘破度：每年 −0.1；戰鬥、圍城、天災時增加（見 [3.9 戰爭](../3-核心系統/3.9-戰爭.md)、[3.11 量劫](../3-核心系統/3.11-量劫.md)）。

## 城池等級

依人口與是否為都城決定，只影響地圖模型大小與稅收：

| 等級 | 名稱 | 條件 |
|---|---|---|
| 0 | 村 | P < 20,000 |
| 1 | 鎮 | P ≥ 20,000 |
| 2 | 縣 | P ≥ 80,000 |
| 3 | 州 | P ≥ 200,000 |
| 4 | 都 | 王朝都城 |

## 稅收與兵源

- 年稅（錢糧）：`P × 0.001 × (1 − devastation) × (1 − 寺院香火 × 0.3)`，歸屬州郡的王朝。
- 常備軍：`P × 0.005`（3.7）。
- 動員兵力上限：`P × 0.02`（3.9）。
- 常備軍與動員兵從 P 中扣除；解散時歸還存活者。

## 教化（faith）

- 三維：道、釋、儒，和 ≤ 1；其餘為民間雜信。
- 每年，每個教的比例向「該州的教化來源」靠攏 5%：
  - 道：宗門勢力範圍。
  - 釋：寺院香火。
  - 儒：書院與王朝的尊儒政策。
- 教化來源的目標值：
  - 道：在宗門勢力範圍內為 `min(1, Σ 宗門聲望 / 300)`。
  - 釋：寺院香火 H，或鄰州擴散的 `0.3 × H`。
  - 儒：本州書院為 0.5，王朝國策尊儒再 +0.3。
  - 三者總和超過 1 時，等比縮放。
- M2 只更新「道」的教化目標；釋、儒的教化在 M3、M4 接上（7.5、7.6）。
- 用於三教地圖模式，以及魂的道緣（3.1 faith4）。
- 上古開局時，每州 faith 初值為 `(U(0.1,0.4), U(0,0.15), U(0,0.15))`，使三教都有出現的可能（4.6）。
