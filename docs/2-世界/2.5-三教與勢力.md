# 2.5 三教與勢力

三教是三條離開輪迴的路，不是三種皮膚。魔與妖是輪迴中墮落的一面。

| 勢力 | 所屬 | 地圖上的存在 | 成員 | 追求（超脫） | 規格 |
|---|---|---|---|---|---|
| 王朝 | 儒 | 佔據州郡的疆域（大面積著色）、都城、軍隊 | 君主、儲君、文臣、武將 | 天命；聖王封禪 | [3.7](../3-核心系統/3.7-儒-王朝與天命.md) |
| 書院 | 儒 | 城中的書院建築，正氣光暈 | 山長、儒士 | 三不朽而成聖 | [3.8](../3-核心系統/3.8-儒-書院與成聖.md) |
| 宗門 | 道 | 靈脈上的山門，勢力範圍虛線圈 | 掌門、長老、弟子 | 渡劫飛升 | [3.5](../3-核心系統/3.5-道-修煉與天劫.md) |
| 寺院 | 釋 | 寺塔建築，香火金光範圍 | 住持、僧人 | 證果涅槃 | [3.6](../3-核心系統/3.6-釋-功德與度化.md) |
| 魔門 | 魔 | 魔窟上的黑色據點，業氣煙柱 | 魔主、魔修 | 以殺證道（魔道飛升） | [3.10](../3-核心系統/3.10-魔與妖.md) |
| 妖域 | 妖 | 荒野州郡上的妖氣覆蓋 | 妖王、妖眾 | 化形、渡劫 | [3.10](../3-核心系統/3.10-魔與妖.md) |

## 勢力共通欄位

| 欄位 | 說明 |
|---|---|
| `id`、`kind`、`name` | 種類與名稱（7.3） |
| `seat` | 據點州郡（都城、山門、寺、書院、魔窟、妖穴） |
| `leader` | 首領（有名之人） |
| `members` | 有名之人成員 |
| `founded`、`fallen` | 創立與覆滅 tick |
| `prestige` | 聲望，決定招收與勢力範圍 |
| `relations` | 對其他勢力的態度 −100..100 |

## 勢力間關係

| 關係 | 機制 |
|---|---|
| 宗門 ↔ 宗門 | 勢力範圍重疊且爭同一靈脈節點 → 爭脈之戰（3.5） |
| 王朝 ↔ 王朝 | 宣戰、行軍、攻城、議和（3.9） |
| 王朝 ↔ 寺院 | 香火分走稅收 → 可能滅佛（3.6） |
| 王朝 ↔ 宗門 | 國師、供奉（宗門長老入朝）；或禁道（3.7） |
| 王朝 ↔ 書院 | 書院出仕提升德政；大儒諫言（3.8） |
| 寺院 ↔ 魔、妖 | 度化（3.6） |
| 宗門、書院 ↔ 魔、妖 | 斬妖除魔，殺有罪之魂得功德（3.1） |
| 魔門 ↔ 所有 | 襲殺、屠城以修煉（3.10） |
