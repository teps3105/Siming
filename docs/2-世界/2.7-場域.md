# 2.7 場域

世界的模型分兩層：**基底**是一顆以奇幻地圖模擬生成的星球（板塊、抬升與侵蝕、水系、氣候、生態區、州郡，見 [2.2 世界生成](2.2-世界生成.md)）；**其上**整個世界被表達為一疊「場域」——在同一片山河上定義的許多「維」，每一維是一個數值場：有的是物理的（高度、河流），有的是本作原創的虛擬維度（靈氣、業氣、功德、正氣、教化、緣）。

一句話：**山河是紙，場域是墨；系統只對場注入與抽取，場依自己的法則流轉，別的系統讀場而行動。** 故事因此在空間上湧現：屠城的業氣順水而下，在下游河口聚成魔窟；寺院的功德向四鄰暈開，壓住一方濁氣；書院的正氣讓王朝的天命穩住。

本節定義「有哪些維、每一維的意義與法則」；資料結構、運算核心、渲染取樣見 [6.9 場域框架](../6-技術/6.9-場域框架.md)。

## 場域觀

| 原則 | 內容 | 依據 |
|---|---|---|
| 一維一場 | 每個「維」是一個標量或向量場，定義在格、州或脈三種域之一上 | — |
| 源—傳輸—匯 | 每個場有明確的寫入者（源）、傳輸法則（擴散、順流、衰減、靠攏）、讀取者（匯）；沒有「某系統偷偷改某州某值」 | 1.4 規則 2 |
| 看得見 | 每個場都有地圖模式或圖層；看不見的維不存在 | 支柱 2、1.4 規則 2 |
| 能生緣 | 場的作用最終要回到魂與宿緣：業氣生妖魔、妖魔遇修士、殺業成線 | 支柱 4、1.4 規則 1 |
| 清濁雙極 | 本作的「陰陽」：靈氣為清、業氣為濁。清氣聚於山脈與靈脈、不流動；濁氣沉重、順水而下、向四鄰暈開。功德與正氣輕，只暈開、不順流 | 支柱 2、5 |
| 確定性 | 所有傳輸以快照計算、依 ID 順序寫回，結果與處理順序無關 | 1.4 規則 5 |

## 三種域

| 域 | 單位 | 數量（中尺寸） | 儲存 | 典型的場 |
|---|---|---|---|---|
| 格 | 等距圓柱投影格點（2.2） | 384×192 = 73,728 | `Geography` 的 `Vec`（SoA） | 高度、地形、河流、格點靈氣 |
| 州 | 州郡（2.3） | 約 110 | `Province` 欄位（≤ 180 州，AoS 即可） | 人口、業氣、功德、正氣、教化、殘破 |
| 脈 | 洞天福地（節點）與靈脈（邊）（2.4） | 約 16 節點、約 30 邊 | `LeyNode`、`LeyEdge` | 節點強度、靈脈強度、宗門佔用 |

另有**全域量**（天道業障 4.4、魔勢 3.10、量劫強度 3.11）：它們不是場，但是場的耦合端——由場聚合而來，或回頭調整場的門檻。

域之間的轉換只有兩種：
- **聚合**（格 → 州、脈 → 格）：例如州郡靈氣 = `0.7 × 格點平均 + 0.3 × 格點最大`（2.4）；格點靈氣由節點與靈脈距離衰減得到。
- **投影**（州 → 格）：用於渲染與「格的人口」（4.2 移山的人口損失）：格值 = 州值 × 該格宜居度 / 州宜居度總和（人口），或格值 = 州值（氣場，再暈染，見 6.9）。

## 清濁雙極與順流

這是場域層最原創的法則，也是「業氣地圖」會長出地理故事的原因。

- **清氣（靈氣）聚而不流**：靈氣是山與脈的「勢」，由地形與靈脈決定，只在地貌改變時重算。修士逐靈氣而居，宗門立於洞天。
- **濁氣（業氣）沉而下流**：業氣每季除了向四鄰暈開，還有 `KARMA_DRIFT`（4%）順著本州主河流向下游州郡；河口與下游平原因而成為業氣的「淵藪」，魔窟多生於此，魔門沿江而立。入海的業氣消散（下游為海時無順流）。
- **輕氣（功德、正氣）暈而不流**：功德與正氣只向四鄰暈開，不順流；因此寺院與書院是「點」，業氣是「流」——善需要一座一座立起來，惡會自己流向低處。

`downstream`（2.3 欄位）：州郡內累積量最大的河流格（出口格）沿 2.2 的流向進入的下一格所屬州郡；該格為海、湖或仍屬本州時為無。生成時計算，移山時重算。

## 耦合

場不直接改場；耦合經由系統（寫入者）與門檻事件發生。下表列出跨場的主要因果鏈，完整的「誰讀誰寫」矩陣見 6.9。

```
 人口 ──饑荒──▶ 業氣 ──順流、擴散──▶ 濁氣 ──門檻──▶ 疫病 ──▶ 人口↓、業氣↑
                                            ├──門檻──▶ 妖滋生 ──▶ 妖襲 ──▶ 業氣↑、殺業線（斬妖）
                                            └──門檻──▶ 魔窟 ──▶ 魔門 ──▶ 討魔之戰 ──▶ 殺業線
 戰爭 ──死傷、屠城──▶ 業氣、殘破 ──▶ 承載↓、天命↓ ──▶ 起義 ──▶ 戰爭
 寺院 ──香火──▶ 功德↑、業氣↓、教化（釋）、超度 ──▶ 六道判定
 書院、大儒 ──▶ 正氣↑ ──▶ 天命↑、書院規模↑
 靈脈 ──▶ 靈氣 ──▶ 修煉速度、宗門選址、風水（天命）
 教化 ──▶ faith4 ──▶ 道緣傳承、因果牽引 ──▶ 出生地 ──▶ 相遇 ──▶ 了結
 司命 ──疫病、旱澇、移山、開脈、斷脈、祥瑞──▶ 任一層
 全域：Σ(業氣 × 人口)、Σ((功德 + 正氣) × 人口) ──▶ 量劫強度 ──▶ 劫煞 ──▶ 天災
```

### 司命與場

每個權能都是場的寫入者（4.2）：疫病寫業氣與人口；旱澇寫承載修正；造山、平地、滄海桑田改寫基底場並觸發重算鏈；開脈、斷脈改寫脈域場並重算靈氣；祥瑞寫正氣；天雷、心魔、引渡、牽線、點化、賜福作用在魂與人，不直接寫場。

## 重算鏈

基底場或脈域場改變時，依序重算（移山：4.2；量劫損脈：3.11）：

1. `height`、`terrain`（只在移山時）→ `river`、`downstream` → 宜居度（格、州）→ 承載 K。
2. `LeyNode`、`LeyEdge`（開脈、斷脈、量劫）→ `aura_cell` → `aura`。
3. 影響範圍內州郡的 `terrain_mix`、`cells`、`neighbors`、`sea_neighbors`（只在滄海桑田與造山時）。
4. 渲染端：`province_id`、`field` 貼圖重新烘焙（6.9）。

重算只針對受影響的格與州（移山：半徑內的格與含這些格的州；量劫損脈：受損節點 24 格內的格與州），以 ID 順序處理。

## 湧現的例子（設計驗證用）

1. **業隨水下**：上游兩國交戰，屠城 +0.4 業氣；十年內業氣順流到下游河口州，濁氣 > 0.8 形成魔窟；魔修立派，襲殺一名遊歷至此的金丹修士，建立殺業線——下一世這條線在因果模式中跨越整條江。
2. **一寺鎮一方**：河口州的寺院香火升到 0.8，每年 −0.016 業氣並 +0.016 功德，四鄰的濁氣隨之降下；魔窟在濁氣 < 0.4 時消失。玩家在業氣模式看到一圈 gold 淡塗慢慢擴大。
