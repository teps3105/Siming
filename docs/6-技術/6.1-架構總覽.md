# 6.1 架構總覽

```
┌──────────────── siming（Bevy 應用：原生 / WASM）────────────────┐
│  render/  地形、水墨著色器、地圖模式、模型、標籤、奇觀              │
│  ui/      bevy_egui：頂欄、權能列、傳聞、卡片、輪迴台、天書、結算    │
│  input/   鏡頭、選取、權能目標選擇                                  │
│  bridge/  驅動模擬、同步可視實體、事件轉奇觀                        │
│  storage/ 存檔、設定、天書（原生：檔案；WASM：IndexedDB）            │
└──────────────────────────────┬─────────────────────────────────┘
                               │ 唯讀狀態、事件 ◀──── ▶ Command
┌──────────────────────────────▼─────────────────────────────────┐
│  siming-sim（純 Rust 函式庫：無引擎、無 IO、確定性）              │
│  params  worldgen  calendar  soul  people  powers  field         │
│  war  cosmos  command  ledger  save                              │
└────────────────────────────────────────────────────────────────┘
          ▲                                         ▲
  siming-cli（無頭：生成、模擬、統計、重播、匯出圖檔）     tests/
```

`field` 模組是 [6.9 場域框架](6.9-場域框架.md)：所有州域與格域的「場」（2.7）的識別、統一讀寫入口、傳輸運算核心與重算鏈；其他系統是場的讀取者與寫入者。`render/` 以同一條烘焙與著色路徑呈現任一場。

```
Cargo.toml                 workspace
crates/
  sim/                     siming-sim（lib）
    src/params.rs          8.1 參數總表的唯一程式對應
    src/worldgen/          2.2
    src/field/             2.7、6.9（識別、核心、衍生場、重算鏈）
    src/...                其餘模組見 6.2、6.3
  app/                     siming（bin，執行檔 Siming，Bevy 0.16 + bevy_egui 0.34）
    src/render/ ui/ input/ bridge/ storage/
    assets/                9 素材（字型子集、著色器）
    index.html             WASM 外殼
  cli/                     siming-cli（bin）
tools/
  subset_font.py           字型子集化（6.6）
docs/                      本 GDD
```

## 依賴原則

| crate | 允許 | 禁止 |
|---|---|---|
| sim | serde、serde_json（只用於編譯期嵌入的字庫）、rand、rand_chacha、bincode、miniz_oxide、smallvec、rustc-hash（FxHasher） | bevy、任何 IO、執行緒、時間 |
| app | sim、bevy、bevy_egui、web-sys（僅 WASM） | 遊戲規則 |
| cli | sim、png、clap | — |
