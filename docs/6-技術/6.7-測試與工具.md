# 6.7 測試與工具

## 自動測試

| 類別 | 內容 | 位置 |
|---|---|---|
| 單元 | 公式（天劫存活率、六道判定、天命變化…）對照 8.1 | `crates/sim/src/**` |
| 世界生成 | 10 個種子都通過 2.2 品質檢查 | `crates/sim/tests/worldgen.rs` |
| 確定性 | 同種子跑兩次 1 運，雜湊相同 | `crates/sim/tests/determinism.rs` |
| 存檔 | 跑半運 → 存檔 → 載入 → 跑到一運，雜湊等於不中斷直跑 | 同上 |
| 指令 | 每種權能各下一次，重播雜湊相同 | 同上 |
| 跨平台 | wasm32 與原生跑同一劇本，雜湊相同 | CI |
| 平衡迴歸 | 3 個種子各 3 運的統計落在 8.1「平衡目標」範圍內 | `crates/sim/tests/balance.rs`（`#[ignore]`，CI 每晚跑） |

## siming-cli

| 子命令 | 功能 |
|---|---|
| `gen --seed S [--size s\|m\|l] --out map.png` | 生成世界並匯出圖檔：地形、河流、州郡邊界、洞天、地名；不需 GPU |
| `gen --seed S --layer province\|aura\|karma` | 匯出指定圖層 |
| `sim --seed S --yun N [--report r.json]` | 無頭跑 N 運；印出每世的統計（人口、勢力數、有名之人數、境界分布、宿緣建立與了結數、超脫數、天書觸發） |
| `replay FILE` | 重播存檔或分享碼並驗證雜湊 |
| `chronicle FILE --min-importance 4` | 印出因果帳（除錯用，不是產品功能） |

## App 除錯面板（F12）

- 每 tick 耗時（各系統分項）、幀時間、實體與事件數。
- 強制事件：指定人物立即突破、指定王朝天命設值、立即量劫。
- 強制事件同樣寫入指令紀錄（標記為除錯），使重播仍可重現。
- 除錯指令不可出現在正式分享碼中。

## 規範檢查腳本（tools/，僅用標準函式庫）

| 腳本 | 檢查內容 | 結束碼 |
|---|---|---|
| `python3 tools/check_hant.py` | 文件（`docs/**/*.md`）、資料與字串（`crates/**/data/*.json`、`crates/app/assets/text/*.json`）、Rust 字串常值與註解中的簡體字；每筆印出「檔案:行:欄: 簡→繁」 | 有簡體字為 1，否則 0 |
| `python3 tools/check_trace.py` | (a) `params.rs` 每個 `pub const` 的文件註解須引用 8.1 內的代號（反引號）；8.1 中 M1 範圍的列須有常數採用。(b) `docs/` 內相對 Markdown 連結皆可解析。(c) `docs/` 內每個檔案皆被 `docs/索引.md` 連結 | 有問題為 1，否則 0；`--list-info` 另列 M1 範圍外尚未抄寫的代號 |

- 簡體對照表僅收錄簡繁字形不同、且簡體字不是常用繁體字的字；刻意保留的簡體文字（例如說明簡體譯名的表格）登記於 `check_hant.py` 的 `ALLOW`。
- 兩支腳本預設以腳本所在的 repo 為根目錄；需要時加 `--root <路徑>` 指定。
