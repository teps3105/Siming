# 6.6 平台與建置

## 目標平台

| 目標 | 指令 | 備註 |
|---|---|---|
| Windows（Demo 必要） | CI Windows runner：`cargo build -p siming --release --features steam` | 10.4 |
| Linux、Steam Deck | `cargo run -p siming --release`（加 `--features steam` 為 Steam 版） | 主要開發環境 |
| macOS | — | Demo 不提供 |
| 瀏覽器 | `tools/build_web.sh` | wasm32-unknown-unknown + wasm-bindgen + wasm-opt；WebGL2 |
| 無頭 | `cargo run -p siming-cli --release -- <子命令>` | CI 與平衡調整 |

## WASM 建置流程（`tools/build_web.sh`）

1. `cargo build -p siming --release --target wasm32-unknown-unknown`
2. `wasm-bindgen --target web --out-dir dist/web`
3. `wasm-opt -Oz`（若有安裝）
4. 複製 `crates/app/index.html` 與 `assets/` 到 `dist/web/`
5. 目標體積：wasm ≤ 25 MB（壓縮前）、≤ 8 MB（gzip）

## 字型子集化（`tools/subset_font.py`）

1. 掃描下列檔案中的 CJK 字元：
   - `crates/**/*.rs`
   - `crates/sim/data/*.json`（命名字庫，8.3）
   - `crates/app/assets/text/*.json`（事件模板與介面字串，9.6）
2. 加上常用字表（教育部常用字 4,808 字，確保數字與標點）。
3. 以 fontTools 產生 `crates/app/assets/fonts/wenkai_tc_subset.ttf`、`wenkai_sc_subset.ttf`（10.5）。
4. 子集字型提交到版本庫；原始字型不提交。
5. 驗收：子集字型 ≤ 3.5 MB。

## 持續整合（GitHub Actions）

| 工作 | 內容 |
|---|---|
| `check` | `cargo fmt --check`、`cargo clippy -D warnings`、`cargo test -p siming-sim` |
| `determinism` | 7.x 的確定性測試（原生）；wasm32 以 wasm-bindgen-test 在 Node 中跑雜湊比對 |
| `build` | 原生 Linux、Windows 建置（含 `steam` feature）；WASM 建置 |
| `l10n` | 繁簡字庫條目數一致；簡體檔與 `t2s.py` 產生結果一致（10.5） |
| `balance` | `siming-cli sim` 跑 3 個種子各 1 運，輸出統計報表為 artifact（不判失敗，只記錄） |
