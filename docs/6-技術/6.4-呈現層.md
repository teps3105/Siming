# 6.4 呈現層

`crates/app`，Bevy 0.16 + bevy_egui 0.34。

## Bevy 功能裁剪

只啟用：
- `bevy_winit`、`bevy_render`、`bevy_core_pipeline`、`bevy_pbr`
- `bevy_asset`、`bevy_window`、`bevy_log`、`bevy_state`
- `multi_threaded`（僅原生）
- `webgl2`（僅 WASM）
- `x11`（僅 Linux；Wayland 桌面與 Steam Deck 經由 XWayland 執行，避免額外的系統依賴）
- `bevy_gilrs`（僅原生；搖桿輸入，5.9）

不啟用音訊、glTF、場景、`bevy_ui`。

## 插件

| 插件 | 職責 |
|---|---|
| `SimPlugin` | 持有 `Sim` 資源；依速度推進；把指令佇列送入模擬；事件轉為 Bevy `Event` |
| `MapPlugin` | 地形網格、地圖材質（自訂 `Material`，WGSL）、貼圖更新、場域烘焙（`field_bake.rs`：依模式選 `FieldId` → 投影、暈染 → `field` 貼圖，6.9）、標籤（egui 螢幕空間繪製） |
| `ObjectsPlugin` | 建築、軍隊、劍光的 instancing 與狀態表現 |
| `SpectaclePlugin` | 奇觀佇列與特效（5.6） |
| `InputPlugin` | 動作層 `InputActions`：鍵鼠與搖桿分別寫入；輸入模式切換；準星與吸附（5.9） |
| `CameraPlugin` | 鏡頭與操作（5.2、5.9），只讀 `InputActions` |
| `UiPlugin` | egui 主題、各面板與卡片（5.7、5.8） |
| `StoragePlugin` | 存檔、設定、天書 |

## 模擬驅動

- 每幀預算：
  - 依速度計算本幀應推進的 tick 數 `n`。
  - 呼叫 `step()` 直到完成 `n` 次或用掉 8 ms。
  - 未完成者累積到下一幀，累積上限 60 tick，超過即自動降速並提示。
- 指令：介面產生的 `Command` 先放入佇列，在下一次 `step()` 前以 `apply()` 送入；同時寫入存檔的指令紀錄。
- 背景執行緒（若 100× 跟不上）：
  - `Sim` 放在獨立執行緒。
  - 每 N tick 送出一份輕量的「可視快照」（州郡顏色、物件位置、事件）。
  - 模擬本身仍單執行緒，確定性不受影響。
  - WASM 版不使用此路徑。

## 可視同步

- **州郡顏色**：地圖模式依賴的資料變動時，重算 `province_color` 查表（256 個顏色），上傳 GPU。
- **物件**：以 `PowerId` 或 `ArmyId` 對應 Bevy 實體；模擬端回報新增、移除、狀態變化，只更新髒的實體。
- **軍隊位置**：每幀依 `progress` 內插。

## 地圖材質

- 以 Bevy `Material` 加自訂 WGSL 實作 5.3 的著色流程。
- uniform：
  - 地圖模式
  - 高度縮放
  - 古地圖化權重
  - 因果模式權重
  - 選取的州郡
  - 時間（給雲紋與流動光點）
  - `field_ramp`：連續場的兩端點色與五階門檻（墨分五色，5.4）
  - `field_blend`：`field_prev` → `field` 的淡入淡出權重
- 貼圖綁定：`province_id`、`province_color`、`field`、`field_prev`、`paper`、`stroke`、`cloud`。

## 地理細格（決策 #35）

模擬輸出兩層格點：遊戲格 `World::geo`（州郡、靈脈、場域）與細格 `World::fine`（`FineGeography`，每軸 2 倍）。渲染以細格為準：

- `fine.scale`（= 2；0 表示開發用的手工世界，無細格，退回 `geo`）、`fine.w`、`fine.h`；細格 `(X, Y)` 屬遊戲格 `(X / scale, Y / scale)`。
- `fine.height`（u16，0..65535 ↔ 0..1，填窪後）：高度圖貼圖、山體陰影（光自西北）、海岸線（與 `fine.sea_level` 比較）、海深。
- `fine.terrain`：生態區底色；`fine.temperature`、`fine.moisture`（u8）：生態區之間的漸層（依溫度×濕度混色，不用硬邊）。
- `fine.river`（等級）、`fine.flow`（流量對數刻度 0..255）：墨線河流，線寬依 `flow`。
- 州郡、靈脈、節點、治所仍以遊戲格座標；格心換算為細格 `(x·scale + scale/2, y·scale + scale/2)`。
- 細格陣列只讀；`siming-cli gen --layer atlas` 為同一契約的參考實作（`crates/cli/src/render.rs`）。

## 選取

- 由鏡頭射線與地形高度圖求交，得到格點 → 州郡。
- 建築、軍隊以螢幕空間距離挑選，優先於州郡。
