# 9.1 素材總覽與規範

## 原則

1. **程序生成優先**：貼圖、模型、特效、圖示都以程式產生；只有字型與文字資料是檔案。
2. **單一來源**：每項素材只有一個產生來源（程式或檔案），在本章登記。
3. **可重現**：程序素材使用固定種子；同版本產生的結果位元相同。程序素材與世界種子無關。
4. **授權清楚**：外部素材只用 OFL、CC0、MIT、Apache-2.0；全部登記於 [9.10 授權清單](9.10-授權清單.md)。
5. **體積**：WASM 版素材總量 ≤ 5 MB（壓縮前）。

## 目錄

```
crates/sim/data/            文字資料：命名字庫（9.6）
crates/app/assets/
  fonts/                    子集字型（9.2）
  shaders/                  WGSL（9.4）
  text/                     介面與事件模板（9.6）
crates/app/src/procgen/     程序素材產生器：貼圖、模型、特效、圖示
tools/                      字型子集化等建置工具
```

## 命名

- 檔名用小寫英文與底線，例如 `terrain_ink.wgsl`、`wenkai_subset.ttf`。
- 程序素材以產生函式命名，例如 `procgen::texture::paper()`、`procgen::mesh::pagoda(levels)`。
