# 5.5 地圖物件

全部程序生成的低多邊形模型，以 `MultiMeshInstance3D` 批次繪製。尺寸以「格」為單位。

| 物件 | 外觀 | 尺寸 | 顯示距離 |
|---|---|---|---|
| 城池 | 城牆方框 + 城樓；依城池等級 0–4 增加城門與樓層 | 0.6–2.0 | 等級 ≥ 3 全程顯示；其餘在中景 |
| 都城 | 城池 + 王朝旗 | 2.4 | 全程 |
| 山門 | 牌坊 + 三重殿 + 山徑；正道白牆黛瓦，邪道黑瓦 | 1.2 | 中景 |
| 寺塔 | 多層佛塔（層數 = 3 + 住持果位） | 1.0 | 中景 |
| 書院 | 二進院落 + 書樓 | 0.9 | 近景 |
| 魔窟 | 黑色裂谷 + 業氣煙柱 | 1.2 | 中景 |
| 妖穴 | 族類圖騰柱（狐、虎、蛇、狼、蛟） | 0.8 | 中景 |
| 洞天福地 | 浮空雲氣 + 光點；依等級大小 | 0.8–1.6 | 靈脈模式全程；其餘中景 |
| 軍隊 | 旗幟（王朝色）+ 3–7 個兵俑（依兵力對數） | 0.8 | 全程（拉遠時以旗幟符號代替） |
| 修士 | 劍光：亮線 + 拖尾；境界越高越長 | — | 中景以內；金丹以上的修士遊歷換州、赴爭脈之戰時（3.5） |
| 有名之人 | 不常駐顯示；選取或關注時在所在處顯示一個人形剪影 | 0.4 | 近景 |

## 目前實作

- **山門**：畫在 `hud` 的地圖覆蓋層（與治所、洞天福地標記同層，為螢幕空間的 2D 圖樣，不是 `MultiMeshInstance3D`）。圖樣是牌坊、三重殿與山徑，正道白牆黛瓦、邪道黑瓦。鏡頭高度不高於地圖寬的 0.4 倍時畫出，不高於 0.3 倍時在圖樣下方寫宗門名；圖樣尺寸以像素計並隨介面縮放，不隨鏡頭距離變大小。位置取宗門的山門格（`SimWorld.sects()` 的 `pos`）；只畫還在的宗門，宗門新立或覆滅後隨每次推進更新。山門先於其他地名放置，地名與治所名讓開。平面與星球視角都畫，星球視角背對鏡頭的不畫。
- **劍光**：未做。模擬沒有提供修士的位置與移動資料（橋接只有州郡、宗門、洞天福地與事件），待模擬端有可讀的修士所在與遊歷路徑後再做。
- 寺塔、書院、魔窟、妖穴、軍隊、有名之人：未做。

## 位置

- 建築放在州郡治所，或指定格（山門、寺院）。
- 同一格有多個建築時，以 0.6 格間距環狀排開。
- 軍隊在兩州郡之間移動時，依 `progress` 沿治所連線插值。

## 狀態表現

| 狀態 | 表現 |
|---|---|
| 被圍城 | 城池周圍環形營帳 + 煙 |
| 殘破度 > 0.5 | 城池模型變灰、缺角 |
| 香火 | 寺塔周圍金光環，半徑依 H |
| 正氣 | 書院上方白色光暈 |
| 業氣 > 0.5 | 州郡上空飄散暗紅煙霧貼片（數量依業氣） |
