# 5.13 導演模式

玩家不操作時，鏡頭自己帶到正在發生事情的地方，每一處停得夠久、看得完當事人的演出。本節定義導演怎麼選去處、每個鏡頭停多久、怎麼過場、到位後畫面上有什麼，以及事件對應的棋子動作。預設開啟，設定裡可關。尚未實作，見文末「現況」。

## 導演何時掌鏡

- 設定「導演模式」開啟（預設）且遊戲時間在走時，導演掌鏡。玩家按了暫停，導演停在原地，不解除暫停。
- 玩家拖曳或推動鏡頭、縮放、換視角、點地圖、開任何卡片或天下冊，導演立刻讓出；進行中的過場當場中斷，鏡頭停在玩家手上。
- 鏡頭沒有操作、也沒有開著的卡片滿「閒置接回」秒數（預設 20 秒）後，導演接回。
- 開場運鏡（5.2）、新手指引（5.11）要玩家操作的步驟、權能選目標期間，導演不掌鏡。
- 星球視角下導演照常運作，轉的是星球。

## 去哪裡

以州郡為單位計分。

- **分數**：過去 10 秒（真實時間）內送到畫面的事件，依發生的州郡加總重要度。重要度用事件本身的等級（7.2），不上傳聞的事件不計。
- **大事**：最高重要度等級的事件（渡劫、飛升、宗門覆滅、開國這一級）。大事發生時，該州郡排到最前面。
- **遲滯**：別的州郡分數要高出目前所在州郡的 1.2 倍才換過去，否則留在原地。
- **回訪冷卻**：剛離開的州郡 30 秒內不再選，大事例外。
- **沒有事**：所有州郡分數都是 0 時留在原地，不巡遊。

## 每個鏡頭停多久

停留以真實秒計，從鏡頭到位起算，不含過場；自動放慢期間照樣計時。

| 計時 | 預設 | 意義 |
|---|---|---|
| 最短停留 | 8 秒 | 這段時間內不換鏡頭，大事也要等 |
| 一般停留 | 12 秒 | 滿了才依分數評估要不要換；沒有更值得看的地方就續留 |
| 最長停留 | 30 秒 | 滿了且別處有分數就換，不論遲滯 |

- 正在播的棋子演出沒播完不換，即使最短停留已滿。
- 大事在最短停留滿、且目前的演出播完後插隊。
- 設定「節奏」三檔：慢、標準、快，三個計時各乘 1.5、1、0.7。

## 過場

- 目的地在目前畫面寬度一倍之內：焦點緩起緩停平移，約 1 秒。
- 更遠：先拉高到起點與終點同時入鏡，平移，再落回原本的高度；全程一條連續的曲線，1.5 到 2.5 秒，隨距離增加。
- 到位的高度：看得到棋子的高度（地圖寬的 0.4 倍以下，5.6）；玩家原本就在這個範圍內時維持玩家的高度。
- 設定「減少鏡頭運動」開啟時，一律畫面淡出、換位置、淡入，各 0.3 秒。
- 沿用 `MapCamera` 的平滑與東西無縫（5.2），走較短的那一邊。

## 時間

- 導演對準大事時，把遊戲速度降到一倍速；離開那個鏡頭時恢復降速前的速度。設定「大事自動放慢」可關。
- 放慢期間玩家自己改了速度或按了暫停，就以玩家的為準，導演離開時不再恢復。

## 字卡

鏡頭到位的同時，在畫面下方中央出一行字卡：州郡名加一句事件，用傳聞的句子（5.12），人名、州名、宗門名可點。點了算玩家操作，導演讓出。

- 停留期間當地有分數更高的新事件，換成新的句子；同一句至少顯示 3 秒。
- 離開時字卡淡出。設定「導演字卡」可關。
- 不遮住時間盤、傳聞簽與地圖模式列（5.7）；四種視圖（1280×800、1920×1080 各 100% 與 150%）都不出界，句子過長時依帳冊文字的折行規則折成兩行。

## 棋子演出

事件發生時，當事人以 2D 棋子立在事件所在格上演出（5.6、8.11）。鏡頭高度超過地圖寬的 0.4 倍不畫。

| 事件 | 當事人 | 動作 |
|---|---|---|
| 被殺、冤冤相報 | 動手的人／被殺的人 | `strike`／`fall` |
| 報仇、了結仇怨 | 了結的人／對方 | `strike`／`fall`（對方未死則 `brace`） |
| 壽終、病故 | 亡者 | `fall` |
| 突破 | 本人 | `seal`，成功後 `rise` |
| 渡劫 | 本人 | 天劫奇觀既有的 `brace`、`struck`（5.6） |
| 飛升 | 本人 | `rise` |
| 入魔 | 本人 | `seal`，接 `struck` |
| 拜師、入宗 | 徒／師 | `bow`／`stand` |
| 成婚 | 雙方 | 相對 `bow` |
| 繼位 | 新掌門 | `bow` |
| 報恩、了情、釋怨 | 雙方 | 相對 `bow` |
| 立派、分宗 | 祖師 | `seal` |
| 遊歷 | 本人 | `walk`，朝目的州郡的方向走出事件格 |

- 兩人的演出，兩個棋子面對面站在同一格的兩側。
- 同一格同時有多件事時依重要度排隊，一次演一件；排隊超過 3 件的丟掉重要度最低的。
- 演出不在畫面內、或鏡頭太高時不建立棋子。
- 每件演出回報自己的長度（秒），導演用它判斷「演出播完」；沒有對應動作的事件長度為 0。
- 演出以真實時間播放，不隨遊戲速度加快。

## 設定

設定頁新增一組「導演」：

| 項目 | 預設 | 選項 |
|---|---|---|
| 導演模式 | 開 | 開、關 |
| 節奏 | 標準 | 慢、標準、快 |
| 閒置接回 | 20 秒 | 10、20、40、60 秒 |
| 大事自動放慢 | 開 | 開、關 |
| 導演字卡 | 開 | 開、關 |
| 減少鏡頭運動 | 關 | 開、關 |

另有快捷鍵與搖桿鍵切換導演模式（5.9），切換時在畫面上短暫提示「導演　開／關」。

## 依據

- 模擬遊戲的自動跟拍前例 Dwarf Fortress 的 DFHack `spectate`：預設 10 秒換目標，計時不含暫停，有衝突時加快（<https://docs.dfhack.org/en/stable/docs/tools/spectate.html>）。
- 遲滯：英雄聯盟觀戰鏡頭專利 US8636589B2，新目標的興趣值要高出一定比例（範例 20%）才切（<https://patents.google.com/patent/US8636589B2/en>）。
- 最短停留與插隊的兩層計時：SSCAIT 自動觀戰腳本的 t_min、t_max（<https://ar5iv.arxiv.org/html/1505.00278>）；Unity Cinemachine ClearShot 的 Min Duration（<https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineClearShot.html>）。
- 先拉高再落下的過場：van Wijk & Nuij, Smooth and efficient zooming and panning（<https://vanwijk.win.tue.nl/zoompan.pdf>）。
- 自動鏡頭運動要能關：Xbox Accessibility Guideline 117（<https://devdocs.xbox.com/gaming/accessibility/xbox-accessibility-guidelines/117>）。
- 最短 8 秒、最長 30 秒、閒置接回 20 秒、回訪冷卻 30 秒沒有外部來源，是本作自定的起始值，實機看過再調。

## 驗收

- 開著導演不操作，任兩次換鏡頭的間隔不短於最短停留；十六倍速下也一樣。
- 玩家拖鏡頭後導演停止；閒置滿設定秒數後接回。
- 大事發生後，鏡頭在目前的最短停留滿時切過去，遊戲速度降到一倍；離開時恢復原速。玩家暫停時導演不解除暫停。
- 同一州郡離開後 30 秒內不再被選（大事例外）。
- 設定關閉後鏡頭完全不自動移動；「減少鏡頭運動」開啟後沒有平移與拉高。
- 導演帶到的事件，表中有對應動作的，看得到當事人的棋子把動作演完才換鏡頭。
- 字卡四種視圖不出界，名字點得開對應的卡。
