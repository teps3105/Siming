# 5.9 輸入與平台適配

產品以 **Windows 桌機（鍵鼠）** 與 **Steam Deck（搖桿）** 為主要平台，兩者都原生支援，各自優化，不以一方遷就另一方。

## 原則

1. **動作層**：所有操作都定義為「動作」（例如：平移、縮放、選取、返回、切換地圖模式）。鍵鼠與搖桿分別對應到動作；遊戲邏輯只讀動作，不讀原始按鍵。
2. **輸入模式自動切換**：以最後使用的裝置決定目前的輸入模式。
   - 游標只有一個，由遊戲自己畫，滑鼠與搖桿共用（見「遊戲內游標」）。
   - 鍵鼠模式：按鍵圖像畫鍵帽。
   - 搖桿模式：按鍵圖像畫搖桿按鈕，左下角顯示按鍵提示。
   - 切換即時發生，不需設定。
3. **每個功能兩種都能完成**：任何新介面或新操作，都必須同時定義鍵鼠與搖桿的做法（路線圖的完成定義）。
4. **提示圖示跟著模式**：介面上的按鍵提示依目前輸入模式顯示（鍵盤鍵帽，或搖桿按鈕圖示）。

## 遊戲內游標

- 系統游標在視窗內隱藏，游標由遊戲畫在所有器物之上（`game/modules/hud/code/game_cursor.gd`）。
- 游標的位置取自遊戲收到的滑鼠事件，與點擊、停留判定用的是同一個座標，畫出來的位置和判定的位置不會不同步。滑鼠離開視窗時不畫。
- 圖示依情形更換，由程式繪製，大小隨版面倍率：

  | 情形 | 圖示 | 條件 |
  |---|---|---|
  | 一般 | 墨色箭頭，紙色描邊 | 以下都不是 |
  | 可按 | 朱色箭頭，尖端加一個朱環 | 停在可以按的地方：天時儀的圓盤、狀態字與疾徐四筆，視角鈕，印匣裡已開放的模式印，命簿的關閉與置中 |
  | 拖動地圖 | 四向箭頭 | 左鍵（搖桿 LT）按住並已拖動 |
  | 旋轉鏡頭 | 朱色弧形雙箭頭 | 右鍵或中鍵（搖桿 RT）按住 |

- 熱點在箭頭尖端；拖動與旋轉的圖示以熱點為中心。旋轉、拖動優先於可按。
- 器物以 `is_hot(點)` 回報游標所在的那一點能不能按；新器物照此接上，游標就會跟著變。
- 權能目標選擇時的印章游標（5.2）在 M5 加入。

## 鍵鼠（Windows 桌機）

沿用 5.2，並補充：

| 操作 | 功能 |
|---|---|
| 滑鼠停留 | 州郡、人物、建築的提示（0.3 秒後出現） |
| 右鍵點擊目標 | 情境印環（5.7）：關注、溯因、在因果模式中顯示、鏡頭置中；司命權能（M5） |
| `G` | 星球視角與平面地圖互換（5.2） |
| `Esc` | 有卡片開著時關掉最上層的卡片；沒有時開啟遊戲中選單（9.1） |
| `F7` | 開關導演模式（5.13）：畫面上短暫提示「導演　開」或「導演　關」。F6 留給地圖模式的業氣（5.2） |
| `F12` | 把目前的畫面存成 PNG，放在使用者資料夾的 `screenshots/` |
| `F` | 關注／解除關注目前選取或停留的人物 |
| `X` | 溯因：開啟目前選取人物的最近事件 |
| `Enter` | 原因簽顯示時：飛往該事件 |
| （待定） | 展開／收合傳聞簽的 50 則清單：原本用 `Tab`，改為切速度後待 M2 另訂 |
| `[` `]` | 上一則／下一則傳聞並飛過去 |
| 中鍵拖曳 | 旋轉方位角（右鍵拖曳的替代） |
| 邊緣捲動 | 游標離畫面邊緣 10 px 以內時往那一邊平移；設定頁開關，預設關 |
| Ctrl + 1–9 | 鏡頭書籤：記下目前視角（單獨的數字鍵不佔用，回到書籤用 Alt + 1–9） |
| Alt + 1–9 | 回到對應的鏡頭書籤 |
| 滾輪於卡片上 | 捲動卡片內容，不縮放地圖 |

- 所有按鈕都有鍵盤快捷鍵，並在停留提示中顯示。
- 介面密度以 1920×1080 為基準（5.7）。

## 搖桿（Steam Deck、Xbox 類手把）

以 Steam Deck 的按鍵命名（與 Xbox 手把相同）。

| 按鍵 | 地圖上（無卡片焦點時） | 介面中（卡片或選單有焦點時） |
|---|---|---|
| 左搖桿 | 平移地圖 | 同左 |
| 右搖桿 | 移動遊戲內游標。搖桿當滑鼠用：游標可以移到地圖與任何介面按鈕上 | 同左 |
| A | 自動鎖定：游標吸到離它最近的目標並選取；連按依距離換下一個 | 同左 |
| B | 取消選取、關閉最上層卡片 | 返回、關閉 |
| X | 情境印環：對游標下的目標能做的事（M2 關／溯／因／中；M5 加入權能印）。情境印環實作前，州郡卡開著時 X 為「置中」 | 次要操作（依卡片） |
| Y | 切到下一檔速度並放行：1× → 5× → 10× → 20× → 回到 1× | 同左 |
| LB / RB | 切換地圖模式（上一個／下一個） | 切換卡片分頁 |
| LT / RT | 滑鼠左鍵／右鍵，作用在游標的位置。左鍵：點選、按介面按鈕、按住拖曳平移地圖。右鍵：按住並移動游標旋轉方位角；M2 起對目標按一下開情境印環 | 同左 |
| 十字鍵 | 上下：縮放；左右：旋轉方位角。傳聞與命牌改以游標點選，不佔用十字鍵 | 同左 |
| Start（選單鍵 ☰） | 開啟遊戲中選單（9.1）：時間暫停，關掉後回到原本的行止 | 關閉選單 |
| Select（檢視鍵 ⧉） | 暫停／繼續 | 同左 |
| L3 | 開關地圖標籤 | — |
| Share（Xbox 手把中間偏右的小鍵） | 開關導演模式（5.13）；Steam Deck 沒有此鍵時，到設定頁開關 | 同左 |
| R3 | 星球視角與平面地圖互換（5.2）。原訂的「鏡頭回到選取的目標」由 X 的置中承擔 | 同左 |

### 搖桿的平移與縮放手感

| 項目 | 規格 |
|---|---|
| 死區 | 0.15（徑向） |
| 平移速度 | 與鏡頭高度成正比；推滿時每秒移動畫面寬的 0.8 倍 |
| 加速曲線 | 輸入值平方（細微控制） |
| 縮放速度 | 推滿時每秒縮放 2 倍高度 |
| 平滑 | 與 5.2 相同的臨界阻尼彈簧 |

### 搖桿游標

- 搖桿當滑鼠用（6.10 #49）：右搖桿移動游標，LT 是左鍵，RT 是右鍵。這些輸入轉成滑鼠事件送回輸入分派，地圖與介面都以同一條滑鼠路徑回應，所以介面按鈕的停留、按下回饋與點擊在搖桿上直接生效，不另設焦點導航。
- 游標推滿時每秒移動 1,100 px（以 1080 高的畫面計，其他解析度等比），實際速度再乘輸入量（輕推時慢、好對準）；游標不出畫面。從滑鼠換到搖桿時，游標從滑鼠最後的位置接手；換回滑鼠時回到滑鼠的位置。圖示與滑鼠相同（見「遊戲內游標」）。
- 游標下的州郡即時高亮並顯示停留提示。
- **自動鎖定（A）**：不必把游標對準。按 A，游標吸到畫面上離它最近的目標並選取；目標現在是各州郡的治所，M2 起加入人物、建築與軍隊。連按 A 依距離由近到遠換下一個，全部輪過就從頭再來；動了右搖桿、平移地圖或換了視角，下一次重新從最近的算起。星球視角只鎖定朝向鏡頭那一面的目標。
- 「關注游標下的人物」原本在 Y；Y 改為切速度後，關注改由情境印環的「關」印處理（M2）。

### 觸控（Steam Deck 螢幕）

| 操作 | 功能 |
|---|---|
| 單指點擊 | 選取 |
| 單指拖曳 | 平移 |
| 長按（按住不動 0.5 秒以上） | 顯示該處的提示；放開不選取 |
| 雙指捏合 | 縮放，以兩指中點為中心 |
| 雙指旋轉 | 旋轉方位角（±45°），地圖跟著手指轉 |
| 介面元件點擊 | 等同 A |

- 單指的點與拖由引擎轉成滑鼠事件，與滑鼠走同一條路；雙指與長按另外處理。
- 第二指落下後，到手指全部離開螢幕為止，放開都不算點選。

## 按鍵提示圖示

- 鍵的名稱由動作層的綁定表推得（`InputHints`），不另列對照表；改綁定，圖像跟著變。
- 最後一次輸入來自搖桿就畫搖桿的鍵，來自鍵鼠就畫鍵帽；器物隨即重畫。
- 由程式繪製（8.8）：
  - 搖桿：圓形 A／B／X／Y；肩鍵、扳機、R3、Start、Select 是寫著鍵名的深色膠囊；右搖桿是搖桿帽的圓形圖標，帽上寫 R；十字鍵是十字形圖標，要按的兩臂（上下或左右）是亮的。
  - 鍵盤：鍵帽圖示，內含按鍵名稱。
- 搖桿圖示的配色依 Xbox 慣例（A 綠、B 紅、X 藍、Y 黃），取 5.1 色票內相近的顏色（forest、seal-red、cyan、gold）。
- PlayStation 手把的圖示在正式版另議。

## 技術

- 搖桿輸入使用 Godot 內建的 `Input` 手把支援（6.4）。Steam 用戶端會以 Steam Input 把 Steam Deck 映射為 Xbox 類手把。
- Steam Input API 的進階整合（動作集、Steam 內建的按鍵設定介面）在正式版另議（9.2）。
- 動作層是 Godot 的 `InputMap`：鍵鼠與搖桿各自綁到同一組動作，其他模組只讀動作。
