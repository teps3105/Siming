# 5.9 輸入與平台適配

產品以 **Windows 桌機（鍵鼠）** 與 **Steam Deck（搖桿）** 為主要平台，兩者都原生支援，各自優化，不以一方遷就另一方。

## 原則

1. **動作層**：所有操作都定義為「動作」（例如：平移、縮放、選取、返回、切換地圖模式）。鍵鼠與搖桿分別對應到動作；遊戲邏輯只讀動作，不讀原始按鍵。
2. **輸入模式自動切換**：以最後使用的裝置決定目前的輸入模式。
   - 鍵鼠模式：顯示游標與停留提示，隱藏準星。
   - 搖桿模式：顯示準星與按鍵提示圖示，隱藏游標。
   - 切換即時發生，不需設定。
3. **每個功能兩種都能完成**：任何新介面或新操作，都必須同時定義鍵鼠與搖桿的做法（路線圖的完成定義）。
4. **提示圖示跟著模式**：介面上的按鍵提示依目前輸入模式顯示（鍵盤鍵帽，或搖桿按鈕圖示）。

## 鍵鼠（Windows 桌機）

沿用 5.2，並補充：

| 操作 | 功能 |
|---|---|
| 滑鼠停留 | 州郡、人物、建築的提示（0.3 秒後出現） |
| 右鍵點擊目標 | 情境印環（5.7）：關注、溯因、在因果模式中顯示、鏡頭置中；司命權能（M5） |
| `F` | 關注／解除關注目前選取或停留的人物 |
| `X` | 溯因：開啟目前選取人物的最近事件 |
| `Enter` | 原因簽顯示時：飛往該事件 |
| `Tab` | 展開／收合傳聞簽的 50 則清單 |
| `[` `]` | 上一則／下一則傳聞並飛過去 |
| 中鍵拖曳 | 旋轉方位角（右鍵拖曳的替代） |
| 邊緣捲動 | 游標靠近畫面邊緣時平移（設定可關） |
| Ctrl + 1–9 | 鏡頭書籤：記下目前視角（單獨的 1–4 是速度鍵，5.2，故回到書籤用 Alt + 1–9） |
| Alt + 1–9 | 回到對應的鏡頭書籤 |
| 滾輪於卡片上 | 捲動卡片內容，不縮放地圖 |

- 所有按鈕都有鍵盤快捷鍵，並在停留提示中顯示。
- 介面密度以 1920×1080 為基準（5.7）。

## 搖桿（Steam Deck、Xbox 類手把）

以 Steam Deck 的按鍵命名（與 Xbox 手把相同）。

| 按鍵 | 地圖上（無卡片焦點時） | 介面中（卡片或選單有焦點時） |
|---|---|---|
| 左搖桿 | 平移地圖；準星固定在畫面中央 | 移動焦點 |
| 右搖桿 | 上下：縮放；左右：旋轉方位角 | 捲動卡片內容 |
| A | 選取準星下的目標 | 確認、按下按鈕 |
| B | 取消選取、關閉最上層卡片 | 返回、關閉 |
| X | 情境印環：對準星下的目標能做的事（M2 關／溯／因／中；M5 加入權能印）。情境印環實作前，州郡卡開著時 X 為「置中」 | 次要操作（依卡片） |
| Y | 關注準星下的人物 | 切換分頁（依卡片） |
| LB / RB | 切換地圖模式（上一個／下一個） | 切換卡片分頁 |
| LT / RT | 速度減慢／加快（暫停 ↔ 1× ↔ 5× ↔ 20× ↔ 100×） | 同左 |
| 十字鍵 | 左右：上一則／下一則傳聞並飛過去；上：進入命牌列（再按一次展開傳聞清單）；下：關閉清單 | 移動焦點 |
| 選單鍵（☰） | 暫停／繼續 | 同左 |
| 檢視鍵（⧉） | 開啟總覽選單：傳聞、輪迴台、天書、設定 | 同左 |
| L3 | 開關地圖標籤 | — |
| R3 | 鏡頭回到選取的目標 | — |

### 準星與吸附

- 搖桿模式下，畫面中央顯示準星（朱紅小圈）。
- 準星下的目標自動高亮。目標優先序與 5.2 相同：人物 > 建築 > 軍隊 > 州郡。
- **吸附**：準星半徑 48 px 內若有人物、建築或軍隊，準星吸附到最近者；左搖桿移動超過吸附範圍才脫離。
- 吸附半徑依介面縮放調整。

### 搖桿的平移與縮放手感

| 項目 | 規格 |
|---|---|
| 死區 | 0.15（徑向） |
| 平移速度 | 與鏡頭高度成正比；推滿時每秒移動畫面寬的 0.8 倍 |
| 加速曲線 | 輸入值平方（細微控制） |
| 縮放速度 | 推滿時每秒縮放 2 倍高度 |
| 平滑 | 與 5.2 相同的臨界阻尼彈簧 |

### 介面焦點導航

- 所有可互動元件都可以用十字鍵或左搖桿移動焦點。焦點以朱描（毛筆描邊）顯示（5.7）。
- 打開卡片時，焦點自動落在卡片的第一個可互動元件；關閉後回到地圖。
- 清單（傳聞、生平、宿緣）支援 LB／RB 翻頁。

### 觸控（Steam Deck 螢幕）

| 操作 | 功能 |
|---|---|
| 單指點擊 | 選取 |
| 單指拖曳 | 平移 |
| 長按（按住不動 0.5 秒以上） | 顯示該處的提示；放開不選取 |
| 雙指捏合 | 縮放，以兩指中點為中心 |
| 雙指旋轉 | 旋轉方位角（±45°），地圖跟著手指轉 |
| 介面元件點擊 | 等同 A |

- 單指的點與拖由引擎轉成滑鼠事件，與滑鼠走同一條路；雙指與長按另外處理。
- 第二指落下後，到手指全部離開螢幕為止，放開都不算點選。

## Steam Deck 版面（1280×800）

| 項目 | 規格 |
|---|---|
| 偵測 | 視窗解析度 ≤ 1280×800，或 Steam 回報在 Steam Deck 上執行（9.2）時，預設使用 Deck 版面；設定可手動切換 |
| 字級 | 內文最小 16 px（800p 下約 9 pt 以上，符合 Steam Deck 可讀性要求） |
| 天時儀與題簽 | 左上角，直徑 64 px（桌機尺寸的 8/7 倍，其他器物同）；只顯示日期、速度、天機、天道之秤（5.7；不再有整行頂欄） |
| 印匣 | 右下角，每印 43 px，左右帶 LB／RB 提示（不再有整行底欄） |
| 權能 | 併入情境印環（X 開啟；M5 加入權能印） |
| 卡片 | 右側半屏抽屜（命簿卷軸形式，5.8），寬 45%；B 關閉 |
| 傳聞簽 | 預設收合為右上角的一張（最新一則）；十字鍵 △ 兩次開啟全屏清單 |
| 命牌 | 左緣，寬 200 px；十字鍵 △ 進入，上下選、A 飛往、Y 解除關注 |
| 按鍵提示 | 畫面右下角常駐 2–3 個當下可用操作（例如「A 選取 B 返回」） |

## 按鍵提示圖示

- 由程式繪製（8.8）：
  - 搖桿：圓形 A／B／X／Y、肩鍵、扳機、十字鍵、搖桿圖示。
  - 鍵盤：鍵帽圖示，內含按鍵名稱。
- 搖桿圖示的配色依 Xbox 慣例（A 綠、B 紅、X 藍、Y 黃），但降低彩度以配合水墨風格。
- PlayStation 手把的圖示在正式版另議。

## 技術

- 搖桿輸入使用 Godot 內建的 `Input` 手把支援（6.4）。Steam 用戶端會以 Steam Input 把 Steam Deck 映射為 Xbox 類手把。
- Steam Input API 的進階整合（動作集、Steam 內建的按鍵設定介面）在正式版另議（9.2）。
- 動作層是 Godot 的 `InputMap`：鍵鼠與搖桿各自綁到同一組動作，其他模組只讀動作。
