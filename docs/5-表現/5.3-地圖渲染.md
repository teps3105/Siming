# 5.3 地圖渲染

## 地形網格

- 來源：世界生成的 `height`，以 2×2 雙線性超取樣，得到 512×320（中尺寸）的頂點。
- 網格：單一網格（中尺寸約 16 萬頂點）。只有在 6.8 效能預算無法達成時，才改為 64×64 頂點分塊、3 級 LOD、接縫以裙邊遮蓋。
- 高度縮放：陸地 `(h − sea) × 地圖寬 × 0.04 × 高度縮放`；海面固定在 0。
- 頂點屬性：位置、法線、地形代碼（u8）、河流等級（u8）。

## 東西無縫與星球視角

- **平面地圖**：地形網格在 x 方向重複繪製（目前視野所需的副本，通常 2–3 份），使東西邊界無縫。所有物件、標籤、因果線都以「離鏡頭最近的副本」位置繪製。
- **星球視角**：以同一組世界貼圖貼在球體網格上（等距長方投影的 UV），以相同的水墨著色器著色；高度以法線方向的小幅位移表現。
- **過渡**：平面與球面之間以頂點內插（平面座標 ↔ 球面座標）漸變，時間 0.6 秒。

### 球面空間規則與極區

**規則：星球上所有程序紋理一律在 3D 球面座標求值，絕不在 UV 求值。** 等距圓柱投影的 UV 在極點收斂（整列紋素擠成一點），UV 空間的雜訊、紙紋、筆觸、扭曲在極點會捲成漩渦。

- **座標**：著色器由頂點的經緯算出單位球方向（內插後正規化），乘以「赤道半徑」得到 3D 位置，單位為赤道一格。平面狀態改用同半徑的圓柱面（東西週期、無極點）；過渡權重在兩者間內插，過渡時不跳變。
- **紙紋、筆觸**：以三平面（triplanar）取樣平鋪貼圖，權重取方向分量的四次方。**雲紋與取樣扭曲**：3D 值雜訊。扭曲的東西向位移依 `1/cos(緯度)`（下限 0.3）放大，使球面上的實際位移各向同性。
- **資料貼圖**（州郡、地形、場）仍以 UV 查表，因為它們是資料不是紋理。邊界偵測的偏移取螢幕空間導數，故線寬在球面上各向同性；東西接縫兩側的 UV 導數取週期內最短差，接縫不出現假邊界線。
- **極區**：|緯度| ≤ 72° 為正常地圖；72°–84° 漸變，84° 以上為統一的「極冰」——紙色略偏水色、紙紋與低頻雲紋，不畫州郡邊界、海岸線、河流、墨線與高亮（這些在極點收斂處會形成星芒）。頂點高度同步壓平為 0，避免極點列各頂點高度不同而拉出尖刺。
- **星球不套用平面的邊緣淡出**（否則極點出現亮斑）；極區由極冰接手。
- **極地邊疆（平面視角）**：地圖南北緣之外再鋪一條寬約 `0.08 × 地圖寬` 的高度 0 網格帶，著色為向外延伸的極冰，在 `0.05 × 地圖寬` 內漸漸淡成紙色（與清除色相同）。鏡頭焦點的列座標另受「畫面頂／底緣視線與地面交點不得超出南北緣 `0.05 × 地圖寬`」的限制（`focus_row_limits`）：縮得越遠、俯角越低，可看的緯度越靠近赤道；星球視角不受限。因此平面視角永遠不會露出大片空白。開場運鏡的終點取「形心在南北緯 ±60° 內、面積最大的大洲」。
- **標籤**：與墨線同一條極區淡出（|緯度| 62°–78°，smoothstep）；alpha < 0.08 的標籤不畫。
- **河流下游**：複製模擬的 D8 最陡下降（`geo.height` 為填窪後高度，坡度以球面步長計），具名幹流以其格序為準；只連到河格或水格，並略過不足 4 格的孤立非具名河段，避免沿岸梳齒狀短刺。
- **網格**：極點列的三角形在球面上退化為零面積，不產生片元；極點附近的細長三角形不依賴頂點 UV，而是內插「由經緯算出的單位方向」，所以極點、接縫連續。

### 區域邊界平滑（去鋸齒）

格點資料天生是階梯狀；所有「區域邊界」（地形類別、海岸與湖、州郡邊界、河流）都不得讓玩家看到格點階梯，在任何縮放、平面與星球上都應是有機的墨線。做法（參照 8.4 §3.7：等值線、海岸暈染、變寬河線）：

- **地形類別**：不再逐格最近鄰查表。CPU 把「最近陸地格的地形」拆成各類別的遮罩，先做一次 3×3 二項式模糊，存成兩張格點解析度、可線性取樣的 RGBA8 貼圖（共 7 類權重；東西環繞）。著色器以扭曲後的座標雙線性取樣，把權重（乘上 3D 雜訊起伏）取 1.8 次方再正規化，各類顏色按權重連續混合；生態交界不加墨暈（見「水深與陸地連續性」）。扭曲噪聲在 3D 球面空間（見上節），邊緣因此不貼著格線。
- **海岸與湖**：陸／水有號場先與 3×3 二項式模糊各取一半，再以二次 B 樣條取樣成 4× 格的貼圖（模糊與內插合一，等值線 C1 連續）；著色器在 0.5 處取等值線並以 `fwidth` 抗鋸齒。單格湖縮小但不消失。
- **州郡邊界**：州郡 ID 貼圖維持格點解析度（海／湖格向外擴 2 格，避免海岸處露出未著色細縫）。著色器逐像素以二次 B 樣條權重（支撐 3 格）對附近 3×3 格的州郡投票，最高者為該像素的州郡；第一、二名的權重差 `m` 在州界上為 0、約每格 1.5 單位線性增加，故到界的像素距離 ≈ `m / (1.5·每像素格數)`，以此畫出子像素精度、抗鋸齒的墨線（州界 1 px、國界 2 px、國界外暈 6 px）。這是各州郡指示函數模糊後的等值線，階梯被磨成圓順曲線，且與縮放無關；取樣座標先經 3D 雜訊扭曲，邊界蜿蜒。選取與滑鼠選取仍以格點為準。
- **河流**：不再把相鄰河格連成 8 鄰直線。依高度推出每個河格的下游格，每段河以「經過上、下游中點、以本格為控制點」的二次貝茲曲線（等價 Chaikin 平滑）取樣成膠囊段，寫入「到河緣的有號距離」場（紋素單位，內正外負，夾在 ±2；G 通道，可線性取樣）；半徑依等級（0.5／0.75／1.05 紋素）、源頭收細（×0.6），交匯處自然匯合。著色器以 `fwidth` 換算像素：外緣至少 0.8 px、內側約 1 px 為 ink-light 外緣、其內填水色，遠景不斷線、近景不方塊。
- **山脊與山影**：網格頂點法線以 ±0.75 格的寬模板求中央差；曲線（山脊線依據）由 CPU 逐頂點算好（高度場 Hessian 範數）存入第二組 UV，著色器直接取用，不在著色器對內插梯度取 `fwidth`（後者在每個三角形內為常數，呈方塊狀）。山影為西北光、墨色漸層，隨高度縮放降為 0（既有）。
- **高解析輸入**：以上平滑都由「格點大小的資料 + 取樣函數」完成；世界生成若提供更高解析度的高度場或河流折線（6.4 的 `Geography` 擴充欄位），建構貼圖時改用該資料取代格點（遮罩、有號場與河流距離場的解析度跟著提高），否則退回模擬格點。
- 預算（6.8）：平滑的貼圖在載入／移山時由 CPU 一次完成；每像素的額外成本是州郡投票的 9 次 `textureLoad` 與 2 張格點大小貼圖的取樣，並移除不再使用的雲紋貼圖（雲紋改為 3D 雜訊）。

### 水深與陸地連續性

- **水深（海深色階）**：CPU 以 `(海平面 − 高度) / 海平面` 為每個海格的正規化深度，湖格取 `0.35·離岸距離/4`；先 3×3 二項式模糊，再以二次 B 樣條取樣成 4× 格的貼圖 B 通道（與海岸同一做法，無階梯；著色器再加 ±0.5/255 的像素抖動消除 8 位元緩坡色帶）。深度越有意義（棚、坡、淵、海脊、海溝），畫面自動越豐富——世界生成端把海平面以下的高度場做成這些地貌即可，不需改渲染。
- **陸地連續性（反斑塊）**：生態權重乘上 3D 雜訊起伏（零權重維持零）後取 1.8 次方，過渡帶寬而柔、邊緣不規則；**生態之間不加墨暈**（墨線只留給海岸、州界、河流）。色彩再受**高度連續色階**調製（低地 → 丘陵 → 山地漸變，非離散灰塊）與**大尺度 3D 色彩起伏**（冷暖、明度兩軸緩漂），平原不再是平塗。山影改為色相保持的冷暖染色。

## 貼圖

| 貼圖 | 大小（中尺寸） | 內容 | 更新時機 |
|---|---|---|---|
| `province_id` | 格點大小（如 384×192），R16Uint | 每格州郡 ID（海／湖格向外擴 2 格）；邊界由著色器 B 樣條投票平滑 | 移山時 |
| `province_color` | 256×1，RGBA8 | 州郡 ID → 目前地圖模式的顏色 | 每月或切換模式時 |
| `field` | 1024×640，R8 | 地圖模式的連續場（2.7 的一個 `FieldId`）：格域場直接取樣、州域場投影後暈染（6.9 烘焙） | 切換模式時；州域場每季（速度 ≥ 20× 時每年） |
| `field_prev` | 1024×640，R8 | 切換模式前的連續場，供 0.4 秒淡入淡出 | 切換模式時交換 |
| `paper` | 512×512，平鋪 | 紙紋 | 生成一次（程序雜訊） |
| `stroke` | 256×256，平鋪 | 皴法筆觸雜訊 | 生成一次 |
| `cls_a`、`cls_b` | 格點大小，RGBA8，可線性取樣 | 地形類別權重（平原、丘陵、山脈、森林｜雪原、沙漠、沼澤），已 3×3 模糊 | 移山時 |

## 水墨著色器（地形）

依序合成：
1. **底色**：地形色（5.1 色票）× 紙紋。
2. **上墨**：
   - 坡度 > 0.35 或高度位於上 30%：疊 ink 色。
   - 強度 `smoothstep` × 皴法筆觸雜訊，做出山石皴擦。
3. **山脊線**：法線變化大處描 ink 細線。
4. **水**：
   - 海、湖：water 色，近岸處淡、遠岸處深。
   - 海岸線：描 ink-light 雙線。
   - 河流：依等級寬 1–3 像素，water 色加 ink-light 邊。
5. **地圖模式疊色**：`province_color[province_id]` 以 0.45 不透明度乘色（山河模式為 0）；連續場模式另以 `field_ramp`（墨分五色，5.4）把 `field` 量化為五階墨色疊上；著色器不知道場是什麼（6.9）。
6. **邊界**：
   - 取相鄰 4 個像素的 `province_id`，不同即描邊。
   - 州郡邊界：ink-light，1 px。
   - 國界：依 `province_color` 判斷所屬不同時，改 ink 色、2 px，外側加淡色暈。
7. **霧**：依距離混入 paper 色。
8. **古地圖化**：高度縮放 < 0.3 時，步驟 2–3 的權重漸減為 0，改為平塗。

## 文字標籤

- 以 egui 在螢幕空間繪製：把標籤的世界座標投影到螢幕，再以 egui 的繪圖 API 寫字（ink 色加 paper 描邊）。不使用 SDF 文字著色器。
- 國號：疆域重心處，大字，依疆域外接框縮放，字距拉開。
- 州郡名：鏡頭 `z < 地圖寬 × 0.3` 時顯示，放在治所旁。
- 江河、山脈、洞天：中景顯示，沿河道或山脊排列。
- 標籤互相避讓（貪婪擺放，依重要度排序）。

## 因果模式後處理

- 整體轉為墨色調：亮度 × 0.35，彩度 × 0.2。
- 只保留：魂光（有名之人位置的發光點）、因果線、勢力據點輪廓。
