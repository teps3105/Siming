# 5.2 鏡頭與操作

玩家以一顆可平移、縮放、旋轉的鏡頭俯瞰世界，平面地圖與星球兩種視角可以隨時互換。本節定義鏡頭的範圍與行為，以及鍵鼠與觸控的操作對應。

## 鏡頭

- **投影**：正交投影（`MapCamera`，`PROJECTION_ORTHOGONAL`）。
- **高度**：鏡頭離地高度 `z`，範圍 `[z_min, z_max]` = [地圖寬 × 0.04, 地圖寬 × 1.1]。
- **俯角**：固定 60°（`MapView.PITCH_DEG`），不隨高度變。
- **古地圖化**：`z > 地圖寬 × 0.6` 時，地形高度縮放由 1 漸變到 0.05，著色改為平塗（5.3）。
- **東西無縫**：星球地圖東西相接，鏡頭可無限向東或向西平移（2.2）。
- **南北限制**：鏡頭焦點限制在南北緯 75° 之間，避免看到極區的投影變形。導播對準極區事件（5.13）期間例外：焦點列放寬到超出南北緣各 8 列，事件格才置得了中；畫面外側超出地圖南北緣的部分延續邊緣那一列的地面或海的顏色，約 1 格內柔和淡成紙色，沒有硬線。玩家一操作或導播中斷，焦點即恢復上述限制，玩家可拉動的範圍不變。星球視角不放寬。
- **星球視角**：平面地圖與星球是同一個世界的兩種看法，以視角鈕（5.7）、`G` 或搖桿 R3 互換，任何高度都能換；縮放不會換視角。
  - 兩種視角的高度範圍相同。星球視角下 `z` 是鏡頭到球面的距離：拉遠看到整顆星球，拉近到 `z_min` 時球面佔滿畫面，像把地球儀湊到眼前。
  - 星球視角下平移改為旋轉星球；同樣的拖曳距離在高緯跨過較多經度（除以 `max(cos 緯度, 0.25)`）。
  - 換視角時焦點與高度不變，畫面在 0.6 秒內過渡（5.3）。
  - 呼應司命俯瞰眾生的身分；也是開局的第一個畫面（4.1：霧中浮現星球，鏡頭推近到山門）。
- **平滑**：所有移動以臨界阻尼彈簧平滑，時間常數 0.12 秒。
- **導播過場**：導播模式（5.13）掌鏡時，`MapCamera.direct_to` 把焦點帶到目的地：一個畫面寬以內緩起緩停平移約 1 秒；更遠先拉高到起點與終點同時入鏡、平移、再落回，全程一條連續的曲線，1.5 到 2.5 秒；焦點走東西較短的那一邊。拖曳、推動、縮放、旋轉、換視角、點選、`look_at_map` 都發 `player_acted` 訊號並中斷過場，導播聽它讓出。
- **開場運鏡**：開局的第一個畫面是整顆星球（`z = z_max`），正對形心在南北緯 60° 內、面積最大的大洲；鏡頭在 3.5 秒內降到 `z = 地圖寬 × 0.3`，焦點不動；高度降到 `地圖寬 × 0.9` 以下時由星球攤平成平面地圖。高度取對數內插、兩端緩起緩停。期間按下任何鍵、滑鼠鍵、搖桿鍵或螢幕，直接到位。

## 操作（桌面）

| 操作 | 功能 |
|---|---|
| 左鍵拖曳、WASD、方向鍵 | 平移 |
| 滾輪 | 縮放：平面地圖以游標為中心，星球視角以畫面中心為準 |
| `G`、視角鈕 | 星球視角與平面地圖互換 |
| 右鍵拖曳 | 旋轉方位角（±45°，放開後不回彈） |
| 左鍵點擊 | 選取：人物 > 建築 > 軍隊 > 州郡 |
| 滑鼠停留 | 州郡名與簡要提示 |
| 空白鍵 | 暫停／繼續 |
| Tab | 切到下一檔速度並放行：1× → 5× → 10× → 20× → 回到 1× |
| B | 展開／收合天下冊（全螢幕的統計圖紙，[5.10](5.10-天下冊.md)）；展開時左右鍵換頁，Esc 收合 |
| F1–F6 | 地圖模式：山河、天下、三教、靈脈、因果、業氣 |
| （待定） | 開關傳聞欄：原本用 Tab，Tab 改為切速度後，M2 做傳聞簽時另訂鍵位 |
| Esc | 關閉卡片；取消權能的目標選擇 |
| C | 卡片開著時，把鏡頭移到卡片主體所在地 |
| F7 | 開關導播模式（[5.13](5.13-導播模式.md)） |
| F12 | 除錯面板 |

## 權能的目標選擇

1. 在權能列選擇權能 → 游標變為印章。
2. 合法目標高亮，非法目標變暗。
3. 依權能顯示範圍預覽：半徑圈、靈脈路徑、兩魂間的預覽線。
4. 點擊目標 → 確認框（顯示天機花費與預估天道業障）→ 落印。
