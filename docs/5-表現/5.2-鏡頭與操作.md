# 5.2 鏡頭與操作

玩家以一顆可平移、縮放、旋轉的鏡頭俯瞰世界，拉到最遠時地圖變成一顆星球。本節定義鏡頭的範圍與行為，以及鍵鼠與觸控的操作對應。

## 鏡頭

- **投影**：透視投影，垂直視角 30°。
- **高度**：鏡頭離地高度 `z`，範圍 `[z_min, z_max]` = [地圖寬 × 0.04, 地圖寬 × 1.1]。
- **俯角**：隨高度內插，`z_min` 時 68°，`z_max` 時 88°。全程接近正俯視：這是一張地圖，斜看會讓山體壓住後方的地面，也讓浮雕暈渲失真。
- **古地圖化**：`z > 地圖寬 × 0.6` 時，地形高度縮放由 1 漸變到 0.05，著色改為平塗（5.3）。
- **東西無縫**：星球地圖東西相接，鏡頭可無限向東或向西平移（2.2）。
- **南北限制**：鏡頭焦點限制在南北緯 75° 之間，避免看到極區的投影變形。
- **星球視角**：鏡頭拉到最遠（`z > 地圖寬 × 0.9`）時，畫面漸變為一顆可旋轉的星球，地圖貼在球面上。
  - 再往外拉只會縮小星球，不再移動。
  - 在星球視角下平移改為旋轉星球；往內推回時，回到焦點所在的平面地圖。
  - 呼應司命俯瞰眾生的身分；也是開局的第一個畫面（4.1：霧中浮現星球，鏡頭推近到山門）。
- **平滑**：所有移動以臨界阻尼彈簧平滑，時間常數 0.12 秒。

## 操作（桌面）

| 操作 | 功能 |
|---|---|
| 左鍵拖曳、WASD、方向鍵 | 平移 |
| 滾輪 | 縮放（以游標為中心） |
| 右鍵拖曳 | 旋轉方位角（±45°，放開後不回彈） |
| 左鍵點擊 | 選取：人物 > 建築 > 軍隊 > 州郡 |
| 滑鼠停留 | 州郡名與簡要提示 |
| 空白鍵 | 暫停／繼續 |
| 1–4 | 速度 1×、5×、20×、100× |
| F1–F6 | 地圖模式：山河、天下、三教、靈脈、因果、業氣 |
| Tab | 開關傳聞欄 |
| Esc | 關閉卡片；取消權能的目標選擇 |
| C | 卡片開著時，把鏡頭移到卡片主體所在地 |
| F12 | 除錯面板 |

## 權能的目標選擇

1. 在權能列選擇權能 → 游標變為印章。
2. 合法目標高亮，非法目標變暗。
3. 依權能顯示範圍預覽：半徑圈、靈脈路徑、兩魂間的預覽線。
4. 點擊目標 → 確認框（顯示天機花費與預估天道業障）→ 落印。
