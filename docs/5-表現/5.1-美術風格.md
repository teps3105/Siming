# 5.1 美術風格

全作採水墨設色的古地圖風格，素材以程式產生。本節定義美術方向、色票、山河設色的規則與無障礙要求，所有畫面與著色器的顏色以此為準。

## 方向

- **水墨設色**：紙本底色、墨色山脈、淡彩疆域、金線因果。
- **拉遠**：如一張古地圖（CK3 的政治地圖），疆域淡彩平塗、州郡細線描邊、大字標出國號。
- **拉近**：2.5D 山體起伏，城池、山門、寺塔以小型立體模型呈現，修士化作劍光飛行。
- **全程序生成**：不依賴手繪美術資源。

### 地形圖設色（預設地圖模式）

**主調：暈渲地形圖，印在紙上。** 地圖要看起來像實景地形再畫成平面圖（5.3），所以設色跟著地形與氣候走，不用色塊區分地類；色彩壓在自然、低彩度的範圍，疆域淡彩與介面才不被搶走。

- **植被底色**（依溫度與濕度連續取色，沒有邊界）：沙漠 `#D9C59A`、乾草原 `#D0CA9C`、草地 `#BAC690`、森林 `#7AA06C`、雨林 `#618D60`、寒林 `#8DA68A`、凍原 `#C3C2AD`、雪 `#F1F0EA`、沼澤 `#8FA287`。模擬判定為森林、沙漠、沼澤、雪原的地方，底色再向該類的顏色靠 45%。
- **高度色階**（疊在植被底色上，隨高度漸入）：丘陵土色 `#C9B58C` → 山地岩色 `#B09C80` → 高山灰 `#A49D97` → 雪 `#F2F1EC`；高度另加 `0.28·sin²(緯度)`，雪線隨緯度降低。陡坡露出岩色。
- **海深五色**（之間線性內插，隨水深連續變化）：`#C9DDD8`（淺棚）→ `#A3C3C4` → `#7BA3B0` → `#567F97` → `#3A5F7A`（深海）。正規化水深經 `1 − exp(−3.2·d)` 映到色階，大陸棚佔較寬的淺色帶。湖取前兩階之間的淺水色。
- **海岸線**：深花青 `#3B5566`，1 像素。
- **浮雕暈渲不變灰**：光自西北上方；陰面乘 `(0.52, 0.58, 0.70)`（偏花青）、陽面乘 `(1.10, 1.07, 0.98)`（偏暖）。
- **地表覆蓋**：冰雪覆蓋用高度色階的雪色 `#F2F1EC`，沙土覆蓋用沙漠色 `#D9C59A`（5.3「地表覆蓋」）；極區沒有另外的極冰色。
- **地圖模式疊色**：疊上淡彩前先把底圖去飽和 40%（乘以該像素的疊色不透明度），淡彩才不混濁。
- **遠景**：距離霧向紙色混合；古地圖化時整體再向紙色靠 22%。
- **地名設色**：不同性質的地名用不同的文字顏色，一律加紙色描邊；山河模式的例簽列出對照。對 paper-light 的對比都在 5.4 以上。

  | 地名 | 色值 | 說明 |
  |---|---|---|
  | 大洲 | `#3C4A52`（silk） | 字最大，用沉的中性色 |
  | 州郡 | `#2B2620`（ink） | 數量最多 |
  | 治所 | `#8C2A1C` | 絳紅；治所的點同色 |
  | 海與湖 | `#2E5D62` | 黛青；洋、海、湖共用 |
  | 江河 | `#3E6379`（water-deep） | 花青 |
  | 山脈 | `#3F5A45` | 黛綠 |
  | 洞天福地 | `#5B3A6B`（violet） | 與凡俗地名區隔 |

- **無障礙**：地類不靠色相區分——山靠暈渲、水靠海岸線、疆域靠州界與標籤。色差以 `python tools/checks/check_palette.py` 量測（CIE76 ΔE；Machado 2009 模擬矩陣，嚴重度 1.0），下列為各組的最小值，依序是一般視覺／紅色盲／綠色盲／藍黃色盲：
  - 陸色對海色：11.1／7.7／9.4／9.3。最接近的一對是雪與最淺的海，兩者之間有海岸線。
  - 海岸線對陸色與淺海兩階的明度差：19.7／19.6／19.7／19.3。
  - 海深相鄰兩階：11.2／10.2／11.3／11.9。
  - 墨對紙的明度差：75.3／75.1／75.4／75.2。
  - 植被底色兩兩：2.5／1.2／0.9／3.0。植被是連續取色，不要求可分辨；地形類別由州郡卡的文字標出。
  - 因果線五色兩兩：42.4／8.4／24.5／12.8。紅色盲下粉（情緣）與青（師徒）只差 8.4、藍黃色盲下金（恩義）與粉只差 12.8，因果線加入時（M2）每種線要另有一個不靠顏色的區別（線型或線上的字印）。

勢力著色：從一組 24 色的淡彩調色盤（彩度 0.25–0.35，明度 0.75–0.85）依勢力 ID 取色，鄰國避免同色。

## 字型

- 霞鶩文楷 TC（LXGW WenKai TC，OFL 授權）。
- 依實際用字子集化（6.6）。
- 地圖大字（國號、地名）以墨色加紙色描邊；介面內文 14–16 px。

## 介面母題

- **司命案頭**（5.7）：介面是司命桌上的器物——天時儀、題簽、印匣、命簿、紙簽。沒有欄、沒有表格框。
- 母題只有四種：**紙**（底）、**墨**（字與筆劃）、**朱**（印與焦點）、**綾**（裱褙邊）；金只用在功德與飛升相關數值。
- **邊框只有一種——絹本裱框**（6.10 #45）：直邊紙面、外圈綾邊（silk）、紙面內緣一道金線、底下一層柔影。紙簽的綾邊寬 3 px，命簿 6 px；圓盤（天時儀）是同一款的圓形。不用不規則的邊緣表現紙質；紙質由紙紋（8.3）承擔。
- 筆劃皆為兩端收細的墨線。按鈕的底為直角：啟用中朱底、可選為紙底綾框、尚未開放為紙底虛線框淡墨。圓鈕用於動作：朱底是收卷，紙底朱圈是其他動作。按鈕上一律是線條圖示加文字，不用單一個字（5.7 原則 7）。
- 紙面上的字只用墨與淡墨；青、金、朱等顏色放在色塊、弧與墨條上（對比見 `tools/checks/check_palette.py`）。
- 動態：墨暈（停留）、壓印（按下）、展卷（開啟）、捲回（關閉）。

## 圖示

- 傳聞與天書的圖示以印章風格繪製：朱紅方印，內有一個字，例如劫、升、殺、緣、佛、聖、朝、魔。
- 由字型與形狀程式生成，不需點陣圖。
