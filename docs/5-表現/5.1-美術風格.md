# 5.1 美術風格

全作採水墨設色的古地圖風格，素材以程式產生。本節定義美術方向、色票、山河設色的規則與無障礙要求，所有畫面與著色器的顏色以此為準。

## 方向

- **水墨設色**：紙本底色、墨色山脈、淡彩疆域、金線因果。
- **拉遠**：如一張古地圖（CK3 的政治地圖），疆域淡彩平塗、州郡細線描邊、大字標出國號。
- **拉近**：2.5D 山體起伏，城池、山門、寺塔以小型立體模型呈現，修士化作劍光飛行。
- **全程序生成**：不依賴手繪美術資源。

### 山河設色（預設地圖模式）

**主調：淺絳山水為底、青綠點染。** 傳統中國山水有三條路：水墨（只用墨的濃淡）、淺絳（赭石淡染，花青點水）、青綠（石青、石綠重彩，如王希孟《千里江山圖》）。策略地圖需要在拉遠時一眼分辨生態，純水墨不夠；純青綠又太飽和、壓過疆域淡彩與介面。因此取**淺絳做大面積底色**（平原、丘陵、沙漠都是赭與黃赭的淡染，貼近絹／紙），**青綠只用在山與水**：森林是石綠，山峰隨高度由赭石過石綠、青綠到石青再到雪，海是花青。「司命俯瞰」的氣質是：暖紙上浮著冷色的山水，印證 5.1 的「紙、墨、朱、綾」。青綠重彩與純水墨留作其他地圖模式或季節變體。

- **海深五階**（墨分五色，階間以 smoothstep 柔和銜接）：`#D3E0D6`（青白，棚）→ `#A8C7C3` → `#7DA4AD` → `#5A8296` → `#3E6379`（深花青）。正規化深度 `(海平面 − 高度) / 海平面` 經 `0.92·d^0.55` 映到色階，使大陸棚佔較寬的淺色帶；棚緣（t = 0.42）一條極淡的 ink-light 等深線。湖以離岸距離（淺緣）取同一色階的淺端。
- **山地高度色階**（連續，非離散山塊）：`#BC9A68`（赭石）→ `#9DAA80`（石綠淺）→ `#7FA39A`（青綠）→ `#8FA6BA`（石青）→ `#EEF0EC`（雪）；高度加上 `0.30·sin²(緯度)` 的偏移，雪線隨緯度降低。
- **明暗不變灰**：陰面乘 `(0.60, 0.69, 0.80)`（偏花青）、陽面乘 `(1.07, 1.03, 0.94)`（偏暖）；山影強度與光向由 uniform 指定（預設西北，燈光層以此為掛鉤，6.4）。
- **無障礙**：生態底色兩兩 CIE76 ΔE ≥ 13（一般視覺），在綠色盲（deuteranopia）／紅色盲（protanopia）／藍黃色盲（tritanopia）模擬（Machado 2009，嚴重度 1.0）下最小 ΔE 分別為 8.6／8.3／9.5；森林與丘陵靠**明度差**（石綠偏暗、赭石偏亮）而非色相區分。
- **地圖模式疊色**：疊上淡彩前先把底圖去飽和 40%（乘以該像素的疊色不透明度），淡彩才不混濁。
- **遠景**：距離霧向紙色混合（明度上升、彩度下降）；古地圖化時地形色再向紙色靠 25%。

勢力著色：從一組 24 色的淡彩調色盤（彩度 0.25–0.35，明度 0.75–0.85）依勢力 ID 取色，鄰國避免同色。

## 字型

- 霞鶩文楷 TC（LXGW WenKai TC，OFL 授權）。
- 依實際用字子集化（6.6）。
- 地圖大字（國號、地名）以墨色加紙色描邊；介面內文 14–16 px。

## 介面母題

- **司命案頭**（5.7）：介面是司命桌上的器物——天時儀、題簽、印匣、命簿、紙簽。沒有欄、沒有表格框。
- 母題只有四種：**紙**（底）、**墨**（字與筆劃）、**朱**（印與焦點）、**綾**（裱褙邊）；金只用在功德與飛升相關數值。
- 筆劃皆為兩端收細的墨線；邊緣為毛邊；方印為圓角方形加飛白缺口。
- 動態：墨暈（停留）、壓印（按下）、展卷（開啟）、捲回（關閉）。

## 圖示

- 傳聞與天書的圖示以印章風格繪製：朱紅方印，內有一個字，例如劫、升、殺、緣、佛、聖、朝、魔。
- 由字型與形狀程式生成，不需點陣圖。
