# 5.12 史書文本

遊戲裡講「誰做了什麼」的文字——人物卡的生平、事件卡的因果鏈、傳聞——一律寫成白話的史書句子：讀的人不必懂遊戲的術語，單看這一句就知道是誰、對誰、做了什麼、為什麼。本節定義人物卡的小傳與年表怎麼寫、每一句需要哪些事實、事實從哪裡來，以及傳聞的類別印用哪些字。資料層（`person_chronicle`）與 Godot 端的小傳、年表、句型庫都已實作，見文末「現況」。

## 寫法的規則

1. **一件事只說一次**。同一個人的生平裡，同一件事不出現兩條。
2. **名字用當時的名字**。前世的事用前世的名字；前世與今生之間要有一句交代轉世。
3. **有方向的事寫出方向**。拜師與收徒、殺與被殺、施恩與受恩，分開寫，不寫成「甲與乙結下某緣」。
4. **事情的結束也要寫**。婚姻怎麼結束（喪偶）、師徒怎麼結束（師亡、離宗）、何時離開宗門，寫得出來才寫開始。
5. **後果要帶前因**。報仇、了結這類句子把前因織進句子裡：寫出這筆緣是哪一世、當時叫什麼名字、因什麼事結下，對方今生的名字與前身的名字都交代；年表的句子同樣完整。同一筆前因在同一段小傳只完整說一次，再提用短句（「再遇封荷蘭轉世之崔李，殺之，此仇至此了結」）。
   - 輩分用詞：上一世稱「前世」，更早的稱「宿世」或「三世之前」並帶那一世的名字（「其宿世張雅」）；同一世的舊事稱「往日」。
   - 不留殘句：不出現「之其人」「其其」；「某某轉世之某」整段替換，不拆開。
   - 年表的句子不含主詞，不寫本人的名字。
6. **不用術語**。不寫「魂判入人道」「赤線漸近」「結下殺業」；寫「死後魂入人道」「將與前世的仇人相遇」「為某某所殺，結下死仇」。
7. **年號寫法**：每個年份都寫紀元時間加世界時間（2.6「日期顯示」）：「咸寧紀元一二三年（12356年）十一月」，不因同一紀元連續出現而省略；小傳裡只寫到年。世界年由 tick 與開局前的年數算出（`ChronicleText._year_text`，小傳與年表的日期字串只在此產生，併入共用日期函式後改呼叫它）。
8. 人名、州名、宗門名可以點，行為與現在相同。
9. **恩怨的取捨**：這一世新結的殺業多於三件時合成一句（「先後斬魔修二十三人，多在中清郡，其中十四人結下死仇」），只有對方境界最高者、報仇或了結者、與本人另有緣分者逐一寫。小傳不寫「將遇」：已有了結的只寫了結，尚未了結的合成恩怨段最後一句現況（至多三個名字，更多只寫數量）；年表照舊逐條。劫雲只在年表，小傳不寫。
10. **段落**：每段（首段除外）約不超過 220 字，超過時去掉最不重要的事；死者的結局單獨成最後一段。

## 人物卡的生平

人物卡的「個人歷程」改成兩段：上面是**小傳**，下面是可展開的**年表**。左邊的紅字標籤拿掉。

### 小傳

一段到五段的連貫文字（已歿者多一段結局），依下列順序，沒有的段落跳過：

| 段 | 內容 | 句型示例 |
|---|---|---|
| 出身 | 姓名、籍貫、現在的身分 | 周道爍，南白州人，靈鷲門弟子。 |
| 前世 | 這個魂上一世是誰、怎麼死的；有帶到這一世的未了之緣就在這裡點出 | 前世為散修南宮意，咸寧紀元九年（12242年）為魔修徐鋒昊所殺，死後魂入人道，同年轉生南白州。 |
| 入道與師門 | 何時入道、入哪一門、拜誰為師；換師、離宗 | 咸寧紀元二五年（12258年）及長，未得入道；咸寧紀元三四年（12267年）入靈鷲門，拜魏恕滄為師。魏恕滄歿後，咸寧紀元一〇二年（12335年）改拜馬融星。 |
| 家室 | 婚姻的開始與結束 | 咸寧紀元三二年（12265年）嫁彭銘；彭銘歿後，咸寧紀元九六年（12329年）再嫁令狐塵真。 |
| 修行 | 各次突破、渡劫、入魔 | 咸寧紀元一〇三年（12336年）築基。 |
| 行跡 | 遊歷、立派、繼位等 | 咸寧紀元一〇九年（12342年）出遊瓊靈州。 |
| 恩怨 | 這一世結下、了結的緣；前世之緣在這一世的下文 | 咸寧紀元一一一年（12344年）五月，遇陳淑於坦陵州，殺之以報前世之仇——其前世南宮意，咸寧紀元九年（12242年）被陳淑的前身徐鋒昊殺害。 |
| 結局 | 已歿者：死因、地點、享年 | 咸寧紀元一四〇年（12373年）壽終於靈鷲門，享年一百二十七。 |

同類的事多於三件時合併：「先後收徒五人」「遊歷七州」；只逐一寫出重要的（對方是有名之人中境界最高的、報仇或了結的、或與本人另有緣分的）。恩怨段裡殺業的總數與死仇數合成一句，不逐筆寫。

### 年表

一年月一條，舊的在上，預設收合、點「年表」展開。每條是不含主詞的完整句子，內容與小傳一致，但不合併、不省略。前世的事不列，只在第一條交代：

```
咸寧紀元九年（12242年）七月　前世為散修南宮意，為徐鋒昊所殺，復生於南白州。
咸寧紀元二五年（12258年）十一月　年滿十二，未得入道。
咸寧紀元三二年（12265年）六月　嫁彭銘。
咸寧紀元三四年（12267年）二月　入靈鷲門，拜魏恕滄為師。
咸寧紀元九六年（12329年）八月　彭銘先己而逝；另嫁令狐塵真。
咸寧紀元一〇二年（12335年）二月　魏恕滄亡故，改拜馬融星為師。
咸寧紀元一〇三年（12336年）十一月　築基。
咸寧紀元一〇九年（12342年）十一月　出遊瓊靈州。
咸寧紀元一一〇年（12343年）六月　將與前世的殺身仇人陳淑相遇——其前世南宮意，咸寧紀元九年（12242年）為陳淑的前身徐鋒昊所殺。
咸寧紀元一一一年（12344年）五月　遇陳淑於坦陵州，殺之以報前世之仇——其前世南宮意，咸寧紀元九年（12242年）被陳淑的前身徐鋒昊殺害。
```

同年同月的幾件事併成一條（入門與拜師）。

## 每一句需要的事實

「現有」是模擬已經記了，橋接帶出來就能寫；「要新增」是模擬沒有記，要加事件或欄位。

| 句子 | 需要的事實 | 來源 | 現況 |
|---|---|---|---|
| 出身 | 籍貫、身分、宗門 | 人物現況 | 現有 |
| 前世是誰、怎麼死 | 魂的上一世：姓名、身分、死因、死亡年、殺他的人 | 魂的各世紀錄；上一世的 `Died`／`Killed` | 現有；清單第一筆是上一世摘要 |
| 魂入哪一道 | `Judged` 的六道 | 事件 | 現有；橋接已歸到上一世歷程的最後一條，寫「死後魂入某道」 |
| 未得入道／自行入道／入某門 | `ComeOfAge` 的 role 與宗門 | 事件 | 現有；橋接不拿現況的宗門回填，事件自己帶宗門才寫入某門 |
| 後來投入宗門 | 散修投靠宗門、隨師遷入新宗；未得入道者後來被宗門收錄（第二次 `ComeOfAge`） | `SectJoined`、第二次 `ComeOfAge` | 現有；清單把第二次入道標成 `sect_joined` |
| 拜某為師／收某為徒 | 師徒緣的方向 | `ThreadCreated`，順序為徒、師 | 現有；傳聞寫「拜某為師」，本人是師的歷程寫「收某為徒」 |
| 師亡、離宗、師徒解除 | 何時、因何 | `MasterEnded`（師亡、師離宗、徒離宗）、`SectLeft`（入魔離宗、宗門覆滅、隨師遷出） | 現有；現行規則沒有自願離宗與改拜的路徑，換師一定接在師亡或離宗之後 |
| 嫁娶 | 成婚雙方、性別 | `Married` | 現有 |
| 喪偶 | 配偶何時死 | 配偶的 `Died` | 現有；清單由成婚對象的死亡推出一筆 `widowed` |
| 結仇、受恩、定情、結怨 | 宿緣的種類、方向、起因事件 | `ThreadCreated` 與它的 `causes` | 現有 |
| 將遇 | 這條緣是哪一世、哪一年、因何事結下 | `ThreadOmen` 的 `causes` 指向結緣事件；`lives` | 現有；每筆帶 `because`（結緣事件、年月、雙方當時的名字、已隔幾世） |
| 報仇、報恩、了結 | 同上 | `ThreadResolved`、`FeudEscalated` | 同上 |
| 對方是誰的轉世 | 對方的魂在結緣當時的名字 | 魂的各世紀錄 | 現有；`other_bond_name` |
| 魂入某道的理由 | 功德、業障的數值 | — | 不寫；只寫入哪一道 |

橋接查詢 `person_chronicle(id)` 回傳排好的事實清單，文字由 Godot 端依本節的句型組成。人物卡已不再讀 `person_history`（它仍在橋接，見現況）。欄位見 6.4。

## 文字怎麼組

條件文法加句型庫（6.10 #77 之後的去模板化方向，訪談第 41 輪）：每一種事實有三到六種句型，依事實本身選用——有前因用帶前因的句型、對方是有名之人用帶身分的句型、同段前一句已出現過的名字改用代稱或省略。選擇只看事實，同一個人每次打開讀到的文字相同。執行期不跑語言模型；句型在開發期寫好，放 `game/modules/locale/resources/chronicle.zh-Hant.json`。

## 事件卡的因果鏈

每一條是含主詞的完整句子，名字用當時的名字，不掛類別印。兩條之間的關係寫在縮排的開頭：`因`（上一條是下一條的原因）、`轉世`（同一個魂換了一世，寫「南宮意轉世為周道爍」）。

## 傳聞的類別印

傳聞簽每張留一枚印，兩個字，是白話的動詞。現在年月前面的小印（宿緣、高境、隕落）併進這一枚：死在天劫裡蓋「隕落」，了結的是前世的仇蓋「報仇」。展開後的六個篩選鈕不變。

| 類 | 事件 → 印 |
|---|---|
| 生死 | 壽終、病故等自然死亡 → 壽終；被殺 → 遇害；死於天劫 → 隕落；轉世 → 轉世。魂入六道不上傳聞 |
| 修行 | 成年入道 → 入道；入宗門 → 拜入；突破 → 突破；劫雲聚 → 劫至；渡過 → 渡劫；入魔 → 入魔；飛升 → 飛升 |
| 人倫 | 成婚 → 成婚；拜師 → 拜師 |
| 恩怨 | 結下時依種類 → 結仇、受恩、定情、結怨；將遇 → 將遇；了結時依種類 → 報仇、報恩、了情、釋怨；淡去 → 緣盡；冤冤相報 → 世仇 |
| 宗門 | 立派、分宗、繼位、爭脈、覆滅 |
| 王朝 | 開國、開疆、宣戰、起義、割據、篡位、內戰、崩解、封禪、賑濟、禁道 |
| 天地民生 | 饑荒、墾林、沙化、洞天、遷治、陸沉、海陸、天變 |
| 天書 | 添頁 |

新用到的字要先確認在子集字型裡（8.2），不在就重跑子集化。

## 驗收

- 任取 20 個有名之人（在世與已歿各半，至少 5 人有前世的宿緣）：小傳與年表裡同一件事沒有出現兩次；每一次再婚之前有上一段婚姻的結束；每一次換師之前有原因；每一筆報仇、了結、將遇寫得出是哪一世因何事；前世的事用前世的名字。
- 同一個人連續打開三次，文字逐字相同；存檔再載入後也相同。
- 連續看 20 個人的小傳，「入道與師門」一段至少出現 4 種不同的句型，差別來自事實不同。
- 找一位沒看過這個遊戲的人讀三篇小傳，各用兩三句話複述，內容與事實相符。
- 傳聞簽上每一枚印單獨拿出來，沒玩過的人說得出是什麼事。

## 現況

資料層：模擬新增 `SectJoined`、`SectLeft`、`MasterEnded` 三種只供生平的紀錄（重要度 1，不上傳聞，橋接的事件查詢與 `person_history` 不回傳；寫入時不改涉及人物的最近事件，既有事件的因果鏈不變），橋接新增 `person_chronicle(id)`。清單把成婚同時的結緣、殺人當下的殺業、同年月的入門與拜師標成同一 `group`，介面合成一句。

文字層：`game/modules/locale/code/chronicle_text.gd`（`ChronicleText.compose(info, facts, lookup, history)`（`history` 為開局前的年數，供算世界年） 回傳 `{bio, rows, used}`）與句型庫 `chronicle.zh-Hant.json`。人物卡（5.8）顯示四段小傳與預設收合的年表；傳聞的類別印尚未改（見上節）。

- 小傳依序：出身與前世；入道與師門與成家（入宗、離宗、拜師、師徒解除、成婚、喪偶、遷居）；修行與遊歷；恩怨（殺業、報仇、了結、現況）；已歿者再加一段結局。年表每月一列，同月的事以「；」連成一列，有對應事件的整列可點開事件卡。
- 句型庫：每種事實 3 到 6 種句型，選擇鍵是 `人物編號 × 事件編號 × 鍵名` 的雜湊，同一個人每次相同。句型語法：`{名}` 填入參數；`{,名}` 在參數非空時前綴「，」；`@` 標小傳日期的位置（年表列不含）；`需A+需B|句型` 前綴表示該參數都非空才可用，可用句型中需求最多者優先。
- 同一段或同一列內前句已出現的人名改「其師／其徒／其妻／其夫／其人」；超過 3 件的同類事合併（收徒取最高境界者、多次成婚、遊歷、宿緣淡去等）。
- 資料層給不出的事實：重要度 1 的事件滿百年、當事人皆已歿，歿後十年內的複查就修剪（降生、入道、拜師、遊歷、入宗、離宗、師徒解除），長壽者即使剛死，百年前的這類事實也已消失，清單前段殘缺，換師前的結束原因也隨之消失，小傳從現存的第一件事寫起；上一世的六道在同樣情形下為空，不寫去向。世仇與恩怨升級的句型在目前種子的樣本裡沒有出現，只由讀文檢查，未在真資料上跑過。
- `person_history` 已無執行期使用者；仍引用它的是 `test_sim_bridge.gd`、`test_sect_card.gd`（宗門名連結的對照）與 `parts_shots.gd`。移除要同時改寫這三處與橋接測試，另案處理。
- 新用到的字已核對子集字型：句型庫與程式的用字全在 `wenkai_tc_subset.ttf`；`events.zh-Hant.json` 另有「涅槃泯≥」等字不在子集內（非本次新增），下次重跑子集化時一併收入。
