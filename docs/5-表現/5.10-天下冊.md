# 5.10 天下冊

天下冊是一張蓋滿畫面的紙，分四頁列出整個世界的統計：天下、修士、宗門與勢力、因果與歲時。它回答「現在天下是什麼局面」，看到有意思的數字可以點下去，飛到那個州或打開那個人的命簿。本節定義入口、版面、各頁的內容與資料來源。第一批已實作，範圍見文末「現況」。

## 入口與行為

- 開啟：按 `B`，或點題簽右端的「冊」印。收合：`B`、`Esc`／搖桿 B、點紙外的暗處。
- 版面與傳聞簽的全螢幕相同（5.7）：四邊各留 24 px × 介面縮放，底下的地圖壓暗、不收輸入；紙、墨、朱、金四種母題。
- 展開時模擬暫停，收合時暫停狀態與速度回到展開前。開命簿卡片、傳聞全螢幕、選單時先收合；三者不同時在畫面上。
- 頁首：左端「天下冊」與題簽相同的日期，其下一列分頁「天下／修士／宗門／因果」，滑鼠點、左右鍵或搖桿十字鍵左右切換；每次展開回到上次看的那一頁。
- 數字是展開那一刻的世界；展開期間世界不動，所以不重算。
- 每一頁分左右兩欄：左欄是圖表，右欄是名單。點圖表上的一項（一條長條、金字塔的一層、圓環的一段），右欄列出那一群的名單；名單每列可點。
- 可點的東西與命簿相同：州名＝收合並飛往、開州郡卡；人名＝收合並開人物卡；宗門名＝收合並飛往山門。
- 捲動：滾輪、方向鍵上下、PageUp／PageDown、搖桿左搖桿；游標在哪一欄就捲哪一欄。

## 圖表的畫法

全部以 `CanvasItem` 自訂繪製，不用貼圖。

| 圖 | 畫法 |
|---|---|
| 長條 | 橫向墨條，兩端收細；條的右端寫數值，左端寫名稱；最長的一條佔欄寬的 70% |
| 金字塔 | 由下往上逐層置中的橫條，一層一個境界，層高相同、寬度依人數（取對數，最少 12 px，才看得到只有一兩人的高境界） |
| 圓環 | 與州郡卡的三教圓環同一個畫法；每段旁寫名稱與百分比 |
| 曲線 | 墨線，橫軸是年（開天至今，可用滾輪縮放、拖曳平移），縱軸自動取整；多條線以線型區分（實線、虛線、點線），另以色票顏色輔助；大事在橫軸上以朱點標出，停留顯示該事件的一句話 |
| 排行 | 文字表：名次、名稱、兩到三個數值欄；點欄名依該欄排序 |

顏色只用 5.1 色票。不靠顏色區分的原則照舊：每一段、每一條線都有文字或線型。

## 天下

首頁（天下頁）頂端先是世界簡史橫條，其下才是左右兩欄。

### 世界簡史

一條橫貫版面的帶子，回答「這個世界活了多久、換過幾個紀元」。全遊戲只有這裡寫開天以來的年數（世界年）；日期一律只寫紀元時間（2.6「日期顯示」）。

| 部分 | 內容 |
|---|---|
| 標題 | 「世界簡史　開天至今 N 年、M 個紀元」，N 加千分位；右端一行操作提示 |
| 紀元橫條 | 開天到今天一整條，每個紀元一段，寬度與長度成比例，最短一段也留 6 px × 縮放讓人點得到；段寬放得下紀元名就寫在段上，放不下只在停留或選取時顯示（下方說明行） |
| 成住壞空細帶 | 橫條下一道細帶，依同一把尺標出成（0–27,000 年）、住（27,000–113,400）、壞（113,400–118,800）、空（118,800–129,600）；世界只跑了幾千年時只畫到今天，超過一元（129,600 年）時下一輪的成緊接著畫（2.6） |
| 現在 | 橫條右端的朱色三角與「現在」，指著最後一個紀元 |
| 說明兩行 | 選取（或停留中）那一段的「紀元名、第幾至第幾年、共幾年、起因類別」，以及它起因的世界大事的一句話 |

- 選段：滑鼠點一段、鍵盤 `[` `]`、搖桿游標點或 LB／RB；預設選現在的紀元；停留預覽，離開回到選取的一段。
- 起因：點起因那句話開該世界大事的事件卡。開天、開局前已過的紀元沒有事件可開，只寫紀元名與起因類別（開天、大寒、大暖、末法、靈氣復甦、天崩地裂、魔劫蔽日、重光、浩劫之後、承平）；起因事件已被因果帳修剪（3.3）時也只寫這兩項。
- 容量：1 個紀元整條一段，約 15 個紀元每段仍可點；只跑過幾千年的世界只有成劫的前段，十幾萬年的世界四段細帶齊全。
- 其他頁沒有這條橫條，兩欄回到頁籤列下方。

## 驗收

- 四頁在 1280×800 與 1920×1080、介面縮放 100% 與 150% 都排得下，不截字。
- 世界簡史：各段寬度與紀元長度成比例；「開天至今 N 年、M 個紀元」的數字等於紀元表；點每一段顯示該段的起因；除這條橫條外，介面字串、句型庫與跑出來的日期、事件句、小傳、年表都沒有世界年。
- 數字彼此對得起來：修士頁各境界人數的總和＝天下頁的在世有名之人；出身各條的總和相同；宗門榜門人數的總和＝出身長條中各宗門的總和；州郡排行的人口與該州州郡卡相同。
- 每一個可點的項目都到得了該到的地方；右欄名單與圖上那一項的數字相同（名單有上限時寫明「前 N 名，共 M」）。
- 展開與收合前後的暫停狀態與速度相同；展開期間 `tick` 不變。
- 開天十年後與萬年後各看一次：曲線橫軸涵蓋開天至今；萬年時切換分頁與縮放曲線不卡（每次重畫 < 16 ms）。

## 現況

第一批已實作：世界簡史橫條（天下頁頂端）；入口（`B` 與題簽右端的「冊」印）、全螢幕紙面與四頁分頁、四種圖（長條、金字塔、圓環、排行）、左欄圖表點出右欄名單、名單的州名、人名、宗門名可點、暫停與還原、與傳聞全螢幕、命簿卡和選單互斥。畫面在 `hud/code/almanac.gd`（版面與各頁）與 `almanac_pen.gd`（圖的畫法），統計查詢在 `native/sim/rust/crates/sim/src/stats.rs`，橋接在 `gdext/src/stats_api.rs`。

各頁已有的區塊：

- 天下：除王朝外全部。
- 修士：除僧、儒金字塔外全部。
- 宗門：宗門榜、勢力分布、興亡、近百年。
- 因果：未了宿緣、牽連最深、業氣；歲時一行寫「歲時紀錄尚未開放」，沒有曲線與年表。

資料的定義：

- 在世有名之人含孩童、僧、儒與凡人，並非都有境界。境界金字塔最底多一層「凡俗」，各層相加等於在世有名之人；出身同理，各宗門、散修（修士而無門派）、無門無派的非修士相加也等於在世有名之人。
- 年紀分段依年歲占壽元的比例：不到四分之一為少，不到十分之七為壯，其餘為老。
- 道途：入魔者是身分為入魔的人；魔道是入魔者加上邪道宗門的門人；妖是身分為妖者；其餘修士為正道。
- 近百年含當年共一百個年份；隕落指重要度三以上的身死（元嬰以上或執政者）；渡劫失敗含身死與肉身散去。
- 地形圓環只算陸地，水域不計；教化依人口加權，未受教化＝一減三教之和。沒有歸屬任何大洲的州郡合為「海島」一列。
- 宗門覆滅的原因：第一個起因是宗門交戰的寫「敗於爭脈」，其餘寫「門人散盡」。

尚未做：歲時曲線與年表（等模擬端加歲時紀錄）、王朝區塊、僧與儒的金字塔、搖桿專屬的展開鍵（以游標點「冊」印）。
