# 5.10 天下冊

天下冊是一張蓋滿畫面的紙，分四頁列出整個世界的統計：天下、修士、宗門與勢力、因果與歲時。它回答「現在天下是什麼局面」，看到有意思的數字可以點下去，飛到那個州或打開那個人的命簿。本節定義入口、版面、各頁的內容與資料來源。尚未實作，見文末「現況」。

## 入口與行為

- 開啟：按 `B`，或點題簽右端的「冊」印。收合：`B`、`Esc`／搖桿 B、點紙外的暗處。
- 版面與傳聞簽的全螢幕相同（5.7）：四邊各留 24 px × 介面縮放，底下的地圖壓暗、不收輸入；紙、墨、朱、金四種母題。
- 展開時模擬暫停，收合時暫停狀態與速度回到展開前。開命簿卡片、傳聞全螢幕、選單時先收合；三者不同時在畫面上。
- 頁首：左端「天下冊」與題簽相同的日期，其下一列分頁「天下／修士／宗門／因果」，滑鼠點、左右鍵或搖桿十字鍵左右切換；每次展開回到上次看的那一頁。
- 數字是展開那一刻的世界；展開期間世界不動，所以不重算。
- 每一頁分左右兩欄：左欄是圖表，右欄是名單。點圖表上的一項（一條長條、金字塔的一層、圓環的一段），右欄列出那一群的名單；名單每列可點。
- 可點的東西與命簿相同：州名＝收合並飛往、開州郡卡；人名＝收合並開人物卡；宗門名＝收合並飛往山門。
- 捲動：滾輪、方向鍵上下、PageUp／PageDown、搖桿左搖桿；游標在哪一欄就捲哪一欄。

## 圖表的畫法

全部以 `CanvasItem` 自訂繪製，不用貼圖。

| 圖 | 畫法 |
|---|---|
| 長條 | 橫向墨條，兩端收細；條的右端寫數值，左端寫名稱；最長的一條佔欄寬的 70% |
| 金字塔 | 由下往上逐層置中的橫條，一層一個境界，層高相同、寬度依人數（取對數，最少 12 px，才看得到只有一兩人的高境界） |
| 圓環 | 與州郡卡的三教圓環同一個畫法；每段旁寫名稱與百分比 |
| 曲線 | 墨線，橫軸是年（開天至今，可用滾輪縮放、拖曳平移），縱軸自動取整；多條線以線型區分（實線、虛線、點線），另以色票顏色輔助；大事在橫軸上以朱點標出，停留顯示該事件的一句話 |
| 排行 | 文字表：名次、名稱、兩到三個數值欄；點欄名依該欄排序 |

顏色只用 5.1 色票。不靠顏色區分的原則照舊：每一段、每一條線都有文字或線型。

|---|---|---|---|

## 資料來源

唯讀的橋接查詢，畫面不讀遊戲規則，也不自己從事件重算：

| 查詢 | 回傳 | 現況 |
|---|---|---|
| `stats_world()` | 總數、各大洲、地形占比、教化占比、天地負荷與氣候 | 待加；資料模擬端都有 |
| `stats_provinces(sort, limit)` | 州郡排行 | 待加 |
| `stats_people()` | 各境界、各門、男女、年紀、正魔的人數 | 待加 |
| `people_where(filter, limit)` | 符合條件的人的名單（境界、門派、性別、年紀、正魔） | 待加 |
| `stats_sects()` | 現存與已覆滅宗門的各欄 | 現存可由 `sects()` 擴充；已覆滅者模擬端有沒有留下資料尚未查，沒有就要另記 |
| `stats_karma()` | 五類宿緣條數、最深的線、牽連最深的魂、業氣最重的州 | 待加 |
| `recent_counts(years)` | 近 N 年各類事件的次數與事件代號 | 待加；因果帳有修剪，超出保留範圍的年份取歲時紀錄 |
| `annals(from_year, to_year, step)` | 歲時紀錄：每年一筆的各項總數與各類事件次數 | 模擬端沒有這份紀錄，要新增；每年一筆、每筆約 40 個數，萬年約 1.6 MB，存檔要帶 |

歲時紀錄與已覆滅宗門的保留要改模擬核心，排在事件驅動引擎（6.10 #76 之後的新引擎）合併之後；其餘查詢只讀現有資料。

## 驗收

- 四頁在 1280×800 與 1920×1080、介面縮放 100% 與 150% 都排得下，不截字。
- 數字彼此對得起來：修士頁各境界人數的總和＝天下頁的在世有名之人；出身各條的總和相同；宗門榜門人數的總和＝出身長條中各宗門的總和；州郡排行的人口與該州州郡卡相同。
- 每一個可點的項目都到得了該到的地方；右欄名單與圖上那一項的數字相同（名單有上限時寫明「前 N 名，共 M」）。
- 展開與收合前後的暫停狀態與速度相同；展開期間 `tick` 不變。
- 開天十年後與萬年後各看一次：曲線橫軸涵蓋開天至今；萬年時切換分頁與縮放曲線不卡（每次重畫 < 16 ms）。
