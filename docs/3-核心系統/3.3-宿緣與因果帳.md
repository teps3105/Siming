# 3.3 宿緣與因果帳

## 宿緣（因果線）

### 欄位

| 欄位 | 說明 |
|---|---|
| `id` | ThreadId |
| `kind` | 種類（下表） |
| `debtor` | 欠債方的魂 |
| `creditor` | 債主方的魂；情緣、師徒為對稱關係，兩欄只表示建立時的順序（師徒中 creditor 是師父） |
| `strength` | 1..100 |
| `created` | 建立 tick 與來源事件 |
| `lives_base` | 建線時雙方的轉世次數快照（欠債方，債主方） |
| `lives` | 建立後的轉世次數，由 `lives_base` 與雙方目前轉世次數推得：欠債方的增量；對稱線（情緣、師徒）取雙方增量中較大者 |
| `master_best` | 師徒線專用：建線時師父的成就（Achievements，3.1） |
| `woven` | 是否為司命所牽 |
| `resolved` | 了結 tick 與事件；未了結為空 |
| `omen_at` | 已發出預兆時的 `lives` 值（每次轉世最多一次預兆） |

### 種類

| 種類 | 顏色 | 建立時機 | 初始強度 |
|---|---|---|---|
| 殺業 | 赤 | 有名之人殺死有名之人：欠債方是兇手，債主是死者。例外：斬殺惡人不建立（3.1） | 40 + 死者身分加成（修士：境界 × 5；君主：20） |
| 恩義 | 金 | 救命、傳功、度化、扶持：欠債方是受恩者 | 30 |
| 情緣 | 粉 | 婚配（3.4）；司命牽線 | 30 |
| 師徒 | 青 | 拜師（3.5、3.6、3.8）：欠債方是徒弟 | 20 |
| 怨 | 暗紫 | 怨靈對屠城者；無辜者對天道（4.4） | 60 |

- 同一對魂、同一種類只有一條**未了結**的線；重複發生時強度累加，上限 100。
  - 殺業的例外：欠債方再勝而殺死債主時，另建獨立的新線（見相遇結果）。
  - 師徒線的唯一性以**有方向的鍵**（徒弟，師父）判定；方向相反的兩條師徒線可並存。
- 利息：見 3.1。

## 相遇

- **條件**：線兩端的魂都在世，且雙方所在州郡距離 ≤ 1（陸鄰或同州）。幼年者（3.4）不參與。
  - 距離 = 沿陸鄰（`neighbors`）的步數，不含海鄰。
- **頻率**：每年判定一次。機率 `0.15 × 強度 / 50`，同州則加倍。
- 情緣線的兩人現為配偶時，略過相遇。
- 遊歷（3.5）會改變所在州郡，增加相遇。
- 欠債方與債主任一方是天道（0 號魂）時，永不相遇。

### 相遇結果

| 種類 | 結果判定 | 了結條件 | 未了結時 |
|---|---|---|---|
| 殺業 | 50% 爆發衝突。勝率 `r/(1+r)`，r = 債主戰力 / 欠債方戰力（戰力見 3.4；分母下限 1） | 債主勝：殺死欠債方，即**復仇** | 欠債方勝而殺死債主：舊線強度 +30；並**另建一條獨立的新殺業線**（不與舊線合併），方向相同（兇手＝欠債方、死者＝債主）——冤冤相報（4.5） |
| 殺業（化解） | 只在債主遇險時判定（會戰、天劫、妖襲、被襲殺）：欠債方在同州時，以 `0.3 × 德行 / 10` 機率出手相救 | 欠債方救了債主 | — |
| 恩義 | 50% 報恩 | 報恩：傳授修為（受恩者為修士時，使對方修為 +10%）、救命、扶持（使對方職位或聲望提升） | 強度不變 |
| 情緣 | 雙方年齡差 ≤ 10 且皆未婚：60%；否則 10% | 須 `lives ≥ 1`：轉世後再結為道侶或夫妻（再續前緣）；婚配成立時結算（3.4）。同一世建立的情緣線不在同一世了結 | 有緣無分：強度 −10；降到 0 時線消散（不算了結） |
| 師徒 | 同教時 70% 拜入對方門下（身分允許時）；戰力較高者為師 | 須 `lives ≥ 1`：轉世後再結師徒，或徒弟今生的成就超過 `master_best`（建線時師父的最高成就） | — |
| 怨 | 同殺業 | 怨靈之魂的今生殺死仇人，或攻滅仇人的勢力 | 怨靈轉世後判入阿修羅道（3.2 條件不滿足時亦同） |

- 衝突的死亡依 3.1 計算業障。復仇殺死欠債方時，**不**建立新的殺業線（報應不算殺業）。
- **復仇與冤冤相報不限於相遇**：任何場合（襲殺、會戰、斬妖）只要債主殺死欠債方即視為復仇、欠債方殺死債主即為冤冤相報，處理相同；怨線同殺業。
- **婚配與情緣線**：婚配成立時，若兩魂已有 `lives ≥ 1` 的未了情緣線，該線了結（再續前緣）；否則建立情緣線，或累加既有未了線。
- **處理順序**：
  - 每年依魂 ID 升冪處理；每個魂最多處理 1 次相遇（`MEET_PER_SOUL_PER_YEAR`）。
  - 每個魂的線依強度由高到低，相同時取 ThreadId 小者。
  - `MEET_PER_SOUL_PER_YEAR` 計「實際發生」的相遇（機率判定通過者）；判定未通過不佔名額，但該線當年不再判定。
  - 相遇結果的補充：師徒「身分允許」指師父非幼年、徒弟尚無師父、師父徒弟 < 5、修士師父境界 ≥ 金丹；同教以身分所屬的教（修士＝道、僧＝釋、儒士＝儒、魔修＝魔）判定。恩義報恩的「修為 +10%」為修為乘以 1.1。情緣的結合只在 `lives ≥ 1` 且雙方成年未婚時成立，其餘算未了結。
  - 一條線的兩端在同一年只處理一次。

## 了結

1. **清算業力**：
   - 殺業被復仇：欠債方 S −= 強度 × 0.5（下限 0）。
   - 殺業被化解：欠債方 S −= 強度。
   - 其他種類：雙方各 G += 強度 × 0.2。
2. 寫入因果帳「宿緣了結」事件。因（causes）指向該線的建立事件，以及雙方今生的最近事件。
3. 司命天機（4.3）。
4. 天書偵測（4.5）。
5. 地圖奇觀：線燃盡（5.6）；奇觀的兩端為事件當下兩端所在州郡。

## 預兆

- **條件**：線兩端在世、距離 ≤ 2、強度 ≥ 50，且 `omen_at ≠ lives`。
- **效果**：發出「赤線漸近」事件，並記下 `omen_at = lives`。

## 因果帳（事件紀錄）

| 欄位 | 說明 |
|---|---|
| `id` | EventId，遞增 |
| `tick` | 發生時間 |
| `kind`、`args` | 事件種類與參數（8.2）；文字由介面依模板產生，不存在模擬中 |
| `province`、`cell` | 地點 |
| `souls`、`persons`、`powers` | 牽涉的魂、人、勢力 |
| `causes` | 直接原因事件 |
| `importance` | 1..5 |

- **溯因**：沿 `causes` 往上。**漣漪**：沿反向索引往下。介面在人物卡、事件卡提供（5.8）。
- **墓碑**：為使 EventId 即索引，被修剪的事件留下墓碑（`importance = 0`，保留 `tick`、`kind`、`causes`，其餘清空）；讀取一律經 `ledger::get`。
- **保存**：
  - importance ≥ 2 的事件永久保存。
  - importance 1 的事件只保留最近 100 年。
  - 修剪 importance 1 的事件時，所有指向它的 `causes` 改指向它的因（遞迴到最近被保留的祖先），使溯因不斷鏈。
