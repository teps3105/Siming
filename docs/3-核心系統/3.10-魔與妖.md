# 3.10 魔與妖

魔修、魔門與妖族是世界的濁氣出口：業氣高的地方滋生魔與妖，他們再製造更多業氣。本節定義魔修、魔門、妖與妖域的來源與行為，以及魔勢累積成魔劫的條件。

## 魔修

- **來源**：
  - 入道時選魔（3.4）。
  - 修士入魔（3.5 心魔）。
  - 怨靈、修羅轉世者入魔的機率較高。
- **修煉**：沿用 3.5 的九境界與修為公式，但靈氣係數改為業氣係數：`0.5 + 2 × 所在州郡業氣`。
  - 另外，每殺一名有名之人，修為 += 對方戰力 × 2；殺凡人（肆虐）每萬人 +5。
- **天劫**：存活率公式相同；因為業障極重，魔修天劫極凶。
  - 大乘魔修若渡過飛升劫，則「以殺證道」，魂超脫。極少發生；天書條目「以殺證道」。
- **行為**（每年，依戾氣）：
  - 襲殺本州或陸鄰一名有名之人，機率 `戾氣 × 0.02`。勝率 `r/(1+r)`，r 為戰力比（戰力見 3.4）；敗者死亡，業依 3.1 計算。
  - 魔主可聚眾為魔軍出擊（3.9），只在魔勢 > 0.5 時；機率 `0.05 × (魔勢 − 0.5)`。魔軍兵力 = `Σ 魔門成員戰力 × 500`。

## 魔門

- **創立**：金丹以上魔修，在有魔窟的州郡立派；每年 5%。
- 規則同宗門（3.5），差別如下：
  - 與所有正道勢力的關係初值 −80。
  - 每年使所在州業氣 +0.01。
- **討魔**：正道宗門的勢力範圍與魔門據點相鄰或重疊時，每年以 0.05 機率比照爭脈之戰（3.5）判定。

## 妖

- **來源**：畜生道轉世、且魂的宿慧 W ≥ 30（3.2；妖在 M4 加入，M2–M3 暫行為獸）；或濁氣 > 0.5 的州郡滋生（建立新魂，道緣偏魔）。
- **出生地**：
  - 畜生道轉世：依因果牽引（3.2）選州，但只限「荒野格（森林、山脈、沼澤、雪原、鄰海格）≥ 30%」的州郡。
  - 濁氣滋生：就在該州。
- **族類**：依出生州郡中數量最多的荒野格決定。

  | 荒野格 | 族類 |
  |---|---|
  | 森林 | 狐 |
  | 山脈 | 虎 |
  | 沼澤 | 蛇 |
  | 雪原 | 狼 |
  | 鄰海格（與海相鄰的陸地格） | 蛟 |

- **境界**：沿用九境界，名稱改為：開靈、化形、妖丹、妖嬰、妖王（化神以上）。修煉使用靈氣係數。
- **行為**：
  - 每年以 `戾氣 × 0.03` 機率襲擊所在州郡的凡人：人口 −1–3%，業氣增加（2.4），妖的魂 S += 死者 / 2000。
- **結局**：
  - 被斬殺（3.5 斬妖除魔；業依 3.1）。
  - 被度化（3.6）。
  - 渡過飛升劫而超脫（算作飛升）。

## 妖域

- **創立**：境界達妖王（化神）的妖，在出生州郡立域；每年 10% 機率。據點即該州。
- **成員**：所在州及陸鄰的妖投靠（每年 20%）；規模上限 `3 + 妖王境界`。
- **聲望**：`妖王戰力^0.5`。
- **範圍**：據點州及陸鄰中，荒野格 ≥ 30% 的州郡。地圖上以妖氣覆蓋。
- **妖群**：魔勢 > 0.5 時，妖王每年以 `0.05 × (魔勢 − 0.5)` 機率率妖群出擊（3.9）。
  - 妖群兵力 = `Σ 成員戰力 × 500`。

## 魔勢與魔劫

```
魔勢 = Σ(魔修、妖的戰力) / (Σ(淨業力 ≥ 0 的修士、羅漢以上僧人、大儒的戰力) + 3 × 陸地州郡數)
```

- 戰力見 3.4。
- 分母的常數項代表凡人義勇，避免分母為 0。
- 天道業障 ≥ 100 時，分子 × 1.2（4.4）。

- **魔劫開始**：魔勢 > 1.0。
  - 所有魔窟每 3 年（魔劫開始後每滿 36 個月）產生一支魔軍，兵力 = 所在州人口 × 0.01。
  - 濁氣門檻降低 0.2。
  - 地圖整體色調轉紅。
- **魔劫結束**：魔勢 < 0.6。
- 魔劫期間降臨的量劫，強度 +2 成（3.11）。
