# 3.4 有名之人

魂在人間的肉身。只有有名之人被個別模擬；凡人只是州郡人口。

## 欄位

| 欄位 | 說明 |
|---|---|
| `id`、`soul` | PersonId；對應的魂 |
| `name`、`gender` | 7.3 命名規則；性別男、女 |
| `born`、`died` | 出生、死亡 tick；死因。年齡 = `floor((tick − born) / 12)`。`born` 為有號整數：開天時已成年的人物出生在 tick 0 之前（負值） |
| `home` | 籍貫州郡（出生地或所屬勢力據點） |
| `province`、`cell` | 目前所在（遊歷、行軍時與 home 不同） |
| `role` | 身分（下表） |
| `power_id` | 所屬勢力（可無） |
| 屬性 | 根骨、悟性、才略、德行、戾氣，各 0..10 |
| `lifespan` | 壽元上限（歲） |
| `spouse`、`master`、`disciples`、`children` | 人際關係 |
| `path` | 身分專屬狀態 `PathState`：幼年 `Child`、修士 `Cultivator`（境界、修為、上次突破嘗試、是否入魔）、僧 `Monk`（果位、修行）、儒士 `Scholar`（立德、立功、立言）、`Mortal`（散人、武將候補等）；見 6.2。境界與果位從 0 起算（3.1） |
| `last_event` | 本人最近一次事件（因果帳溯因用，3.3） |
| `blessed_until`、`travel_until` | 賜福到期、遊歷到期 |
| `forced_breakthrough` | 開局保證用：排定的 tick；到期時就地執行一次必定成功的突破與天劫（3.5、4.6） |

## 屬性

出生時決定：

| 屬性 | 公式 | 影響 |
|---|---|---|
| 根骨 | `U(0,6) + W/40`，截斷 0..10 | 修煉速度 |
| 悟性 | `U(0,6) + W/40`，截斷 0..10 | 突破、證果、立言 |
| 才略 | `U(0,8)` | 統治、統兵 |
| 德行 | `U(2,8) + (G−S)/100`，截斷 0..10 | 德政、行善 |
| 戾氣 | `U(0,6)` + 修羅印記 4，截斷 0..10 | 好戰、屠城、入魔 |

## 戰力

所有身分共用的個人戰力，用於衝突、復仇、襲殺、斬妖、魔勢：

| 身分 | 戰力 |
|---|---|
| 修士、魔修、妖 | `3^境界 × (1 + 層/10)`（層見 3.5，1..10） |
| 僧 | `2 × 3^果位`（沙彌 2、比丘 6、羅漢 18、菩薩 54） |
| 大儒 | 27（浩然正氣）；一般儒士同凡人 |
| 武將 | `3 + 才略` |
| 君主 | `2 + 才略 × 0.5`；作為被襲擊方時 × 3（護衛） |
| 其他凡人身分 | `1 + 才略 × 0.2` |

## 凡人、門人與出頭

規格已定（6.10 #93），分兩步實作。

- 第一步已實作（`crates/sim/src/adepts/`）：每州五門的門人數、入道率隨靈潮、五門權重與世局係數、「出了超脫者或在世最高成就者」的全世界加成、養分（存著供查詢）、魔道消耗凡人（記在門人層自己的帳上）；開天與人口期、人物期的每年結算；`siming-cli adepts`（6.7）。常數在 7.1「門人」，步驟位置在 6.3 步驟 7a。
- 尚未接線：門人數字不影響任何有名之人的判定，也不從州郡人口扣人。待第二步：出頭（門人到有名之人）、十二歲入道與輪迴出生改為凡人轉出頭、養分接到出頭率與修行速度、有名之人子女改為凡人。現行程式仍照下面「一生」「入道判定（12 歲）」運作；第二步實作後取代那兩節與「來源與數量控制」的輪迴出生。
- 待別的系統成勢力：寺院香火、書院、王朝毀佛、正道宗門清剿四項世局係數目前取 1（3.6、3.8、3.10）；魔道消耗他門門人本步未做。

世間的人分三層：

| 層 | 是誰 | 怎麼模擬 | 占人口（承平時） |
|---|---|---|---|
| 凡人 | 沒有入道的人 | 州郡人口的數字（2.3） | 約 99.7% |
| 門人 | 入了道而沒有出頭的人：煉氣修士、沙彌、生員、魔徒、煉氣散修 | 每州五個數字（道、佛、儒、魔、散修各一） | 約 0.3% |
| 有名之人 | 出了頭的人：築基、得初果、中舉以上，以及君主、王族、文臣武將 | 逐一模擬，有卡片、有生平、有魂 | 中型世界上限 4,000（7.1） |

- 能入道已是凡人裡的天才；門人與凡人地位相去不遠，是背景，也是資源。競爭從出頭開始。
- 門人沒有名字、沒有魂、不留紀錄；門人死了只是數字減少。
- 魂在出頭時才建立或喚回，魂只記得出過頭的那幾世（3.1）。

### 入道率

- 入道率 = 一州的門人總數 ÷ 一州人口，是在世人數的比，不是每年的流量。
- 基準 0.3%（三百人一個）；隨天地靈氣浮動：靈氣最盛時 1%，末法時 0.03%，之間依靈氣連續變化。
- 每年各州的門人數向「人口 × 入道率」靠近 1/20（門人的修行年限以 20 年計）；人口驟減時門人同比例減少。
- 依據：唐會昌五年還俗僧尼 26 萬 500 人約占人口 0.33%（<https://zh.wikisource.org/wiki/舊唐書/卷18上>）；明萬曆生員約 50 萬、三百人一個（<https://en.wikipedia.org/wiki/Imperial_examination>）；清代生員 0.18%–0.24%、舉人 0.0065%、進士 0.0009%（<https://pages.ucsd.edu/~dkjordan/chin/CivilServiceTable.html>）。1% 與 0.03% 兩端是本作自定的起始值。

### 五門的分布

- 新入道的人依各門的權重分到五門：權重 = 0.2 × 世局係數，五門合計正規化。承平時五門各約 20%。
- 世局係數（各項相乘，每項 0.5–2）：

  | 門 | 往上推的 | 往下拉的 |
  |---|---|---|
  | 道 | 本州與鄰州宗門的聲望、靈氣盛 | 宗門名額已滿 |
  | 佛 | 寺院香火、末法、戰亂與量劫之後 | 王朝毀佛（待 3.6） |
  | 儒 | 王朝承平、書院 | 無主之地、戰亂 |
  | 魔 | 本州濁氣、戾氣、亂世 | 清氣盛、正道宗門清剿 |
  | 散修 | 固定 1 | — |

- 任何一門出了超脫者或在世最高境界者，全世界該門的係數再乘 1.5，持續一運（360 年）。
- 一門獨大時，其餘四門仍照各自的權重分剩下的份額，彼此大致平均。
- 四門的寺院、書院、魔門尚未成為勢力（3.6、3.8、3.10）時，該門的門人照樣計數，係數裡與勢力有關的項取 1。

### 凡人是資源

| 用途 | 規則 |
|---|---|
| 門人來源 | 一門能收的門人 ≤ 它轄下州郡的人口 × 入道率 × 該門權重；爭地盤就是爭人口 |
| 修行的養分 | 一門在一州的養分 = 該州凡人 ÷ 該門門人，相對基準（1,500 人養一個門人）的比；養分低於 1 時，該門的出頭率與有名之人的修行速度同比例下降。佛門取香火、儒門取教化、道門取供奉、魔道取血食，算法相同 |
| 天地資源總量 | 世界的資源總量 = 靈氣總量 × (世界人口 ÷ 基準人口)^0.5；推得出超脫者要看它（2.6「成住壞空」） |
| 可被消耗 | 魔道每年消耗本州凡人（門人數 × 0.5 人）與他門的門人；戰亂、量劫（3.11）同時減凡人與門人。吃得太凶的一門養分下降，自己先衰 |

### 出頭

- 每年，一州一門的門人中有人出頭，成為有名之人：出頭人數 = 門人數 × 出頭率 × 養分 × 靈氣係數。基準出頭率每年 0.2%，使在世有名之人約為門人的 4%。
- 出頭的門檻：道、魔、散修為築基；佛為初果；儒為中舉。出頭時年齡取 18–40 歲，出生年、出生地依此回推，出身（宗門子弟、世家、寒門）隨之抽定。
- 出頭的是哪個魂：先從在中陰等待、因果牽引落在本州的魂裡取（3.2），權重為宿慧與該門道緣；沒有等待的魂時建立新魂。前世走得遠的魂因此更常再出頭，這是跨世累積的主要作用處。
- 等待的魂超過 60 年沒有出頭，算作一世無名：魂的宿慧照 3.1 折減，不留生平。
- 有名之人達上限時，新的出頭者依境界由高到低遞補，補不進的留在門人裡。
- 有名之人的子女不再自動成為有名之人，是凡人；他們出頭的機會較高（出身為世家或宗門子弟，權重 ×3）。君主的王族子女維持逐一模擬（3.7）。

### 現況數字（2026-10-14，中型世界，`siming-cli adepts --years 1000` 與 `funnel`，種子 7、42、20261011）

- 接手時（開天加預跑後）：世界人口 2,900–3,130 萬，門人 9.9–11.6 萬，入道率 0.34–0.37%；五門占比道 15–19%、佛 15–16%、儒 13–15%、魔 31–32%、散修 22–24%。魔門偏多因預跑期間濁氣高的州多。
- 接手後 1,000 年：入道率隨靈潮在約 0.05%（末法）到 0.9–1.4%（靈氣最盛，另含大劫後人口驟減的暫時值）之間起伏，三個種子的年均 0.27%、0.33%、0.38%；五門年均占比道 14–15%、佛 18%、儒 12–14%、魔 31–35%、散修 20–22%。
- 養分：靈氣最盛、入道率近 1% 時魔門養分降到 0.16–0.23，其他門 0.3–0.5；入道率回到 0.3% 以下時，除魔門約 0.66 外各門回到 1。本步不接判定。
- 有名之人層（`funnel --seed 7 --years 720`）：與門人層併入前逐位相同，十二歲去向為道門 3.9%、散修 18.0%、僧 0、儒 19.9%、魔 45.8%、散人 10.3%；種子 42、20261011 同樣與併入前相同。第二步才會改。

## 一生

| 年齡 | 階段 | 發生的事 |
|---|---|---|
| 0–11 | 幼年 | 身分為 `Child`；不在地圖上顯示，不行動 |
| 12 | 入道 | 決定身分（下） |
| 12+ | 成年 | 依身分行動，每年判定 |
| 壽元盡 | 終 | 死亡，魂入中陰（3.2） |

### 幼年

- 幼年者身分為 `Child`（`PathState::Child`）。出生時壽元先以凡人壽元抽取（見「壽元」）。
- 幼年者計入在世有名之人與 `NOTABLE_CAP`。
- 幼年者不參與相遇、衝突、襲殺、斬妖除魔，也不能被選為目標。
- 6.3 步驟 12 對「年齡 ≥ 12 且身分為 `Child`」者入道。入道由 `people::enter_path` 判定；拜師與師徒線由 3.5 的招收步驟處理，不在入道時建立。

### 入道判定（12 歲）

1. 王族子女：見 3.7。
2. 依道緣，在「可入之門」中加權抽樣（權重 = 魂的該教道緣分量；全為 0 時等機率）：

   | 門 | 條件 | 身分 |
   |---|---|---|
   | 道 | 根骨 ≥ 3 | 本州或陸鄰有宗門 → 該宗弟子；否則 → **散修** |
   | 釋 | 釋道緣 ≥ 0.2 | 本州有寺院 → 該寺僧人；否則 → **遊方僧** |
   | 儒 | 悟性 ≥ 3 | 本州有書院 → 書院儒士；否則 → **散儒**（自學） |
   | 魔 | 本州濁氣 > 0.5（`ENTRY_REQ`），或帶修羅印記 | 魔修（本州有魔門則入門） |

3. 都不符合時：
   - 州郡屬於王朝且才略 ≥ 6 → **武將候補**。
   - 否則 → **散人**。

- 入道看到的是上一年的聲望與規模（6.3）。
- 宗門已滿員（`SECT_SIZE`，3.5）時，原本入宗門者改為**散修**。
- 入道成為修士時，壽元改為 `max(現有, 煉氣壽元)`。
- 開天時（4.6）年齡 ≥ 12 的有名之人不經 12 歲流程，直接依本規則判定身分；M2 開天沒有王朝，武將候補改為散人。

散修、遊方僧、散儒照常修煉、修行、累積三不朽，只是沒有勢力加成。他們是宗門、寺院、書院在滅絕後重新出現的來源（3.5、3.6、3.8）。

## 婚配與子女

- 年滿 18 且未婚：每年 10% 機率，與同州或陸鄰、年齡差 ≤ 10 的未婚**異性**有名之人（不含幼年者；對方同樣須年滿 18）結為夫妻或道侶。
- 婚配成立時：若兩魂已有 `lives ≥ 1` 的未了情緣線，該線了結（再續前緣，3.3）；否則建立情緣線，或累加既有未了線。
- 修士偏好同宗門（候選中有同宗門者時，只從中挑）；僧人不婚。
- 王族子女由君主或王族夫妻產生：每年 15%，至多 5 名。子女的魂取自「判入人道、在等待或中陰中、宿緣對象在本州」者；沒有時建立新魂。
- 非王族的子女不個別模擬（併入凡人）。

## 來源與數量控制

- 有名之人只能由魂轉世而來：
  1. **輪迴**：判入人道的魂，依因果牽引出生（3.2）。
  2. **補足**：勢力低於規模下限時，從本州 12 歲入道者優先分派；仍不足且未達上限時，建立新魂，以 12 歲出生於據點州郡。
  3. **人間補魂**（6.3 步驟 13，婚配之後）：每年，若在世有名之人 < `NOTABLE_FLOOR`（= `NOTABLE_CAP × 0.5`，`NOTABLE_FLOOR_RATIO`），建立 `ceil((NOTABLE_FLOOR − 在世數) × REFILL_RATE)` 個新魂（`REFILL_RATE` = 0.1），依州郡人口分布選出生地，年齡 0。
- 達到上限 `NOTABLE_CAP`（7.1）時的處理，見 3.2「出生的延後」。
