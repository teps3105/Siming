# 3.9 戰爭

戰爭以月為單位在戰略地圖上推進，沒有戰術畫面。

## 軍隊

| 欄位 | 說明 |
|---|---|
| `owner` | 王朝，或叛軍、妖群、魔軍 |
| `general` | 統帥（有名之人）；無統帥時戰力 × 0.7 |
| `size` | 兵力（人） |
| `origin_size` | 出征時兵力，用於判定潰退 |
| `location`、`path` | 所在州郡；行軍路徑 |
| `progress` | 跨越目前邊界的進度（月） |
| `morale` | 士氣 0..1；初值 1.0 |

## 正義之戰

以下戰爭為「正義之戰」，主將殺敵的業障減半（3.1），儒士勝戰得立功（3.8）：
- 防守方。
- 討伐天命 < 30 的王朝。
- 討伐魔門、妖群、魔軍。

## 動員與解散

- **常備軍**：平時存在（3.7），駐在武將所在州；宣戰時編入軍隊。
- **動員**：宣戰時，每州動員 `P × 0.02 × min(1, M/100 + 0.5)` 兵（不超過 2.3 的動員上限）。
- **編組**：常備軍與動員兵集結成 1–3 支軍隊（依接敵前線數）。
  - 統帥：依才略由高到低指派武將。
  - 國師：尊道國策的國師加入第一支軍隊（3.7）。
- **解散**：戰爭結束時，動員兵解散，存活者回歸州郡人口；常備軍回駐。

## 行軍

穿越一條邊界所需月數，取目的州郡的主要地形：

| 地形 | 月數 |
|---|---|
| 平原 | 1 |
| 森林、丘陵、沼澤 | 2 |
| 山脈、沙漠、雪原 | 3 |

- 跨大河或江：+1 月。
- 走海路：+2 月。
- 目標選擇：優先敵方都城；其次是相鄰、且人口最多的敵方州郡。

## 會戰（每月）

兩方軍隊在同一州郡即會戰。

```
戰力 = size × (0.6 + 統帥才略 × 0.08) × 地形防守 × 士氣 × 國師加成
地形防守：守方在山脈 1.5、丘陵或森林 1.25、其餘 1.0
國師加成：1 + Σ 隨軍修士境界 × 0.1（尊道國策或宗門參戰）
每月損失：己方 size −= 對方戰力 × 0.05 × U(0.8, 1.2)
士氣：會戰月 −0.1 × (己方損失 / max(對方損失, 1))；非會戰月 +0.1，上限 1
```

- **潰退**：size < 40% origin_size，或士氣 < 0.3 → 退往己方最近的州郡。
- **陣亡統帥**：敗方統帥每月 5% 機率陣亡。殺者為對方統帥，建立殺業線。
- **業的結算**：
  - 死傷數計入州郡業氣（2.4）。
  - 主將業障（3.1）：每 5,000 殺敵 +1；正義之戰減半。
- 殘破度 +0.05 / 月。

## 圍城

- 敵方州郡中沒有敵軍時，開始圍城。
- 所需月數：`3 + 城池等級 × 2`；都城再 +3。
- **陷落**：
  - 州郡易主。
  - 殘破度 +0.3。
  - 人口 −10%。
- **屠城**：陷落時判定，機率 `0.02 × 統帥戾氣 × (圍城超過 12 個月 ? 2 : 1)`。
  - 人口 −30%，業氣 +0.4。
  - 統帥業障 `+100 + 死者 / 1000`。
  - 產生怨靈（3.1）。
  - 地圖表現：城池冒出黑紅業氣，持續一年。

## 戰爭結束

| 條件 | 結果 |
|---|---|
| 一方都城陷落 | 該方割讓所有被佔州郡；遷都到剩餘州郡中人口最多者；天命 −15 |
| 一方失去所有州郡 | 王朝滅亡；王族成為散人 |
| 戰爭 ≥ 3 年且最近一年沒有州郡易主 | 每年 15% 機率議和，維持現狀 |

## 宗門與王朝之戰

- 由禁道詔令觸發（3.7）。
- 王朝以一支軍隊進攻山門州郡；宗門以全體成員迎戰。宗門戰力 = Σ 成員戰力 × 1,000，視為一支駐守山門的軍隊，不移動、不圍城。
- 王朝佔領山門州郡 6 個月後，宗門覆滅（同 3.5）。
- 宗門擊退王朝軍（敵軍潰退）後，雙方議和，禁道詔令解除。

## 叛軍與其他軍隊

- **叛軍**：起義時以該州 `P × 0.01` 兵建立；目標是最近的都城。
  - 攻陷都城即改朝換代：叛軍首領建立新王朝，接收舊王朝所有未被他國佔領的州郡；舊君主被殺，建立殺業線。
- **妖群、魔軍**：見 3.10；使用相同的行軍與會戰規則，但不圍城，只「肆虐」（每月人口 −2%、業氣 +0.02）。
