# 3.7 儒：王朝與天命

王朝是儒家入世的舞台：君主憑天命統治，天命由德政、風水與災異增減，耗盡則改朝換代。本節定義王朝的欄位、開國、天命公式與效果、繼承、國策、財政、擴張與封禪。

## 欄位

| 欄位 | 說明 |
|---|---|
| `name` | 國號（一字，7.3） |
| `founder`、`ruler`、`heirs` | 開國君主、在位君主、儲君（王族子女） |
| `capital` | 都城州郡 |
| `provinces` | 疆域 |
| `mandate` M | 天命 0..100 |
| `treasury` | 國庫（錢糧） |
| `policy` | 國策：尊道、尊佛、尊儒、無，即位時決定，在位不變 |
| `decree` | 詔令：滅佛、禁道或無；頒布後鎖定到君主駕崩 |
| `officials`、`generals` | 文臣、武將（有名之人） |
| `standing_army` | 常備軍兵力（分駐各州） |
| `wars` | 進行中的戰爭（3.9） |
| `purges` | 歷代滅佛次數 |
| `prestige` | `州數 × 10 + M`（加修正值，每年 × 0.95） |

## 開國

| 開局時代 | 初始王朝 |
|---|---|
| 上古 | 無；所有州郡無主 |
| 中古 | 4–6 個，覆蓋約 70% 陸地 |
| 末法 | 2–3 個大國 |

建國的途徑：
- **立國**（每年判定）：無主州郡中，人口 ≥ 50,000 的州若有才略 ≥ 8 的散人或武將候補，以 2% 機率立國。立國時取得該州及無主的陸鄰。
- **起義**、**割據**、**內戰**：見下方「天命的效果」與「繼承」。

新王朝天命初值 60；國庫初值為一年收入。

## 天命（每年）

```
ΔM = 0.5 × (君主德行 − 5)
   + 0.4 × (文臣平均德行 − 5)          （無文臣時此項為 0）
   + 10 × 疆域平均正氣
   − 15 × 疆域平均業氣
   + 4 × (都城靈氣 − 0.5)               （風水）
   − 0.5 × 本年饑荒州數                  （2.3）
   + 1 × 本年新得州數 − 3 × 本年失去州數
   − min(3, 立國年數 / 100)              （王朝週期）
```

- 天象（4.2）立即 ±15；篡位 −20；國庫不足時每年 −5。
- 截斷在 0..100。

## 天命的效果

| 天命 | 效果 |
|---|---|
| ≥ 80 | 盛世：疆域人口成長率 +50%；可封禪（下） |
| 40–79 | 正常 |
| < 40 | **起義**：每州每年 `(40 − M) / 400` 機率出現叛軍（3.9）。首領為該州才略最高的散人或武將候補；沒有時建立新魂，以 25 歲出生在該州 |
| < 20 | **割據**：每位駐守非都城州的武將，每年 `(20 − M) / 200` 機率據州自立為新王朝。取得駐地及相連的本國州郡中，距離駐地比距離都城近者 |
| 0 | **崩潰**：所有州郡無主；王族成為散人 |

## 繼承

1. 君主死亡 → 最年長的在世儲君繼位。
2. 無儲君 → 才略最高的武將或文臣**篡位**（天命 −20）。
3. 若前兩名候選人才略差 ≤ 1：35% 機率**內戰**。
   - 以兩人的駐地為核心，依距離瓜分疆域，成為兩國，互相宣戰。

## 文臣與武將

| 職位 | 員額 | 來源 | 駐地 |
|---|---|---|---|
| 文臣 | `2 + 州數 / 5`，上限 10 | 疆域內書院、散儒；依「德行 + 才略」挑選（3.8） | 都城 |
| 武將 | `1 + 州數 / 4`，上限 12 | 疆域內武將候補、王族；依才略挑選 | 依序駐守：與敵國接壤的州 → 與無主州接壤的州 → 都城 |

- 每年補足缺額；無人可補時維持缺額。

## 國策與詔令

### 國策（即位時決定，在位不變）

| 國策 | 條件 | 效果 |
|---|---|---|
| 尊道 | 君主道緣中道最高 | 疆域內宗門聲望修正 +2 / 年；可聘國師：疆域內聲望最高宗門的最強長老，隨主力軍出征（3.9） |
| 尊佛 | 釋最高 | 寺院的王朝壓制 −0.5（3.6） |
| 尊儒 | 儒最高 | 書院的立德、立功 +50%；疆域正氣 +0.01 / 年 |
| 無 | 魔最高 | — |

### 詔令（在位期間每年判定，頒布後鎖定到駕崩）

| 詔令 | 條件與機率 | 效果 |
|---|---|---|
| 滅佛 | 見 3.6 | 見 3.6 |
| 禁道 | 君主道緣中道 < 0.15，且疆域內有聲望 ≥ 100 的宗門；每年 5% | 宗門與王朝關係 −100；宗門聲望修正 −5 / 年；每年 10% 機率爆發宗門與王朝之戰（3.9） |

## 財政（每年）

| 項目 | 公式 |
|---|---|
| 收入 | 疆域稅收總和（2.3） |
| 常備軍 | 疆域人口 × 0.005，平時分駐武將所在州 |
| 軍費 | 每千兵（常備軍 + 動員軍）每年 20 |
| 官俸 | 每位文臣、武將每年 5 |
| 宮廷 | 收入 × 10% |
| 賑災 | 天命 ≥ 40 且國庫 > 一年支出時，對每個饑荒州支出 `饑荒死者 × 0.001`，救回其中一半（主事文臣 G += 救活人數 / 2,000） |

- **年支出** = 軍費 + 官俸 + 宮廷（不含賑災）。
- 國庫上限 = 5 年收入；超出部分視為耗散（貪腐）。
- **國庫不足**：國庫 < 年支出。此時：
  - 天命每年 −5。
  - 動員軍每月流失 5%。
  - 才略最高的武將有 50% 機率叛離自立（同割據）。

## 擴張（每年）

- **軍力** = 常備軍 + 可動員兵力（3.9 動員公式的總和）。
- 天命 ≥ 50 且國庫 ≥ 兩年支出時，判定：
  - **開疆**：吞併一個相鄰的無主州郡，機率 20%。
  - **宣戰**：對相鄰王朝，在「我方軍力 ≥ 對方 1.3 倍，且關係 < 0」時，機率 10%（3.9）。
- **關係**：每年向 0 回歸 10%；接壤 −5 / 年；同國策 +5 / 年；議和 +30。

## 封禪

- **條件**：天命 ≥ 90 持續 30 年，且君主德行 ≥ 8。一位君主一生一次。
- **效果**：
  - 君主的魂 G + 300；君主立功 + 50（3.8）。
  - 天命 +10；都城正氣 +0.2。
- **地圖表現**：金色雲氣環繞都城（5.6）。
