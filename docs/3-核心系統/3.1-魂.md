# 3.1 魂

本作的模擬主角。肉身（有名之人，見 3.4）死去，魂繼續輪迴。用語「轉世」與「世」的區別見 3.2。

## 欄位

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | SoulId | 永久不變；0 號保留給「天道」（4.4） |
| `merit` G | f32 ≥ 0 | 功德累積 |
| `sin` S | f32 ≥ 0 | 業障累積 |
| `wisdom` W | f32 0..200 | 宿慧：前世修為留下的悟性 |
| `affinity` | [f32; 4] | 道緣：道、釋、儒、魔，和為 1 |
| `threads` | Vec<ThreadId> | 宿緣（3.3） |
| `lives` | Vec<PersonId> | 歷次轉世的肉身，依序 |
| `best_prev` | Achievements | 前世最高成就（天書偵測用）；`Achievements { realm: Option<u8>, fruit: Option<u8>, immortality: f32 }`：最高境界、最高果位、最高三不朽總和 |
| `best_now` | Achievements | 今生成就，結構同上；轉世時併入 `best_prev`（逐項取較大），再清空 |
| `power` P | f32 ≥ 0 | 魂力：新魂 720；每次轉世與在惡道的年數消耗，耗盡則魂散（見「魂力與魂散」） |
| `born` | Tick | 魂誕生的時刻；魂齡 = 魂散（或現在）− 誕生 |
| `last_place` | (ProvinceId, u32) | 最後所在州郡與格；一端不在世時，因果線懸在此處（5.4） |
| `state` | 見下 | 目前所處 |
| `origin` | 見下 | 怎麼來的 |
| `marks` | 位元旗標 | 修羅、怨靈、菩薩願、曾入魔、曾被地獄引渡；另有三個暫存旗標「前世入魔、前世兵解、前世被度化」，死亡時設定、下次轉世處理後清除（供宿慧與道緣傳承用）。修羅印記在每次六道判定時重設 |

### 狀態 `state`

| 狀態 | 說明 |
|---|---|
| `Incarnate(PersonId)` | 在世為人或妖 |
| `Bardo { until }` | 中陰，等待判定 |
| `Realm { path, until }` | 在天道、畜生道（為獸）、餓鬼道、地獄道中，期滿返回判定 |
| `Waiting { until, for_souls }` | 判入人道後，等待宿緣對象出生（3.2） |
| `Liberated { way, tick }` | 已超脫：飛升、涅槃、成聖，永久離開 |
| `Dissolved { tick }` | 魂散：魂力耗盡，散入天地，永久離開輪迴；宿緣線斷（3.3「斷」） |

### 來源 `origin`

| 來源 | 產生方式 |
|---|---|
| 先天 | 開天時建立（4.6） |
| 新魂 | 勢力缺額、州郡滋生妖、人間補魂（3.4）等情況下，若沒有合適的轉世魂且未達上限，則新建 |
| 怨靈 | 大量無辜死亡時產生；帶有對加害者的怨線，道緣偏魔 |

## 功德與業障

只有「有名之人」的行為會改變魂的 G 與 S。凡人的善惡反映在州郡氣場（2.4）。

| 行為 | 效果 | 備註 |
|---|---|---|
| 殺死有名之人（一般） | 兇手 S += 10 × 無辜係數；建立殺業線（3.3） | 無辜係數：死者淨業力 ≥ 0 為 1；< 0 為 0.3 |
| 斬殺惡人：死者 S > G + 50 | 兇手 G += 5；**不**建立殺業線 | 斬妖除魔；判斷看死者，不看兇手 |
| 指揮戰爭 | 主將 S += 我方殺敵數 / 5,000 | 正義之戰減半；正義之戰的定義見 3.9 |
| 屠城 | 下令者 S += 100 + 死者 / 1,000；產生怨靈 | 每 1 萬死者產生 1 個怨靈，最多 5 個 |
| 傳道授業 | 師父每收一徒 G += 2 | — |
| 僧人修行 | 每年 G += 1 + 悟性 × 0.2 | 3.6 |
| 德政 | 君主、文臣每年 G += max(0, 德行 − 5) × 0.5 | — |
| 暴政 | 君主每年 S += max(0, 戾氣 − 6) × 0.5 | 有大儒在朝時減半（3.8） |
| 救災 | 主事者 G += 救活人數 / 2,000 | 3.7 賑災 |
| 度化 | 度人者 G += 20；被度者 S × 0.7 | 3.6 |
| 未了殺業線、怨線（利息） | 欠債方每次轉世出生時，先 S += 線強度 × 0.1（以舊強度），再線強度 × 1.1（上限 100） | 3.3 |

**淨業力** = G − S，決定六道去處（3.2）。

境界與果位一律從 0 起算：境界 0 = 煉氣、8 = 大乘（3.5）；果位 0 = 沙彌、1 = 比丘、2 = 羅漢、3 = 菩薩、4 = 佛（3.6）。

## 宿慧

- 轉世時：`W_new = W_old × 0.5 + 前世成就`，截斷在 0..200。
- 前世成就：

  | 前世身分 | 加成 |
  |---|---|
  | 修士、魔修、妖 | 前世最高境界 × 8 |
  | 僧人 | 果位 × 15 |
  | 儒士 | 三不朽總和 / 10 |
  | 其他 | 0 |

- 兵解（3.5）另 +30。
- 宿慧提高今生的根骨與悟性（3.4），讓前世大能轉世後進境更快——這是「轉世大能」故事的來源。

## 道緣

### faith4

州郡的四維教化向量，用於道緣傳承與因果牽引：
`faith4 = (道, 釋, 儒, 濁氣 × 0.5)`，若總和為 0 則取均等，再正規化。三維 faith 見 2.3。

### 傳承與修正

- 每次轉世：`affinity = normalize(0.7 × 前世道緣 + 0.3 × 出生州 faith4)`。
- 前世入魔者，魔 +0.2；被度化者，釋 +0.3；之後再正規化。
- 道緣決定今生在 12 歲「入道」時的方向（3.4）。

## 魂力與魂散

一個魂不是永遠輪迴下去：它帶著有限的魂力，每轉世一次、在惡道待上多少年都在消耗，耗盡就散入天地。超脫（飛升、涅槃、成聖）是另一種結束；魂散是沒能超脫的魂的自然盡頭。

### 消耗

| 事件 | 消耗魂力 | 時點 |
|---|---|---|
| 轉世（判入人道、阿修羅道而出生） | `SOUL_REBIRTH_COST` ÷ 減緩係數 | 出生那一刻（3.2） |
| 為獸 | 每年 `SOUL_BEAST_COST_PER_YEAR` ÷ 減緩係數 | 入畜生道時依停留年數一次扣完 |
| 餓鬼道 | 每年 `SOUL_HUNGRY_COST_PER_YEAR` ÷ 減緩係數 | 同上 |
| 地獄道 | 每年 `SOUL_HELL_COST_PER_YEAR` ÷ 減緩係數 | 同上 |
| 天道、中陰、等待 | 不消耗 | — |

在世的年數本身不消耗魂力，消耗只算轉世的次數：一世越長，同樣的魂力撐得越久，所以長壽的修士一世就占去數百上千年，魂也跟著活得久。

**減緩係數**（≥ 1）使修為高、功德多、宿慧深者消耗得慢：

```
減緩 = 1 + SOUL_EASE_RANK × 修為階²
         + SOUL_EASE_MERIT × ln(1 + G / SOUL_EASE_MERIT_SCALE)
         + SOUL_EASE_WISDOM × min(W, SOUL_EASE_WISDOM_FULL) / SOUL_EASE_WISDOM_FULL
```

修為階 0..9：歷世（`best_prev` 與 `best_now`）最高境界 +1（煉氣 1、大乘 9）、最高果位 +1 後乘 2（沙彌 2、佛 10，上限 9）、三不朽總和 ÷ `SOUL_EASE_IMMORTAL_DIV` 三者取最大；沒有修為為 0。修為項二次方成長，所以高修為者的減緩遠大於一般人，少數魂因此活到數萬年；功德項取對數，功德再多也不會無限放大。

### 魂散

魂力不夠再扣（扣完 ≤ 0）時，該次轉世或入道改為魂散：

1. 魂的狀態改為 `Dissolved { tick }`，`power` 歸零，永久離開輪迴；不再中陰、不再判定、不再被因果牽引選中。
2. 該魂每一條未了的宿緣線同時**斷**（3.3）。
3. 寫入一筆 `SoulDissolved`（7.2）：因為最後一世的最近事件（身故，或在惡道魂散時為那筆 `Judged`），人物為最後一世的肉身，參數為魂齡年數、轉世次數與斷掉的宿緣數。
   - 重要度 2；魂有強度 ≥ 50 的未了宿緣、或歷世最高境界達化神者為 3。
   - 理由：魂散是常事（平均每個魂活約一萬年，全世界每年約有數個），但對有強度宿緣的另一端和高修為者是一件值得記的事，所以升到 3；一般的魂散同月合成一則統計進傳聞簽（7.2），不洗版。
4. 魂散騰出的名額**由新魂補上**：`soul_vacancies` 加一，每年年度補魂（3.4）把空缺補成新魂（G = S = W = 0、魂力 720），名額上限不變，所以在世有名之人與魂的總數不因魂散下滑。
5. 魂散者不計入超脫；超脫的統計（每運 6.x、4.5）不變。

魂散的魂不會再轉世，但歷世留下的因果帳事件、人物生平仍在；人物卡的小傳在該魂最後一世的結尾寫一句「魂力耗盡，魂散入天地」（5.12）。

### 魂齡與紀元

設計目標（訪談第 66 輪，紀元最短 8,000、中位約 15,000 年）：

- 魂齡（誕生到魂散）平均約一萬年；
- 跨 1–2 個紀元的魂占絕大多數；
- 少數魂活到數萬年成為老怪，才會跨過多個紀元。

量測（`siming-cli soul-age`，Small 世界、種子 7、接手年 11000 起跑 45,000 年；紀元以最短 8,000、中位 15,000 年的指數尾分布模擬，每魂抽 40 組）：

- 接手後 5,000 年內誕生的 507 個魂（群體，沒有右截尾偏誤）：魂齡平均 9,730、中位 9,018、P90 13,589、P99 17,935、最長 19,991 年。全部 11,337 個魂散者平均 8,917、最長 29,673 年（跑完 45,000 年時，長壽者還沒散，平均偏低）。
- 一個魂跨越的紀元數（群體魂散者）：1 個 48.8%、2 個 48.9%、3 個 2.4%、4 個以上 0%；全部魂散者跨 1–2 個占 98.2%。
- 魂散者平均轉世 414 次。在輪迴的魂減緩係數平均 7.2、P99 17.0、最大 20.5。
- 全世界魂的總數：對照組（每年補滿魂力、不魂散）固定 2,845 個；有魂散時在世與中陰合計 2,260–2,820（穩態約 2,300）。45,000 年內累計新建 13,602 個，魂散 11,337 個。

老怪（魂齡 ≥ 3 萬年）在這組參數下只有零星個（最長 29,673 年），尚未形成穩定的數萬年尾巴；占比是否要拉高，待老闆裁定。魂散者一生跨 3 個以上紀元的只有約 2%。

### 與門人層的關係

門人層（3.4）第二步上線後，沒有出頭的一世也是一次轉世、同樣消耗魂力；程式在那一步接上，常數屆時依量測重新校準。目前有名之人從出生起建立，每世都記。

## 數量控制（中尺寸）

| 項目 | 穩態目標 |
|---|---|
| 在世魂（有名之人） | 2,000–4,000；上限 `NOTABLE_CAP` |
| 中陰、等待、他道中的魂 | 1,000–3,000 |
| 每運超脫 | 飛升 1–3、涅槃 0–3、成聖 0–2 |

- 達到上限時：延後出生並暫停建立新魂（3.2）。
- 魂散騰出的名額由年度補魂補上新魂（見「魂力與魂散」）。
- 低於下限時：勢力缺額由新魂補足；全世界在世有名之人低於 `NOTABLE_FLOOR`（= `NOTABLE_CAP × 0.5`）時，另有「人間補魂」建立新魂（3.4）。
