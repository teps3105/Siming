# 3.1 魂

本作的模擬主角。肉身（有名之人，見 3.4）死去，魂繼續輪迴。用語「轉世」與「世」的區別見 3.2。

## 欄位

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | SoulId | 永久不變；0 號保留給「天道」（4.4） |
| `merit` G | f32 ≥ 0 | 功德累積 |
| `sin` S | f32 ≥ 0 | 業障累積 |
| `wisdom` W | f32 0..200 | 宿慧：前世修為留下的悟性 |
| `affinity` | [f32; 4] | 道緣：道、釋、儒、魔，和為 1 |
| `threads` | Vec<ThreadId> | 宿緣（3.3） |
| `lives` | Vec<PersonId> | 歷次轉世的肉身，依序 |
| `best_prev` | Achievements | 前世最高成就（天書偵測用）；`Achievements { realm: Option<u8>, fruit: Option<u8>, immortality: f32 }`：最高境界、最高果位、最高三不朽總和 |
| `best_now` | Achievements | 今生成就，結構同上；轉世時併入 `best_prev`（逐項取較大），再清空 |
| `last_place` | (ProvinceId, u32) | 最後所在州郡與格；一端不在世時，因果線懸在此處（5.4） |
| `state` | 見下 | 目前所處 |
| `origin` | 見下 | 怎麼來的 |
| `marks` | 位元旗標 | 修羅、怨靈、菩薩願、曾入魔、曾被地獄引渡；另有三個暫存旗標「前世入魔、前世兵解、前世被度化」，死亡時設定、下次轉世處理後清除（供宿慧與道緣傳承用）。修羅印記在每次六道判定時重設 |

### 狀態 `state`

| 狀態 | 說明 |
|---|---|
| `Incarnate(PersonId)` | 在世為人或妖 |
| `Bardo { until }` | 中陰，等待判定 |
| `Realm { path, until }` | 在天道、畜生道（為獸）、餓鬼道、地獄道中，期滿返回判定 |
| `Waiting { until, for_souls }` | 判入人道後，等待宿緣對象出生（3.2） |
| `Liberated { way, tick }` | 已超脫：飛升、涅槃、成聖，永久離開 |

### 來源 `origin`

| 來源 | 產生方式 |
|---|---|
| 先天 | 開天時建立（4.6） |
| 新魂 | 勢力缺額、州郡滋生妖、人間補魂（3.4）等情況下，若沒有合適的轉世魂且未達上限，則新建 |
| 怨靈 | 大量無辜死亡時產生；帶有對加害者的怨線，道緣偏魔 |

## 功德與業障

只有「有名之人」的行為會改變魂的 G 與 S。凡人的善惡反映在州郡氣場（2.4）。

| 行為 | 效果 | 備註 |
|---|---|---|
| 殺死有名之人（一般） | 兇手 S += 10 × 無辜係數；建立殺業線（3.3） | 無辜係數：死者淨業力 ≥ 0 為 1；< 0 為 0.3 |
| 斬殺惡人：死者 S > G + 50 | 兇手 G += 5；**不**建立殺業線 | 斬妖除魔；判斷看死者，不看兇手 |
| 指揮戰爭 | 主將 S += 我方殺敵數 / 5,000 | 正義之戰減半；正義之戰的定義見 3.9 |
| 屠城 | 下令者 S += 100 + 死者 / 1,000；產生怨靈 | 每 1 萬死者產生 1 個怨靈，最多 5 個 |
| 傳道授業 | 師父每收一徒 G += 2 | — |
| 僧人修行 | 每年 G += 1 + 悟性 × 0.2 | 3.6 |
| 德政 | 君主、文臣每年 G += max(0, 德行 − 5) × 0.5 | — |
| 暴政 | 君主每年 S += max(0, 戾氣 − 6) × 0.5 | 有大儒在朝時減半（3.8） |
| 救災 | 主事者 G += 救活人數 / 2,000 | 3.7 賑災 |
| 度化 | 度人者 G += 20；被度者 S × 0.7 | 3.6 |
| 未了殺業線、怨線（利息） | 欠債方每次轉世出生時，先 S += 線強度 × 0.1（以舊強度），再線強度 × 1.1（上限 100） | 3.3 |

**淨業力** = G − S，決定六道去處（3.2）。

境界與果位一律從 0 起算：境界 0 = 煉氣、8 = 大乘（3.5）；果位 0 = 沙彌、1 = 比丘、2 = 羅漢、3 = 菩薩、4 = 佛（3.6）。

## 宿慧

- 轉世時：`W_new = W_old × 0.5 + 前世成就`，截斷在 0..200。
- 前世成就：

  | 前世身分 | 加成 |
  |---|---|
  | 修士、魔修、妖 | 前世最高境界 × 8 |
  | 僧人 | 果位 × 15 |
  | 儒士 | 三不朽總和 / 10 |
  | 其他 | 0 |

- 兵解（3.5）另 +30。
- 宿慧提高今生的根骨與悟性（3.4），讓前世大能轉世後進境更快——這是「轉世大能」故事的來源。

## 道緣

### faith4

州郡的四維教化向量，用於道緣傳承與因果牽引：
`faith4 = (道, 釋, 儒, 濁氣 × 0.5)`，若總和為 0 則取均等，再正規化。三維 faith 見 2.3。

### 傳承與修正

- 每次轉世：`affinity = normalize(0.7 × 前世道緣 + 0.3 × 出生州 faith4)`。
- 前世入魔者，魔 +0.2；被度化者，釋 +0.3；之後再正規化。
- 道緣決定今生在 12 歲「入道」時的方向（3.4）。

## 數量控制（中尺寸）

| 項目 | 穩態目標 |
|---|---|
| 在世魂（有名之人） | 2,000–4,000；上限 `NOTABLE_CAP` |
| 中陰、等待、他道中的魂 | 1,000–3,000 |
| 每運超脫 | 飛升 1–3、涅槃 0–3、成聖 0–2 |

- 達到上限時：延後出生並暫停建立新魂（3.2）。
- 低於下限時：勢力缺額由新魂補足；全世界在世有名之人低於 `NOTABLE_FLOOR`（= `NOTABLE_CAP × 0.5`）時，另有「人間補魂」建立新魂（3.4）。
