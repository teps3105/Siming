# 3.11 量劫

給無盡的沙盒一個呼吸節奏：前段累積、後段緊張、劫後清算。

## 時程

| 時間（每運之內） | 階段 | 表現 |
|---|---|---|
| 第 1–11 世 | 累積 | 一般推演 |
| 第 12 世（最後 30 年） | 劫兆 | 頂欄出現量劫預測（0–10 成）；天色隨預測強度逐年轉暗轉紅；傳聞「天象有異」 |
| 最後 3 年 | 量劫 | 天災、魔潮、清算依序發生（下） |
| 運末最後一個月 | 結算 | 自動暫停，顯示結算畫面（5.8） |

## 強度

```
I = clamp(
      Σ_州郡(業氣 × 人口) / Σ_州郡(人口)
    + 天道業障 / 200
    − Σ_州郡((功德 + 正氣) × 人口) / Σ_州郡(人口) × 0.5
    + (魔劫中 ? 0.2 : 0),
    0, 1)
```

顯示為 0–10 成（四捨五入）。劫兆期間每年重新預測。

## 量劫內容（最後 3 年，每年執行一次）

| 項目 | 規則 |
|---|---|
| 天災 | 每州以機率 `I × (0.3 + 業氣)` 遭災：人口 −10–40%、殘破度 +0.4、業氣 +0.05 |
| 清算 | 每位有名之人以機率 `I × S / (S + 150)` 隕落（死因：量劫） |
| 靈脈受損 | 每個洞天福地以機率 `I × 0.3` 降一級（福地則消失）；重算靈氣 |
| 天命動搖 | 每個王朝天命 −30 × I |
| 魔潮 | 若魔勢 > 0.5：每個魔窟立即產生魔軍 |

## 結算

- **本運超脫**：飛升、涅槃、成聖的名單與人數。
- **文明**：
  - 人口變化（運初對比運末）。
  - 王朝存續與更替次數。
  - 勢力數。
- **天道之秤**：本運天道業障的增減。
- **天書**：本運新增的條目。
- **評價**：依下表由上而下判定，取第一個符合者，作為天書中的運評。

| 評價 | 條件 |
|---|---|
| 天道自誤 | 人口減少 50% 以上，且天道業障 / 200 占強度 I 的一半以上 |
| 浩劫 | 人口減少 50% 以上 |
| 大治 | 超脫 ≥ 6，且人口成長 |
| 小康 | 超脫 ≥ 3 |
| 平 | 其餘 |

## 劫後

- 天道業障 × 0.5（劫後清算）。
- 所有以天道為一方的怨線消散（不算了結）。
- 所有州郡業氣 × 0.3。
- 文明重建：人口低於峰值 10% 的州郡，承載上限暫時 +50%，持續 1 世。
- 進入下一運。
