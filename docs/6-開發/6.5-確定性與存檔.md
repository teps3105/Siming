# 6.5 確定性與存檔

同一個種子、同一份開局設定與同一串指令，必須在任何機器上算出位元相同的世界；存檔與分享碼都建立在這一點上。本節定義達成確定性的規則、世界雜湊與存檔格式。

## 規則

1. 相同種子 + 相同開局設定 + 相同指令序列（含 tick）⇒ 位元級相同的世界。
2. **隨機數**：只用 `rand_chacha::ChaCha8Rng`；依固定標籤派生子流，各系統只用自己的子流。

   | 子流 | 用途 |
   |---|---|
   | `worldgen` | 世界生成 |
   | `genesis` | 開天 |
   | `soul` | 輪迴判定 |
   | `people` | 有名之人 |
   | `powers` | 勢力 |
   | `war` | 戰爭 |
   | `field` | 氣場 |
   | `cosmos` | 魔劫、量劫 |
   | `command` | 權能 |
   | `evolution` | 天地演變（2.8） |

   宿緣（3.3）的相遇與衝突使用 `people` 子流；`soul` 子流專供輪迴判定。

   新增系統時新增子流，不影響其他系統的序列。`RngStreams` 在 M2 補上 `genesis`、`soul`、`people`、`powers` 子流（M1 只有 `worldgen`）。
3. **迭代順序**：只迭代 `Vec`、`BTreeMap`、`BTreeSet`；禁止迭代 `HashMap`、`HashSet`（可用作查詢）。
4. **浮點**：
   - 只做 IEEE 754 基本運算與 `std` 的 `exp`、`ln`、`sqrt`、`powf`。
   - 跨平台差異以固定期望值的雜湊測試把關（`tests/determinism.rs` 的 `gdd_6_5_golden_hash_is_stable_across_platforms`：種子 20261011 在開天後與再推進 30 年後的雜湊；目前為 `9f4f0b1b311aae3f` 與 `77c5f774e02c4d48`）；Windows 與 Linux 跑同一個測試，值不同即表示有平台差異，屆時改用 `libm`。模擬規則有意改動時要同步更新期望值。
5. 模擬中不讀系統時間、不使用執行緒。
6. **場域**（6.9）：傳輸只用快照、依 ID 升冪寫回；門檻判定機率 > 0 才抽樣；衍生場不保存、不雜湊。

## 世界雜湊

`World::hash()`：依固定順序把所有欄位餵入 FxHasher 的 64 位元版本。只支援 64 位元目標（長度與雜湊器的內部狀態都是指標寬度），程式以編譯期檢查擋下其他目標。用於測試與分享碼驗證。格域與州域場依 `FieldId` 順序餵入（6.9）；新增一維時在列舉末尾追加並遞增 `sim_version`。M2 起納入新欄位：魂（含 `best_prev`、`best_now`、`last_place`）、有名之人（含 `path`、`disciples`、`children`、`last_event`）、宿緣（含 `lives_base`、`master_best`）、勢力（含宗門欄位與 `relations`）、因果帳、世界天書、`kill_pairs`、`follows`。

## 存檔格式

```rust
pub struct SaveFile {
    pub magic: [u8; 4],           // b"SMGS"
    pub sim_version: u32,         // 模擬規則版本，規則改變時遞增
    pub params: WorldParams,      // 含最終種子
    pub commands: Vec<(Tick, Command)>,
    pub tick: Tick,               // 存檔時刻
    pub hash: u64,                // 存檔時刻的世界雜湊
    pub snapshot: Option<Vec<u8>>,// 最近一運開始時的 bincode 快照（加速載入）
    pub snapshot_tick: Tick,
}
```

- **載入**：
  1. 有快照且版本相符：反序列化快照。
  2. 否則從頭重建。
  3. 重播 `snapshot_tick` 之後的指令，推進到 `tick`。
  4. 驗證 `hash`。
- 雜湊不符時：拒絕載入，並提示「天機紊亂」，附上除錯資訊。
- 分享碼：同一結構但不含快照（4.8）。

### M2 實作（U9）

- 格式為 `serde_json`（`native/sim/rust/crates/sim/src/save.rs`）；`bincode` 快照尚未實作，`snapshot` 欄位保留且恆為 `None`，載入時忽略。`sim_version` 目前為 3（洞天福地記下生成時的等級、靈氣改以靈潮為倍率時遞增）。
- `commands` = 已套用的指令（依 tick 遞增）+ 存檔時尚未套用的排隊指令（tick 記為存檔 tick + 1）。載入時先重播到存檔 tick，再把排隊指令放回佇列。
- 載入 = `Sim::new(params)`（世界生成 + 開天 + 預跑）後，依指令 tick 重播並比對 `hash`；不符回 `SaveError::Desync`（天機紊亂）。`Sim::load_with` 允許測試注入開局。
- 世界雜湊以 serde 走訪（`hash_ser.rs`）納入所有 M2 欄位（含因果帳的 `prune_cursor`、`emit_cursor`）、天地演變的慢變量、週期、所在時期與開局前的歷史年數（2.8）與七條 RNG 子流狀態；之後新增的可序列化欄位自動納入。
- 常態分佈以 Marsaglia 極座標法抽樣（只用 `ln`、`sqrt`）；整數次方以連乘計算（不用 `powi`）。新程式碼不得使用三角函數等未列出的 `std` 浮點函式；需要時使用 `worldgen` 的多項式實作。
