# 6.6 平台與建置

遊戲以 Godot 4.7.1 匯出，目標是 Windows 與 Linux（含 Steam Deck）；Rust 部分用 stable 工具鏈建置成 GDExtension 程式庫後由 Godot 載入。本節列出目標平台、建置步驟、字型子集化與持續整合的工作。

## 目標平台

| 目標 | 建置 | 備註 |
|---|---|---|
| Windows x64（Demo 必要） | 橋接程式庫 release ＋ Godot 匯出 | 9.4 |
| Linux x64、Steam Deck | 同上，於 Linux 建置 | 同一份 Linux 建置 |
| macOS | — | Demo 不提供 |
| 瀏覽器 | — | 不在範圍（決策 #39，6.10） |
| 無頭 | `cargo run -p siming-cli --release -- <子命令>` | 持續整合與平衡調整；不需要 Godot |

## 工具版本

| 工具 | 版本 | 來源 |
|---|---|---|
| Godot | 4.7.1 stable | 編輯器與匯出範本 |
| Rust | stable，1.94 以上 | `godot` crate 0.5.5 的 `rust-version` |
| `godot` crate（gdext） | 0.5.5，feature `api-4-7` | <https://crates.io/crates/godot/0.5.5> |

## 建置橋接程式庫

```
python tools/native_build/build.py            # debug
python tools/native_build/build.py --release  # release
```

1. 在 `native/sim/rust/` 執行 `cargo build -p siming-gdext`。
2. 把 `target/<設定>/` 下的程式庫複製到 `game/modules/sim/generated/`，檔名為 `siming_gdext.<debug|release>.dll`（Linux 為 `libsiming_gdext.<debug|release>.so`）。
3. `game/modules/sim/resources/siming.gdextension` 依平台與設定載入對應檔案。

`generated/` 下的程式庫不提交；取得原始碼後要先建置一次，編輯器才認得 `SimWorld`。擴充設定為可重新載入，編輯器開著時重建即可生效。

## 匯出

1. 以 release 建置橋接程式庫。
2. Godot 以 `game/export_presets.cfg` 的設定匯出到 `builds/<目標>/`（`windows`、`linux`）。
3. Steam 版另以 `--features steam` 建置橋接程式庫，並附上 Steamworks 再發行檔（9.2）。

`export_presets.cfg` 在第一次設定匯出時建立。

## 字型子集化（`tools/font_subset/subset_font.py`）

1. 掃描下列檔案中的 CJK 字元：
   - `native/sim/rust/crates/**/*.rs`
   - `native/sim/rust/crates/sim/data/*.json`（命名字庫，7.3）
   - `game/modules/locale/resources/*.json`（事件模板與介面字串，8.6）
2. 加上常用字表（教育部常用字 4,808 字，確保數字與標點）。
3. 以 fontTools 產生 `game/modules/ui_kit/assets/fonts/wenkai_tc_subset.ttf`、`wenkai_sc_subset.ttf`（9.5）。
4. 子集字型提交到版本庫；原始字型不提交。
5. 驗收：子集字型 ≤ 3.5 MB。

GDScript 與場景檔中寫死的中文字不在掃描範圍；顯示文字一律放 `locale` 的 JSON（9.5）。

## 持續整合（GitHub Actions）

| 工作 | 內容 |
|---|---|
| `check` | 在 `native/sim/rust/` 執行 `cargo fmt --check`、`cargo clippy -D warnings`、`cargo test -p siming-sim` |
| `determinism` | 確定性測試（6.7）；Windows 與 Linux 跑同一劇本並比對雜湊 |
| `build` | Windows、Linux 的橋接程式庫（含 `steam` feature）與 Godot 匯出 |
| `l10n` | 繁簡字庫條目數一致；簡體檔與 `t2s.py` 產生結果一致（9.5） |
| `balance` | `siming-cli sim` 跑 3 個種子各 1 運，輸出統計報表為 artifact（不判失敗，只記錄） |

這些工作流程檔尚未建立。
