# 6.3 推演流程

`Sim::step()` 推進一個月。系統依下列固定順序執行；同一步內依 ID 升冪處理。每步標明使用的隨機子流（6.5）。

## 觸發條件

| 名稱 | 條件（`tick` 從 1 起算，開天後第一個月為 1；預跑也推進 tick 1..=120，4.6） |
|---|---|
| 每月 | 每次 |
| 每季 | `tick % 3 == 0` |
| 每年 | `tick % 12 == 0` |
| 每世 | `tick % 360 == 0` |
| 劫兆期 | `tick % 4320 > 3960` 或 `tick % 4320 == 0`（每運最後 30 年） |
| 量劫年 | 劫兆期內，且 `tick % 4320 > 4284` 或 `== 0`，並且是每年 |
| 運末 | `tick % 4320 == 0` |

## 通則

- 所有對州域場（人口、殘破、業氣、功德、正氣……）的寫入經由 `field::add`（6.9），寫入即截斷在值域內；同一步驟內一個場只由一個系統寫入（6.9 耦合矩陣）。
- 任何步驟中，已死者一律跳過。
- 冷卻與遊歷期間以月數計（例如 3 年 = 36 個月）。
- 步驟 14 的處理順序見 3.3「相遇」。
- 預跑（4.6）期間事件照常寫入因果帳，但不進傳聞、不觸發奇觀、不給天機。

## 隨時觸發的處理

### 死亡（任何步驟中發生時立即執行）

1. 寫入死亡事件（或超脫事件）。
2. 魂：
   - 超脫 → `Liberated`。
   - 否則 → 進入中陰，`until = tick + 2`。
3. 勢力：成員移除；首領死亡時，依勢力種類觸發繼承（宗門、寺院、書院、王朝），在本步驟內完成。
4. 人際：配偶、師徒關係解除（宿緣保留）。
5. 有殺者時：依 3.1 計業，必要時建立殺業線。
6. 進行中的會戰：統帥死亡時，軍隊改由下一位武將統率，沒有則無統帥。

### 出生（步驟 5、12、16 中發生）

1. 依 3.4 建立有名之人（輪迴出生寫入 `Rebirth`；`Born` 只用於新魂與開天，7.2）。
2. 魂的轉世處理：
   - 宿慧與道緣傳承（3.1）。
   - 欠債方利息：殺業線與怨線先 S += 強度 × 0.1（以舊強度），再強度 × 1.1（上限 100）（3.1）。
   - 所有相關線的 `lives` 更新（3.3）。

### 事件寫入

1. 指派 EventId，寫入因果帳。
2. 偵測天書條目，新條目寫入世界天書，首次達成給天機（4.3、4.5；M2 為空操作）。
3. 加入 `pending_events`。

## 事件輸出

- `step()` 產生的事件累積在 `pending_events`。
- 呈現層每幀呼叫 `drain_events()` 取走，用來觸發奇觀與傳聞（6.4）。
