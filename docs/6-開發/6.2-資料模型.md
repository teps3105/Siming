# 6.2 資料模型

以下為 `siming-sim` 的主要型別（Rust 示意，欄位意義見各系統章節）。

## ID

```rust
pub struct SoulId(u32);      // 0 = 天道
pub struct PersonId(u32);
pub struct PowerId(u32);     // 王朝、宗門、寺院、書院、魔門、妖域共用
pub struct ProvinceId(u16);
pub struct ThreadId(u32);
pub struct ArmyId(u32);
pub struct EventId(u32);
pub struct NodeId(u16);      // 洞天福地
pub type Tick = u32;         // 月；u32 足夠 3.5 億年
```

- 所有 ID 是 `Vec` 索引，只遞增、不重用。
- 已移除的實體保留墓碑，例如 `Person.died = Some(..)`。

## 世界

```rust
pub struct World {
    pub params: WorldParams,              // 開局設定（4.6）
    pub tick: Tick,
    pub geo: Geography,                   // 2.2：格點、州郡、靈脈
    pub provinces: Vec<Province>,         // 2.3、2.4
    pub souls: Vec<Soul>,                 // 3.1
    pub persons: Vec<Person>,             // 3.4
    pub powers: Vec<Power>,               // 2.5
    pub threads: Vec<Thread>,             // 3.3
    pub armies: Vec<Army>,                // 3.9
    pub ledger: Ledger,                   // 3.3 因果帳
    pub book: WorldBook,                  // 4.5 世界天書
    pub kill_pairs: BTreeMap<(SoulId, SoulId), u8>, // 4.5 冤冤相報：同一對魂（不分方向）累計建立的殺業線數，鍵為較小 ID 在前
    pub follows: BTreeSet<SoulId>,        // 4.7 關注（Command::Follow）
    pub siming: SimingState,              // 天機、天道業障、引渡令（4.3、4.4）
    pub cosmos: CosmosState,              // 魔勢、魔劫、量劫預測（3.10、3.11）
    rng: RngStreams,                      // 6.5
}
```

## 場域

`Geography` 的格點陣列、`Province` 的人口與氣場欄位、`LeyNode`／`LeyEdge` 的強度，都是 2.7 的場；`FieldId` 列舉（6.9）給每一維一個名字，作為雜湊順序、工具圖層與除錯面板的識別。場不另起儲存結構；統一入口 `field::{get, get_cell, add, gather, scatter}` 見 6.9。`Province` 另有 `downstream: Option<ProvinceId>`（2.3）。

## 主要結構

```rust
pub struct Geography {
    pub w: u16, pub h: u16, pub sea_level: f32,
    pub height: Vec<f32>, pub terrain: Vec<Terrain>, pub river: Vec<u8>,
    pub province_of: Vec<u16>, pub aura_cell: Vec<f32>,
    pub nodes: Vec<LeyNode>, pub ley: Vec<LeyEdge>,
    pub rivers: Vec<NamedRiver>, pub ranges: Vec<NamedRange>,
    pub wrap_x: bool,                          // 星球：東西相接（2.2）
    pub continents: Vec<Continent>, pub continent_of: Vec<u16>,
}

pub struct Soul {
    pub merit: f32, pub sin: f32, pub wisdom: f32, pub affinity: [f32; 4],
    pub threads: Vec<ThreadId>, pub lives: Vec<PersonId>,
    pub best_prev: Achievements,               // 前世最高（3.1、4.5 轉世大能）
    pub best_now: Achievements,                // 今生
    pub last_place: (ProvinceId, u32),         // 最後所在州郡與格（5.4 因果線懸掛處）
    pub state: SoulState, pub origin: SoulOrigin, pub marks: SoulMarks,
    pub guide: Option<GuideOrder>,             // 引渡令（4.2）
}

pub struct Achievements { pub realm: Option<u8>, pub fruit: Option<u8>, pub immortality: f32 }

pub enum SoulState {
    Incarnate(PersonId),
    Bardo { until: Tick },
    Realm { path: SixPath, until: Tick },      // 天、畜生（為獸）、餓鬼、地獄
    Waiting { until: Tick, for_souls: SmallVec<[SoulId; 2]> },
    Liberated { way: Liberation, tick: Tick },
}

pub struct Person {
    pub soul: SoulId, pub name: Name, pub gender: Gender,
    pub born: i32, /* 開天前出生者為負 */ pub died: Option<(Tick, DeathCause)>,
    pub province: ProvinceId, pub cell: u32,
    pub role: Role, pub power: Option<PowerId>,
    pub attrs: Attrs,                          // 根骨、悟性、才略、德行、戾氣
    pub lifespan: u16,
    pub spouse: Option<PersonId>, pub master: Option<PersonId>,
    pub disciples: Vec<PersonId>, pub children: Vec<PersonId>,
    pub last_event: Option<EventId>,           // 本人最近事件（溯因用）
    pub path: PathState,                       // 依身分，見下
    pub blessed_until: Option<Tick>, pub travel_until: Option<Tick>,
    pub home: ProvinceId, pub forced_breakthrough: Option<Tick>,
}

pub enum PathState {
    Child,                                                                              // 幼年（3.4）
    Cultivator { realm: u8, exp: f32, last_attempt: Option<Tick>, demonic: bool },      // 修士、散修、魔修（3.5）
    Monk { fruit: u8, practice: f32 },                                                  // 僧（3.6）
    Scholar { virtue: f32, deed: f32, word: f32 },                                      // 儒士（3.8）
    Mortal,                                                                             // 散人、武將候補等
    // 君主、統兵等狀態於 M3 加入（3.7、3.9）
}

pub struct Power { pub kind: PowerKind, pub relations: BTreeMap<PowerId, i8> /* 共通；其餘共通欄位見 2.5 */ }

pub struct Sect {                              // PowerKind::Sect、DemonSect（3.5、3.10）
    pub evil: bool, pub seat_province: ProvinceId, pub seat_cell: u32, pub seat_node: Option<NodeId>,
    pub prestige_mod: f32, pub radius: u8, pub members: Vec<PersonId>, pub ascended: u16,
}

pub enum PowerKind { Dynasty(Dynasty), Sect(Sect), Temple(Temple), Academy(Academy), DemonSect(Sect), BeastDomain(Domain) }

pub struct Thread {
    pub kind: ThreadKind, pub debtor: SoulId, pub creditor: SoulId,
    pub strength: f32, pub created: (Tick, EventId),
    pub lives_base: (u16, u16),                // 建線時雙方的轉世次數快照；lives 由此推得（3.3）
    pub lives: u16,
    pub master_best: Option<Achievements>,     // 師徒線：建線時師父的成就
    pub woven: bool, pub resolved: Option<(Tick, EventId)>, pub omen_at: Option<u16>,
}

pub struct Event {
    pub tick: Tick, pub kind: EventKind, pub province: Option<ProvinceId>, pub cell: Option<u32>,
    pub souls: SmallVec<[SoulId; 2]>, pub persons: SmallVec<[PersonId; 2]>, pub powers: SmallVec<[PowerId; 2]>,
    pub causes: SmallVec<[EventId; 3]>, pub importance: u8, pub args: EventArgs,
}

pub struct Ledger {
    pub events: Vec<Event>,
    pub effects: Vec<SmallVec<[EventId; 4]>>,  // 反向索引：events[i] 的「果」，供漣漪（3.3）
    pub prune_cursor: EventId,                 // 修剪游標：此 ID 之前已檢查過
    pub emit_cursor: EventId,                  // 輸出游標：此 ID 之前已由 take_new 取走
}
// 被修剪的事件留下墓碑（importance == 0），EventId 即索引不變（3.3）；讀取用 ledger::get。

pub struct WorldBook { pub entries: BTreeMap<BookEntryKind, BookRecord> }   // 4.5
pub enum BookEntryKind { /* 4.5 條目的列舉，每條一個變體 */ }
pub struct BookRecord { pub count: u32, pub first_tick: Tick, pub first_event: EventId }
```

## 事件參數

`EventArgs` 為列舉，每種事件（7.2）一個變體，只帶模板中 `{X}`、`{N}` 與結果所需的參數；`{A}`、`{B}`、`{P}`、`{F}`、`{G}` 取自 `Event` 的 `persons`、`province`、`powers`。

```rust
pub enum EventArgs {
    None,                                                      // Genesis、Born、WraithBorn、Ascended、FellToDemon、Vow、Nirvana、GreatScholar、Sage、Killed 等無額外參數者
    ComeOfAge { role: Role, joined: Option<PowerId> },         // 入{F}／自行{X}
    Married { kind: MarriageKind },                            // 夫妻／道侶
    Died { cause: DeathCause, age: u16 },                      // 死因、享年
    Breakthrough { realm: u8 },
    Tribulation { realm: u8, result: TribulationResult },      // 渡過／兵解／身死道消
    FruitAttained { fruit: u8 },
    Treatise { title: BookTitle },
    Rebirth { lives: u16, role: Role },                        // 轉世次數、身分
    Judged { path: SixPath },                                  // 六道判定結果
    Traveled { from: ProvinceId, to: ProvinceId, returning: bool }, // 出發或返回
    Thread { kind: ThreadKind, lives: u16 },                   // ThreadCreated、ThreadOmen、ThreadResolved、FeudEscalated、ThreadFaded：線種類、轉世次數
    BookEntry { entry: BookEntryKind },
    Power { detail: PowerDetail },                             // 勢力類事件的{X}：職位、爭奪對象等
    Count(u32),                                                // Famine、Plague、Massacre 等需帶人數者；KalpaOmen 的成數、KalpaSettled 的運序
    Siming { power: SimingPower, target: SimingTarget },       // 司命
    // 其餘事件依 7.2 模板補變體
}
```

- 事件文字不存在模擬中：由 `EventKind + args` 在介面端以模板產生（7.2）。
- `population::yearly` 回傳事件清單（例如 `Famine`），由 `Sim` 寫入因果帳（6.3）。

## 指令

```rust
pub enum Command {
    Follow { soul: SoulId, on: bool },        // 關注（4.7），影響天機收入
    Weave { a: SoulId, b: SoulId, kind: ThreadKind, debtor: SoulId },
    Enlighten { person: PersonId, teaching: Teaching },
    Bless { person: PersonId },
    Smite(SmiteKind),                         // Lightning{person} / Plague{province} / HeartDemon{person}
    Guide { soul: SoulId, path: SixPath, province: Option<ProvinceId> },
    Terraform(TerraformKind),                 // Raise / Flatten / SeaLand / OpenLey / CutLey
    Omen(OmenKind),                           // Auspice{dynasty} / Comet{dynasty} / Drought{province}
}
```
