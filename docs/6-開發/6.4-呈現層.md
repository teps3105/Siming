# 6.4 呈現層

呈現層是 `game/` 下的 Godot 4.7 專案（Forward+ 渲染），以 GDScript 撰寫，經由 GDExtension 類別 `SimWorld` 讀取模擬世界。本節規定橋接介面、Godot 模組的職責、模擬驅動方式與地圖資料契約；畫面規格見第 5 章。

## 橋接：`SimWorld`

`siming-gdext`（`native/sim/rust/crates/gdext/`）把一個 `Sim` 包成 Godot 的 `RefCounted` 類別 `SimWorld`。載入設定在 `game/modules/sim/resources/siming.gdextension`。

| 方法 | 回傳 | 用途 |
|---|---|---|
| `create(seed, size)` | `String`（空字串為成功，否則為失敗原因） | 開天：世界生成、開天、預跑（4.6）；`size` 為 `small`、`medium`、`large` |
| `is_ready()` | `bool` | 是否已有世界 |
| `step(months)` | — | 推進指定月數（6.3） |
| `tick()`、`date_text()`、`date_short()` | `int`、`String`、`String` | 目前 tick、曆法全稱與簡稱（2.6） |
| `hash_hex()` | `String` | 世界雜湊，16 個十六進位字元（6.5） |
| `grid_size()` | `Vector2i` | 遊戲格的寬與高；地圖的世界座標以格為單位，x 向東、z 向南 |
| `terrain_max_height()`、`terrain_height_at(x, z)` | `float` | 高度縮放為 1 時的最高點與任一點的地形高度 |
| `terrain_mesh()` | `Dictionary`：`positions`、`normals`、`uvs`、`curvature`、`indices` | 地形網格（5.3），含南北兩條極地邊疆帶 |
| `river_mesh()` | `Dictionary`：`positions`、`tangents`、`side_level`、`taper`、`indices` | 河流帶狀網格（5.3「河流」）；寬度由著色器依螢幕像素展開 |
| `map_textures()` | `Dictionary`：`terrain`、`aura`、`cls_a`、`cls_b`、`province_id`（位元組）與 `scale` | 世界貼圖（5.3「貼圖」）；州郡 ID 以 RG8 兩個位元組存放 |
| `paper_texture()`、`stroke_texture()` | `PackedByteArray` | 紙紋 512×512 RGBA8、皴法筆觸 256×256 R8（靜態方法，8.3） |
| `province_colors()` | `PackedByteArray` | 州郡 ID → 淡彩的 256×1 RGBA8 查表（5.4 天下模式） |
| `province_at(x, z)` | `int` | 該點所在格的州郡 ID，水域或圖外為 -1 |
| `province_count()`、`province_info(id)` | `int`、`Dictionary` | 州郡數與單一州郡摘要（名稱、人口、承載、各氣場、城池等級、三教教化、治所位置、格數） |
| `map_labels()` | `Array[Dictionary]` | 地圖標籤：`kind`、`text`、`pos`、`rank`（5.3「文字標籤」） |
| `ley_lines()`、`ley_nodes()` | `Array[Dictionary]` | 靈脈路徑與洞天福地（2.4、5.4） |
| `total_population()`、`alive_person_count()` | `float`、`int` | 全世界人口、在世有名之人數 |
| `follow(soul, on)` | — | 關注或取消關注一個魂（4.7）；下一個 tick 開始前生效 |
| `drain_events()` | `Array[Dictionary]` | 取走新事件：`id`、`tick`、`kind`、`importance`、`province` |

貼圖與網格的換算在橋接 crate 的 `mapbake` 模組，與引擎無關，以 `cargo test -p siming-gdext` 測試；它只讀世界資料，不改變世界狀態。

橋接的擴充規則：

- 一個方法只做一件事，回傳 Godot 內建型別；大量資料用 `Packed*Array`，不逐格跨界呼叫。
- 橋接不含規則，也不快取模擬狀態；每次呼叫都讀當下的 `World`。
- 其餘場域的烘焙與存檔的方法在實作對應功能時加入本表，先改本節再改程式。

## Godot 模組

| 模組 | 職責 | 使用的 Godot 功能 |
|---|---|---|
| `app` | 入口場景 `bootstrap.tscn`、模組裝配 | — |
| `sim` | `SimHost` 節點持有 `SimWorld`；依速度推進；把指令佇列送入模擬；把事件轉成訊號 | 訊號 |
| `map` | 地形網格、地圖著色器、貼圖更新、場域烘焙（依模式選 `FieldId` → 投影、暈染 → `field` 貼圖，6.9）、標籤 | `ArrayMesh`、`ShaderMaterial`、`ImageTexture` |
| `objects` | 建築、軍隊、劍光的批次繪製與狀態表現 | `MultiMeshInstance3D` |
| `spectacle` | 奇觀佇列與特效（5.6） | `GPUParticles3D`、`Tween` |
| `input` | 動作層、輸入模式切換、準星與吸附、鏡頭（5.2、5.9） | `InputMap`、`Camera3D` |
| `hud` | 主題、各面板與卡片（5.7、5.8） | `Control`、`Theme`、`CanvasItem` 自訂繪製 |
| `storage` | 存檔、設定、天書 | `FileAccess`（`user://`） |
| `locale` | 介面字串與事件模板（8.6） | JSON 資源 |
| `ui_kit` | 字型與跨面板共用元件 | `FontFile` |

目前存在的模組是 `app`、`sim`、`map`、`input`、`hud`、`locale`、`ui_kit`：入口場景以種子 20261011 開一個中尺寸世界，可平移、縮放、旋轉鏡頭並拉到星球視角，切換山河、天下、靈脈三種模式，控制時間，選取州郡看州郡卡。`objects`、`spectacle`、`storage` 尚未建立；地圖標籤與搖桿準星畫在 `hud` 的地圖覆蓋層。

## 模擬驅動

- 每幀預算：
  - `SimHost` 依速度計算本幀應推進的 tick 數 `n`。
  - 呼叫 `step()` 直到完成 `n` 次或用掉 8 ms。
  - 未完成者累積到下一幀，累積上限 60 tick，超過即自動降速並提示。
- 指令：介面產生的 `Command` 先放入佇列，在下一次 `step()` 前送入；同時寫入存檔的指令紀錄。
- 背景執行緒（若 100× 跟不上）：
  - `Sim` 放在橋接內的獨立執行緒。
  - 每 N tick 送出一份輕量的「可視快照」（州郡顏色、物件位置、事件）。
  - 模擬本身仍單執行緒，確定性不受影響。

## 可視同步

- **州郡顏色**：地圖模式依賴的資料變動時，重算 `province_color` 查表（256 個顏色），更新貼圖。
- **物件**：以 `PowerId` 或 `ArmyId` 對應 `MultiMesh` 的實例索引；模擬端回報新增、移除、狀態變化，只更新髒的實例。
- **軍隊位置**：每幀依 `progress` 內插。

## 地圖材質

- 以 `ShaderMaterial` 加 Godot 著色語言（`.gdshader`）實作 5.3 的著色流程。
- uniform：
  - 地圖模式
  - 高度縮放
  - 古地圖化權重
  - 因果模式權重
  - 選取的州郡
  - 時間（給雲紋與流動光點）
  - `field_ramp`：連續場的兩端點色與五階門檻（墨分五色，5.4）
  - `field_blend`：`field_prev` → `field` 的淡入淡出權重
- 貼圖：`province_id`、`province_color`、`field`、`field_prev`、`paper`、`stroke`、`cloud`。

## 地理細格（決策 #35）

模擬輸出兩層格點：遊戲格 `World::geo`（州郡、靈脈、場域）與細格 `World::fine`（`FineGeography`，每軸 2 倍）。渲染以細格為準；`SimWorld` 的地圖方法在有細格時回傳細格資料：

- `fine.scale`（= 2；0 表示開發用的手工世界，無細格，退回 `geo`）、`fine.w`、`fine.h`；細格 `(X, Y)` 屬遊戲格 `(X / scale, Y / scale)`。
- `fine.height`（u16，0..65535 ↔ 0..1，填窪後）：高度圖貼圖、山體陰影（光自西北）、海岸線（與 `fine.sea_level` 比較）、海深。
- `fine.terrain`：生態區底色；`fine.temperature`、`fine.moisture`（u8）：生態區之間的漸層（依溫度×濕度混色，不用硬邊）。
- `fine.river`（等級）、`fine.flow`（流量對數刻度 0..255）：墨線河流，線寬依 `flow`。
- 州郡、靈脈、節點、治所仍以遊戲格座標；格心換算為細格 `(x·scale + scale/2, y·scale + scale/2)`。
- 細格陣列只讀；`siming-cli gen --layer atlas` 為同一契約的參考實作（`native/sim/rust/crates/cli/src/render.rs`）。

## 選取

- 由鏡頭射線與地形高度圖求交，得到格點 → 州郡。
- 建築、軍隊以螢幕空間距離挑選，優先於州郡。

## 介面繪製

- 面板與卡片是 `Control` 場景；紙紋、印章、毛邊等器物外觀以 `CanvasItem` 的 `_draw` 向量繪製（5.7、8.8），不使用 Godot 預設主題的外觀。
- 地圖標籤在螢幕空間的 `Control` 層繪製：把標籤的世界座標投影到螢幕後寫字（5.3）。
- 搖桿與鍵鼠都對應到 `InputMap` 的動作；介面與鏡頭只讀動作，不讀實體按鍵（5.9）。
