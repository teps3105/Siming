# 8.5 模型

全部由 `objects` 模組以程式產生的低多邊形網格（`ArrayMesh`），使用 `object_ink.gdshader`。尺寸單位為格。

| 模型 | 產生參數 | 構成 | 三角形上限 |
|---|---|---|---|
| `city(level)` | 城池等級 0–4 | 0：3 間屋頂；1：矮牆 + 5 間；2：方城牆 + 城門；3：加角樓；4：加內城與宮殿 | 600 |
| `capital` | — | `city(4)` + 旗桿 + 旗面（勢力色，頂點動畫飄動） | 800 |
| `sect_gate(evil)` | 正邪 | 牌坊 + 三重殿（階梯上升）+ 曲折山徑；正道白牆黛瓦，邪道黑瓦 | 700 |
| `pagoda(levels)` | 3–7 層 | 八角塔身逐層縮小，每層簷角上翹 | 500 |
| `academy` | — | 二進院落 + 兩層書樓 | 400 |
| `demon_den` | — | 地面裂谷（凹陷）+ 尖石環 | 300 |
| `beast_totem(kind)` | 狐、虎、蛇、狼、蛟 | 圖騰柱 + 族類剪影浮雕（以 2D 輪廓擠出） | 300 |
| `ley_node(grade)` | 等級 | 浮空雲團（數個球體噴點）+ 光點 | 200 |
| `army_flag` | — | 旗桿 + 旗面（勢力色） | 60 |
| `soldier` | — | 簡化人俑（頭、身、戟） | 40 |
| `camp` | — | 環形營帳（圍城） | 200 |
| `silhouette(role)` | 修士、僧、儒、君、將、魔、妖 | 2D 剪影擠出，供人物標記與前世今生縮圖 | 80 |
| `sword_light` | — | 細長菱形 + 拖尾帶狀網格 | 40 |

## 規範

- 產生函式為純函式：相同參數產生相同網格。啟動時產生並快取。
- 所有模型底部置於 y = 0；以 +z 為正面。
- 以 `MultiMeshInstance3D` 批次繪製。每個實例帶：位置、旋轉、縮放、勢力色、狀態（殘破度、高亮）。
- 剪影的 2D 輪廓以向量座標寫在程式中，不使用點陣圖。
