# 8.3 貼圖與材質

全部由程式產生：與世界無關的貼圖以固定種子產生，世界貼圖在世界生成後由橋接 crate 的 `relief` 與 `mapbake` 模組烘焙（6.4）。目前已實作的是 `paper` 與下表的世界貼圖；`cloud`、`brush_mask`、`ui_paper` 尚未實作。

## 程序貼圖（啟動時產生，與世界無關）

| 貼圖 | 尺寸 | 格式 | 產生方式 | 用途 |
|---|---|---|---|---|
| `paper` | 512×512，平鋪 | RGBA8 | 低頻值雜訊（明暗斑）+ 高頻纖維雜訊（沿隨機方向拉伸的線段），存成乘數 | 地形圖的紙紋 |
| `cloud` | 256×256，平鋪 | R8 | Worley + fBm | 霧、劫雲、雲紋 |
| `brush_mask` | 128×128 | R8 | 圓形筆觸加飛白雜訊 | 印章邊緣、結算大字 |
| `ui_paper` | 256×256，平鋪 | RGBA8 | 低頻明暗斑 + 高頻纖維；以 paper-light 為底、alpha 0.35；固定種子，由 `hud` 模組於啟動時產生 | 介面面板（命簿內頁、紙簽、題簽）的紙紋（5.7） |

## 世界貼圖（世界生成後產生，移山時更新）

| 貼圖 | 尺寸（中） | 格式 | 內容 |
|---|---|---|---|
| `elevation` | 3072×1536 | 16 位元浮點 | 相對海平面的高度，含碎形細節（5.3「高度場」） |
| `lake` | 3072×1536 | R8 | 湖面遮罩，0.5 為湖岸 |
| `climate` | 768×384 | RGB8 | 植被底色（5.1「地形圖設色」） |
| `province_id` | 384×192 | RG8 | 每格州郡 ID 的低、高位元組；無州郡為 65535 |
| `field` | 1536×768 | R8 | 地圖模式的連續場 |
| `province_color` | 256×1 | RGBA8 | 州郡 → 顏色查表（每月更新） |

## 材質

| 材質 | 著色器 | 參數 |
|---|---|---|
| 地形 | `terrain_relief.gdshader` | 見 5.3、6.4 |
| 河流、靈脈 | `river_line.gdshader` | 線色、各等級的螢幕寬度與不透明度 |
| 水面 | 併入地形著色器 | — |
| 建築 | `object_ink.gdshader` | 勢力色、殘破度、高亮 |
| 因果線 | `thread.gdshader` | 顏色、寬度、流動速度、淡出 |
| 特效 | `fx.gdshader` | 依特效（8.7） |
| 標籤文字 | 不使用材質；以螢幕空間 `Control` 層繪製（5.3） | — |
