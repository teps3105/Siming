# 8.11 人物模型與動作

地圖上演出的人物是一枚 2D 棋子：由封面的 `CultivatorFigure`（8.12）逐幀畫在一張立在地圖上的後仰面片上，動作則在 Blender 骨架上設計、逐幀匯出成 2D 關節座標。遊戲內沒有 3D 模型。本節定義動作資料、棋子的畫法、在地圖上的呈現與驗收。

## 做法

| 步驟 | 內容 |
|---|---|
| 設計動作 | `tools/figure/model/` 的 Blender 腳本建粗模與骨架，`actions.py` 以關鍵姿勢寫動作（歐拉角關鍵值 → 四元數球面內插 → 每格一個關鍵幀）；動作節奏參照 `sources/figure/direct/<動作>/timing.md` 的影片示範筆記 |
| 匯出 | `export_poses.py` 逐格取樣骨架，換算成封面人物的 2D 關節座標，寫成 `actions.json` |
| 遊戲內 | `FigureMotion` 讀 `actions.json` 取姿勢；`FigureActor` 用 `CultivatorFigure.draw` 把棋子畫進貼圖，貼在後仰面片上 |

棋子與封面同一套畫法（賽璐璐水墨平塗、外粗內細的墨線），樣子取自 `CultivatorFigure.traits()`，所以頭像與地圖上的棋子是同一人。

## 動作資料

檔案：`game/modules/figure/resources/actions.json`，由腳本產生，不手改。

| 欄位 | 內容 |
|---|---|
| `fps` | 24 |
| `actions.<名>.length` | 格數 |
| `actions.<名>.loop` / `loop_start` | 是否循環；循環動作先播一次前導，之後從 `loop_start` 格起循環 |
| `actions.<名>.events` | 具名事件與其格號 |
| `actions.<名>.poses[]` | 每格一個姿勢 |

每格姿勢的關節：`hip`、`neck`、`elbow_f`、`hand_f`、`elbow_b`、`hand_b`（身高為 1、腳底在原點、向上為 −y、人物面向 −x 的座標；`_f` 是畫面左側遠端的手），另有 `head_roll`（頭後仰為正）、`wind`（袖與衣擺的擺動）、`seated`、`point`，以及 `anchors`：`crown`（頭頂）、`foot`（腳底）、`palm_f`、`palm_b`（掌心）。數值取到小數 5 位。

導出以 `stand` 第 0 格為錨：它與封面的 `STAND` 姿勢逐值相同，其他格以此為基準的位移（手臂位移乘 0.8、0.97 的縮放）加上去，棋子因此與封面同樣比例。

現有動作：

| 動作 | 格數 | 循環 | 事件 | 用於 |
|---|---|---|---|---|
| `stand` | 48 | 是 | 無 | 手臂自然垂下，一切演出的起點與終點 |
| `brace` | 60 | 是，從第 12 格起 | `raised` = 12 | 天劫雲聚，仰首舉手迎雷 |
| `struck` | 36 | 否 | `hit` = 2、`peak` = 14、`lowest` = 24 | 天劫落雷，一道一次 |

`walk`、`sit`、`fall`、`rise`、`strike`、`seal`、`bow` 尚未製作（5.6 的飛升與了結要用到）；加動作的方式是在 `actions.py` 寫關鍵姿勢、重跑匯出。

事件與錨點由遊戲讀資料，不寫死格號。天劫舞台（`spectacle`）讓 `struck` 從資料的 `hit` 時刻對齊落雷；兩道雷間隔不足時整段動作等比縮短（留 0.1 秒餘裕）。

## 畫法

- `CultivatorFigure.draw` 的姿勢參數除了列舉，也收關節字典；列舉的行為與封面不變。
- `FigureActor` 的子節點：一個透明背景、關閉 3D、只在內容變化時更新的 `SubViewport`，裡面的畫布呼叫 `CultivatorFigure.draw`；一個四邊形面片貼這張貼圖，著色器 `figure_card.gdshader` 不吃光、做 alpha 混合。
- 時間量化到 1/24 秒，樣子、動作、格、鏡像、貼圖密度任一項不變就不重畫。貼圖密度依螢幕上實際像素換算，以 16 為級距往上取整（含 1.25 倍餘裕）。
- 畫框 `FRAME` 為身高 1 的座標系中的 (−0.45, −1.45) 起、1.6 × 1.5，涵蓋所有動作、各種樣子的最大剪影（`figure_extent.gd` 量測）。
- 面片寬度為人高 × cos 30°、高度為人高，所以後仰壓扁之後棋子在畫面上不變形。
- 棋子永遠正對鏡頭、不隨鏡頭方位角轉動；側面像，`face_right` 切換面向（以面片負縮放鏡像）。預設面向畫面左。
- 袖與衣擺的袖口輪廓若自相交，以多邊形聯集取最大外輪廓（`_simple`），保證能三角化。

實測（視窗 960×540、8 位棋子 24 Hz 動畫）：單次重畫約 3.7–4.6 ms；一位棋子每幀約 1.8 ms 的重畫耗時（幀長 8.3 ms 不受影響），三位約 4.9 ms，八位約 12 ms，二十四位約 45 ms。每個奇觀 ≤ 3 人（5.6）在預算內。

## 在地圖上

`FigureActor`（`Node3D`）由 `spectacle` 的舞台建立與移除：

- `setup(look)`：`look` 是 `CultivatorFigure.traits(seed, given)` 的結果；`look_of(種子, given)` 由人物現況與橋接資料換成 look。
- `play(action, age)`：依奇觀的 `age` 取姿勢；不用 `AnimationPlayer`，暫停時停住，重播時相同。
- `place(origin, up, camera, unit, hidden)`：棋子以腳底為軸往畫面上方後仰，面片與視線夾 60°（30° 俯角的立姿）。地圖鏡頭是正交投影、俯角 60°（5.2），照實立著畫會被壓得很扁，所以後仰。星球視角下「上」取球面法線（`Spectacle._up_basis`），後仰在「視線與畫面上方」的平面內轉動，上方向離開此平面的分量原樣保留，鏡頭正對球面俯視時棋子仍倒向畫面上方。
- 深度：著色器沿視線把面片的深度拉近鏡頭 `depth_pull_factor`（預設 2）倍人高，只改深度不改畫面位置，被後方較高的地形蓋住時整個棋子仍畫在地形之前。面片的渲染優先序高於雲霧粒子，棋子畫在劫雲之上。
- 大小：畫面高度夾在 80–160 px（× 介面縮放）；鏡頭高度超過地圖寬的 0.4 倍（`too_far`）不畫（5.5）。
- 星球視角背對鏡頭的不畫；鏡頭外的不演（5.6）。

## 驗收

- **測試**（`game/tests/test_figure_actor.gd`，21 項）：動作資料的格數、循環、事件、錨點與 `stand` 第 0 格等於封面 `STAND`；姿勢內插與非循環夾住；各種樣子與每格剪影都在畫框內；同一個 `look` 與 `age` 兩次姿勢相同；後仰恆為 60°（方位角 0°、±45°、球面上方向、正俯視）；畫面高度 80–160 px；鏡頭拉遠不畫；鏡像；天劫當事人的動作依資料事件切換、橋接欄位換成 look。封面測試維持原樣通過。
- **掃描**：`figure_triangulate.gd` 對 160 種樣子的所有動作格檢查色塊能否三角化，不得有失敗。
- **讀圖**：`figure_sheet.gd` 畫一個動作的關鍵格，最左是封面同種子的 `stand` 對照，認得出同一人；遊戲內以 `figure_game_view.gd` 取 1920×1080 畫面，方位角 0° 與 ±45°、鏡頭最近與拉遠、星球視角各看一次，確認棋子在地形與劫雲之前、墨線粗細與封面相當、方位角轉動時棋子的朝向不變。
- **量測**：`figure_perf.gd` 量重畫次數與耗時。

## 目錄

```
tools/figure/model/build.py          建粗模與骨架，存成 .blend（輸出到 .shiftblame/tmp/，不入庫）
tools/figure/model/parts.py          部件表
tools/figure/model/actions.py        各動作的關鍵姿勢
tools/figure/model/export_poses.py   骨架 → actions.json
tools/figure/model/direct.py         請影片模型示範一段動作，排成對照表
sources/figure/direct/               示範用工作流、各動作描述、節奏筆記
game/modules/figure/resources/actions.json
game/modules/figure/code/figure_motion.gd        讀資料、取姿勢與事件
game/modules/figure/code/figure_actor.gd         一枚棋子：畫法與擺位
game/modules/figure/code/figure_card.gdshader    面片著色器
game/tests/harness/figure_sheet.gd、figure_extent.gd、figure_triangulate.gd、figure_perf.gd
```

匯出指令（Blender 固定 5.2.2 LTS）：`blender -b --factory-startup -P tools/figure/model/export_poses.py -- game/modules/figure/resources/actions.json`。驗收重建結果時比對匯出的關節數值（小數 5 位），不比對檔案雜湊。
