# 8.11 人物模型與動作

地圖上的人物演出用即時 3D 的小人：一副骨架、一套可換的部件、一組動作，由 Blender 腳本建出、匯出成一個 `.glb`，在奇觀的 3D 舞台（5.6）以墨線著色器畫。本節定義這條製作管線、成品規格與驗收。管線尚未動工，見文末「現況」。

## 做法的來源

取自 hikari 專案的人物管線（`D:\hikari\sources\character\walker\`，該專案稱「死亡細胞做法」）：照設定建很粗的 3D 模型與骨架，以關鍵姿勢做動作，動作的節奏請影片模型示範，成品的每一格都由骨架擺出來。本專案沿用前三步，後面不同：

| 步驟 | hikari | 本專案 | 原因 |
|---|---|---|---|
| 設定 | 2D 設定圖量出各部位尺寸 | `CultivatorFigure.traits()` 的身分→樣子表 | 人是種子生的，沒有逐人的設定圖 |
| 建模 | Blender 腳本建粗模、骨架、衣物殼 | 相同 | — |
| 頭 | 各方向的 2D 頭做成面片 | 3D 的頭，五官是貼在頭面上的墨線小片 | 人物在畫面上 80–160 px 高，頭約 20 px；鏡頭方位可轉，面片會穿幫 |
| 動作 | 腳本寫關鍵姿勢；影片模型當導演 | 相同 | — |
| 出圖 | 八方向逐層逐幀算成透明底圖，再排圖集 | 不出圖：匯出 `.glb`，遊戲內即時畫 | 地圖與奇觀本來就是 3D；種子決定的身形、髮式、衣色組合太多，烘成圖集粗估 20–45 MB，超過 8.1 的 20 MB |
| 換裝 | 每件衣物一層圖，網頁端疊圖 | 每個部件一個網格，同一副骨架，依樣子顯示或隱藏 | 即時 3D 不需要疊圖順序，深度由引擎處理 |
| 畫風 | 賽璐璐兩階明暗、紫褐描線 | 白描設色：墨線勾邊、平塗、由上往下略深，不打光 | 與封面人物（9.1）和古地圖一致（5.1） |

## 規格

| 項目 | 值 |
|---|---|
| 單位與朝向 | 成人站立身高 1；腳底在原點；正面朝 +z（8.5 規範）；匯出時由 Blender 的 −Y 正面轉成 glTF 的 +Z |
| 骨架 | 一副，≤ 40 根骨頭：根、腰、胸、頸、頭；左右的肩、上臂、前臂、手、持物點；左右的大腿、小腿、腳；袖 2×2、衣擺 4、披髮與髮帶 3 |
| 三角形 | 一個人同時顯示的部件合計 ≤ 3,000；檔案內全部部件合計 ≤ 20,000 |
| 檔案 | `figure.glb` 一個，含全部部件與動作，≤ 2 MB |
| 貼圖 | 無。顏色由著色器的實例參數給 |
| 動作取樣 | 關鍵姿勢以每秒 24 格的格號寫定，播放時內插 |
| 同屏數量 | 每個奇觀 ≤ 3 人；奇觀同時 ≤ 12 個（5.6），合計 ≤ 36 人 |

### 身形

不為男女老少各建一個模型。身形由 `traits()` 的數值換算成骨頭的縮放與位移：`heads`（幾頭身）縮放頭骨、`stature` 縮放根、`shoulder` 移動肩、`girth` 縮放腰與胸的橫向、`stoop` 轉胸與頸。

### 部件

部件表照 `CultivatorFigure` 的列舉，一項一個網格，命名 `<類別>.<名稱>`（小寫英文）：

| 類別 | 項目 | 數量 |
|---|---|---|
| `body` | 身體（頭、頸、手、腳露出的部分） | 1 |
| `robe` | 袍：窄袖、常袖、廣袖三種袖形 × 男袍、女子襦裙 | 6 |
| `cape` | 大氅 | 1 |
| `shawl` | 披帛 | 1 |
| `hair` | `Hair` 的 8 種：髮髻、冠、披髮、笠、雙髻、高髻、剃度、儒巾 | 8 |
| `beard` | `Whiskers` 無鬚以外的 5 種 | 5 |
| `prop` | `Prop` 無持物以外的 11 種 | 11 |
| `face` | 眉、眼、口：少、壯、老各一組墨線小片 | 3 |

貼身的部件（袍、大氅）是身體網格往外撐的殼，袖與衣擺另接出去並綁在袖骨、衣擺骨上；髮、鬚、持物是自己的形狀，整件跟一根骨頭（頭、持物點、背）。衣領、腰帶、衣褶的線是沿曲線鋪的細帶網格，算在所屬部件裡。

### 動作

第一批，對應已有與將做的奇觀（5.6）：

| 動作 | 內容 | 循環 | 用於 |
|---|---|---|---|
| `stand` | 立姿，重心微移 | 是 | 一切演出的起點與終點 |
| `walk` | 行走，一個循環兩步 | 是 | 入場、離場 |
| `sit` | 盤坐，雙手置膝 | 是 | 突破、閉關、涅槃 |
| `brace` | 仰首，一手舉起迎雷 | 是 | 天劫雲聚 |
| `struck` | 受雷，身體後仰再撐住 | 否 | 天劫落雷，一道一次 |
| `fall` | 倒下 | 否 | 身死、兵解 |
| `rise` | 離地上升，袖與衣擺上揚 | 是 | 飛升 |
| `strike` | 拔劍出一劍 | 否 | 殺業、宗門之戰、宿緣了結 |
| `seal` | 掐訣前指 | 否 | 施法、度化 |
| `bow` | 躬身行禮 | 否 | 成婚、拜師、繼位 |

袖、衣擺、髮帶隨風的擺動不做成動作，由著色器依頂點色的權重擺。

## 目錄

```
tools/figure/model/build.py      建粗模、骨架、部件，存成 .blend
tools/figure/model/parts.py      部件表：每個部件蓋住身體哪裡、形狀、跟哪根骨頭
tools/figure/model/actions.py    各動作的關鍵姿勢
tools/figure/model/export.py     .blend → figure.glb
tools/figure/model/direct.py     請影片模型示範一段動作，排成對照表
sources/figure/direct/           示範用的工作流 JSON、各動作的描述與種子、對照表
game/modules/figure/assets/figure.glb
game/modules/figure/code/figure_actor.gd     一個人：套樣子、播動作
game/modules/figure/code/figure_ink.gdshader 墨線與平塗
```

腳本是唯一來源；`.blend` 是中間產物，不入庫。`figure.glb` 入庫，由腳本重建的結果要與入庫的檔案位元相同（8.1 原則 3）。

## 管線

1. **建模**：`blender -b --factory-startup -P tools/figure/model/build.py -- <輸出.blend>`。只用 Blender 內建功能，不開視窗。
2. **動作**：同一次建模把 `actions.py` 的關鍵姿勢寫成 action。新動作先跑 `direct.py`：以立姿的 30° 俯角算圖為第一格，請本機 ComfyUI 的影片模型演出，逐格存下排成對照表；排關鍵姿勢時照它的節奏與姿勢。影片只是參照，不進成品；描述、種子與對照表留在 `sources/figure/direct/`。簡單的動作（`stand`、`sit`）不必示範。
3. **匯出**：`blender -b <.blend> -P tools/figure/model/export.py -- game/modules/figure/assets/figure.glb`。匯出後以同一支腳本重新匯入，核對骨頭數、部件名、動作名與三角形數。
4. **匯入 Godot**：`.glb` 由編輯器匯入成場景；`FigureActor` 在執行時實例化，不另存 `.tscn`。
5. **驗收**：見下。

## 著色

`figure_ink.gdshader`，不受光：

- **平塗**：每個部件的顏色是實例參數，取自 `CultivatorFigure._palette()`（門派定衣色的色系，貧富定鮮濁與有無緣邊，年紀定髮色）。UV 的 v 是部件內由上到下 0–1，顏色依 `DEPTH` 表由上往下加深。
- **墨線**：每個網格外包一層翻面殼，沿法線外推，寬度以螢幕像素計（1.5 px × 介面縮放），顏色 ink `#2B2620`。兩個部件互相穿過的地方殼收掉。
- **擺動**：頂點色 R 是擺動權重（袖口、衣擺下緣、髮帶尾端為 1），以演出自己的 `age` 算位移，不讀引擎時間：暫停時停住，重播時相同。

## 在地圖上

`FigureActor`（`Node3D`）由 `spectacle` 的舞台建立與移除：

- `setup(look)`：`look` 是 `CultivatorFigure.traits(seed, given)` 的結果，`given` 取人物的性別、年紀、門派等現況。顯示對應的部件、設骨頭縮放與各部件顏色。
- `play(action, age)`：依奇觀的 `age` 取動作的姿勢；不用 `AnimationPlayer` 自己走時間。
- **俯角固定 30°**：地圖鏡頭俯角是 68°–88°（5.2），照實畫只看得到頭頂。人物以腳底為軸、繞鏡頭的右軸往畫面上方後仰「鏡頭俯角 − 30°」，從鏡頭看過去恆為 30° 俯角的立姿。朝向（繞自身的上軸）先轉，再後仰。
- **大小**：人物在畫面上的高度夾在 80–160 px（× 介面縮放）之間，隨鏡頭拉遠而縮小到下限後不再縮；鏡頭高度超過地圖寬的 0.4 倍時不畫（與山門圖樣同一條線，5.5）。
- **朝向**：單人預設三分面朝畫面左前；兩人的演出彼此相對。
- 星球視角背對鏡頭的不畫；鏡頭外的不演（5.6 規則）。

## 驗收

- **測試**（`game/tests/test_figure_actor.gd`）：每種身分組合套得上（該顯示的部件都在檔案裡）；每個動作在每種袖形下取得到姿勢；骨頭數、三角形數、檔案大小在規格內；同一個 `look` 與 `age` 兩次取得的骨頭變換相同。
- **並排讀圖**（比照 `tools/tests/figure_zoom.py`）：同一個種子只差一項身分的幾個人並排，在 30° 俯角下看得出差別；同一個種子的封面 2D 人物與 3D 人物並排，認得出是同一人。
- **遊戲內**：每個動作在地圖上實際播放並讀新鮮畫面——腳不滑、衣袖不穿身、暫停時停住；鏡頭俯角 68° 與 88°、方位角 ±45° 各看一次，人物都是立姿。
