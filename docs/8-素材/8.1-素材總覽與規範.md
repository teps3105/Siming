# 8.1 素材總覽與規範

本作的貼圖、模型、特效與圖示幾乎都由程式產生，只有字型與文字資料是檔案。本節定義素材的共同原則、存放位置、命名方式與各類素材的數量。

## 原則

1. **程序生成優先**：貼圖、模型、特效、圖示都以程式產生；只有字型與文字資料是檔案。
2. **單一來源**：每項素材只有一個產生來源（程式或檔案），在本章登記。
3. **可重現**：程序素材使用固定種子；同版本產生的結果位元相同。程序素材與世界種子無關。
4. **授權清楚**：外部素材只用 OFL、CC0、MIT、Apache-2.0、CC BY 4.0（須署名，製作群頁列出）；全部登記於 [8.10 授權清單](8.10-授權清單.md)。
5. **體積**：匯出包內的素材總量 ≤ 20 MB（不含引擎與橋接程式庫）。

## 目錄

```
native/sim/rust/crates/sim/data/        文字資料：命名字庫（8.6）
game/modules/ui_kit/assets/fonts/       子集字型（8.2）
game/modules/locale/resources/          介面與事件模板（8.6）
game/modules/<模組>/code/               著色器（8.4）與程序素材產生腳本：貼圖、模型、特效、圖示
tools/font_subset/                      字型子集化工具
```

## 命名

- 檔名用小寫英文與底線，例如 `terrain_relief.gdshader`、`wenkai_tc_subset.ttf`。
- 程序素材以產生函式命名，例如 `paper_texture()`、`pagoda_mesh(levels)`。
