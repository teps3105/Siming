# 8.8 圖示與印章

介面上的圖示與印章全部以字型與向量圖形繪製，不使用點陣圖檔。本節定義印章的構成與三套用字，以及介面圖示的畫法。

## 印章

- 用途：傳聞、天書、權能列、事件類別。
- 構成：朱紅方形（`brush_mask` 做出不規則邊緣）+ 置中的一個字（反白），以字型繪製。
- 由 `hud` 模組的印章繪製函式 在啟動時產生到一張圖集（atlas），256 格 × 64 px。
- 三套印章互不重複：

  | 用途 | 形式 | 對照 |
  |---|---|---|
  | 事件 | 橫長方形二字印 | 7.2「印」欄；每種事件一個二字詞，不重複；朱底（世界大事靛底）紙字 |
  | 天書 | 長方形雙字印 | 條目名的前兩字 |
  | 權能 | 圓形單字印 | 牽、化、福、罰、渡、山、象 |

## 介面圖示

| 圖示 | 構成 |
|---|---|
| 天時儀（時間控制） | 圓盤：墨色雙圈、十二月刻度、朱針；盤心圓印「行」／「止」；盤右四道由短到長的墨筆「疾徐」，作用中者朱紅（5.7） |
| 天道之秤 | 天秤向量圖，兩盤依數值傾斜（即時繪製） |
| 量劫預測 | 十格圓環，已達成數填 seal-red |
| 地圖模式（印匣） | 地、國、教、脈、因、業六字小印（圓角方形加飛白缺口，與上述三套區分） |
| 例簽 | 「例」字小印；展開的圖例為紙簽 |
| 關閉 | 圓印「閉」 |
| 命簿軸頭 | 墨色圓柱，兩端略粗，中段一道高光 |
| 輪迴台 | 即時繪製的六格圓盤 |

### 印章繪製規則（`ui::ink::seal`）

- 形狀：圓角方形（圓角 = 邊長 × 0.18）或正圓；邊緣以固定種子抖動 ±1 px，並在隨機一角留飛白缺口（朱底時缺口露出紙色）。
- 字：以霞鶩文楷繪製單字，字高 = 邊長 × 0.6；朱底紙字（作用中）或紙底朱字（可用）或淡墨字（未開放）。
- 回饋：停留時外圍墨暈（朱紅 α 0.18 的三圈擴散，0.15 秒）；按下時整印縮至 0.94 並留一圈朱痕 0.3 秒淡出；焦點時朱描毛筆外框（5.9）。

| 按鍵提示 | 搖桿：A／B／X／Y 圓鈕（Xbox 慣例配色，降低彩度）、LB／RB、LT／RT、十字鍵、左右搖桿、選單鍵、檢視鍵；鍵盤：鍵帽內含按鍵名（5.9） |
| 遊戲內游標 | 墨色箭頭；可按時朱色箭頭加朱環；拖動地圖時四向箭頭；旋轉鏡頭時朱色弧形雙箭頭。程式繪製，紙色描邊（5.9） |

所有圖示以 `CanvasItem` 的向量繪圖或字型產生，不使用點陣圖檔。
