# 7.3 命名規則

字庫存放於 `native/sim/rust/crates/sim/data/*.zh-Hant.json`（簡體版為 `*.zh-Hans.json`，9.5），編譯期嵌入（素材見 8.6）。所有命名只用 `worldgen`、`people`、`powers` 子流，可重現。

同一世界中不重名：
- 勢力、州郡、地名：重名時重抽，最多 20 次；仍重複則加「新」「北」「南」等前綴。
- 人名：允許重名。

## 人名

| 項目 | 規則 | 字庫 |
|---|---|---|
| 俗名 | 姓 + 名 1–2 字。複姓 10%；名字依性別與陰陽取字，中性字 20% | `names.zh-Hant.json`（v1 沿用：常見姓 80、複姓 26、各類名字 40×5） |
| 道號（金丹起） | 兩字核心 + 依境界的尊稱，例：玄清 + 真人。取得：開天時境界 ≥ 金丹者；突破到金丹時（之後每次突破到新境界，核心不變、依新境界重抽尊稱）。正邪：魔修、邪道宗門成員、無宗門而淨業力 < 0 者取魔門字庫，其餘取正道字庫；男性取陽、女性取陰。尊稱取 `suffix_by_realm` 該境界的 10 條之一。不消耗子流：亂數由（種子、人物 ID、境界）雜湊的臨時亂數取得，使強制突破（不抽樣，3.5）取得道號時不影響 `people` 子流 | `titles.zh-Hant.json`（v1 沿用：依正邪陰陽的前後字、依境界的尊稱各 10） |
| 法號（出家時） | 輩分字 + 一字，例：慧明、空寂；輩分字依寺院固定 | `dharma.zh-Hant.json`（新增：輩分字 20、法名字 60） |
| 儒號（大儒） | 兩字 + 先生、子、居士，例：東林先生 | `scholar.zh-Hant.json`（新增：雅號字 60、尊稱 6） |
| 妖名 | 特徵 + 族類 + 尊稱，例：白面狐王、赤鱗蛟君 | `beast.zh-Hant.json`（新增：特徵 40、尊稱依境界 5） |
| 魔號 | 煞氣兩字 + 魔君、老魔、血尊等 | 沿用 `titles.zh-Hant.json` 魔門字 + `beast.zh-Hant.json` 尊稱 |

## 地名

| 對象 | 規則 | 例 |
|---|---|---|
| 紀元 | 兩個字，由種子與紀元序號算出，不消耗模擬的隨機流。一半機會取該類時間段現成的雙字詞；否則「首字（該類時間段的字池）＋次字（共用的字池）」。同一張年表不重名；兩字相同、列在不用清單的組合不取。字庫在 `native/sim/rust/crates/sim/data/eras.zh-Hant.json`，每個字附出處與原句 | 太始、鴻蒙、玄冥、昭明 |
| 海 | 相連的海依離岸最遠的幾個深處分成海區（兩個深處至少相隔地圖寬 ÷ 9）；最深處離岸達地圖寬 ÷ 14 格者稱「洋」，其餘稱「海」；沒有深處的小海整片算一個海。小於 12 格的不命名。名字取自海名字庫，同一個名只給一個海區 | 望舒洋、鯨海、蓬萊海 |
| 湖 | 每個連通的湖一個名字（小於 3 格的不命名）；40 格以上稱「澤」、8 格以上稱「湖」、其餘稱「池」。名字取自湖名字庫，不重複 | 雲夢澤、洗硯湖、照影池 |
| 海陸變了之後的海與湖（2.8） | 水域照目前的地形重新劃分，名字以生成時的水域為準沿用：生成時的水域由大到小認領目前的水域——名字的標記格現在落在哪個水域，那個水域就沿用原名（連同原本的稱呼；海區與湖各認各的，一個水域只被認領一次）。沒被認領的是新水域，依標記格另取新名，不用生成時出現過的名。生成時的水域若標記格已成陸地，或所在的水域被更大的認領，名字就消失。結果只看種子、生成時的地形與目前的地形，與中間經過無關，讀檔重播與一路玩下來的名字相同 | 兩片海連通後留大的那片的名字 |
| 治所 | 兩字名 + 城池等級的字（村、鎮、縣、城、都；升降級時跟著變）。兩字名約四成借州郡名的一個字——「臨、望」一類的前字加州郡字，或州郡字加依地勢取的後字；其餘是獨立的名字——通用字加依地勢取的後字（海邊：浦港濱灣澳；水邊：津渡口汀洲；山間：關嶺峪岡坂；平地：亭里坊集堡莊）。不與自己州郡名的兩個字相同，同一世界不重名；由種子與州郡編號算出，不消耗世界生成的隨機流 | 雲夢郡的治所：臨雲鎮、夢津縣、嘉浦城 |
| 州郡 | 兩字 + 州（城池等級 ≥ 3 或格數排在前 25%（同格數者一併入選））或郡；首字依主要地形或方位，次字通用 | 雲夢郡、幽州 |
| 江河 | 一至兩字 + 江（等級 3）、河（2）、水（1） | 滄浪江 |
| 山脈 | 兩字 + 山、嶺、嶽（最高者） | 太華嶽 |
| 洞天福地 | 兩字 + 大洞天、洞天、福地 | 赤城洞天 |
| 大洲 | 儒、釋、道三教混合，見下方「大洲命名」 | 豫洲、南贍部洲、瀛洲、蓬萊島 |
| 世界（星球） | 兩字 + 界 | 玄黃界 |

地名字庫 `places.zh-Hant.json`（新增）：
- 依地形分組的首字：山 20、水 20、平原 20、森林 15、沙漠 10、雪原 10、沼澤 10。
- 方位字 8。
- 通用次字 60。
- 江河名 40、山名 40、洞天名 40。

## 大洲命名

命名不偏一教：儒、釋、道三組地名輪流使用。

| 教 | 字庫（`places.zh-Hant.json` 的 `continent_names`） | 出處 |
|---|---|---|
| 儒 | 冀洲、兗洲、青洲、徐洲、揚洲、荊洲、豫洲、梁洲、雍洲、神洲、中洲 | 《尚書・禹貢》九州；鄒衍「赤縣神州」 |
| 釋 | 東勝神洲、西牛賀洲、南贍部洲、北俱蘆洲 | 佛教四大部洲 |
| 道 | 祖洲、瀛洲、玄洲、炎洲、長洲、元洲、流洲、生洲、鳳麟洲、聚窟洲；小陸塊另有蓬萊、方丈、岱輿、員嶠 | 《海內十洲記》十洲；三神山與五神山 |

規則：

1. 陸塊依面積由大到小排序。
2. 以種子決定起始的教（儒、釋、道其一），之後依序輪流：第 i 塊使用第 `(起始 + i) mod 3` 教的字庫。
3. 在該教字庫中不放回地抽取一個名字。
4. 面積 ≥ 陸地 5% 者稱「洲」（字庫名已含「洲」者照用）；較小者若屬道教則優先取三神山、五神山之名並稱「島」，否則以字庫名的首字加「島」。
5. 某教字庫用盡時，改用下一教。
6. 釋教四大部洲的方位字只是名字，不要求與實際方位一致。

## 三教混合原則

- 世界層級與地理層級的命名（大洲、世界名、洞天福地、山川）都混合三教意象，不偏一教。
- 勢力命名依其所屬：宗門偏道、寺院屬釋、書院屬儒、王朝國號屬儒家傳統（2.5）。

## 紀元名字庫

- 十類時間段各有一池首字（2.8「世界大事與紀元」）：開天之初、大寒、大暖、末法、靈氣復甦、天崩地裂、魔劫、重光、浩劫之後、承平；次字共用一池。
- 來源限中文原典：《易》（含十翼）、《老子》、《莊子》、《列子》、《淮南子》、《尚書》、《楚辭》、《千字文》。每個字與每個現成的雙字詞都記書名篇名與含該字的原句。
- 查證方式：2026-10-11 以維基文庫（`https://zh.wikisource.org/wiki/` 加字庫各條的 `page`）的原始文字逐句比對，88 條引句全部在原文中找到。例：《列子·天瑞》「太初者，氣之始也」；《千字文》「天地玄黃，宇宙洪荒」；《淮南子·覽冥訓》「四極廢，九州裂」。
- 不用的組合：與現代常用詞相同者（和平、清明、光明、平常等）、會聯想到朝代者（元明、明清等）、部分真實年號（太平、太和、元始等）。現成雙字詞中的「太初」「太始」同時是漢代年號，因為它們本身是《列子》講天地生成的用語，保留。
- 增刪字時，引句必須是該頁原文中找得到的句子；`cargo test -p siming-sim era` 會檢查每一條的原句確實含有那個字。
