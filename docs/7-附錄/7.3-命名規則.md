# 7.3 命名規則

字庫存放於 `native/sim/rust/crates/sim/data/*.zh-Hant.json`（簡體版為 `*.zh-Hans.json`，9.5），編譯期嵌入（素材見 8.6）。所有命名只用 `worldgen`、`people`、`powers` 子流，可重現。

同一世界中不重名：
- 勢力、州郡、地名：重名時重抽，最多 20 次；仍重複則加「新」「北」「南」等前綴。
- 人名：允許重名。

## 人名

| 項目 | 規則 | 字庫 |
|---|---|---|
| 俗名 | 姓 + 名 1–2 字。複姓 10%；名字依性別與陰陽取字，中性字 20% | `names.zh-Hant.json`（v1 沿用：常見姓 80、複姓 26、各類名字 40×5） |
| 道號（金丹起） | 兩字核心 + 依境界的尊稱，例：玄清 + 真人。取得：開天時境界 ≥ 金丹者；突破到金丹時（之後每次突破到新境界，核心不變、依新境界重抽尊稱）。正邪：魔修、邪道宗門成員、無宗門而淨業力 < 0 者取魔門字庫，其餘取正道字庫；男性取陽、女性取陰。尊稱取 `suffix_by_realm` 該境界的 10 條之一。不消耗子流：亂數由（種子、人物 ID、境界）雜湊的臨時亂數取得，使強制突破（不抽樣，3.5）取得道號時不影響 `people` 子流 | `titles.zh-Hant.json`（v1 沿用：依正邪陰陽的前後字、依境界的尊稱各 10） |
| 法號（出家時） | 輩分字 + 一字，例：慧明、空寂；輩分字依寺院固定 | `dharma.zh-Hant.json`（新增：輩分字 20、法名字 60） |
| 儒號（大儒） | 兩字 + 先生、子、居士，例：東林先生 | `scholar.zh-Hant.json`（新增：雅號字 60、尊稱 6） |
| 妖名 | 特徵 + 族類 + 尊稱，例：白面狐王、赤鱗蛟君 | `beast.zh-Hant.json`（新增：特徵 40、尊稱依境界 5） |
| 魔號 | 煞氣兩字 + 魔君、老魔、血尊等 | 沿用 `titles.zh-Hant.json` 魔門字 + `beast.zh-Hant.json` 尊稱 |

## 大洲命名

命名不偏一教：儒、釋、道三組地名輪流使用。

| 教 | 字庫（`places.zh-Hant.json` 的 `continent_names`） | 出處 |
|---|---|---|
| 儒 | 冀洲、兗洲、青洲、徐洲、揚洲、荊洲、豫洲、梁洲、雍洲、神洲、中洲 | 《尚書・禹貢》九州；鄒衍「赤縣神州」 |
| 釋 | 東勝神洲、西牛賀洲、南贍部洲、北俱蘆洲 | 佛教四大部洲 |
| 道 | 祖洲、瀛洲、玄洲、炎洲、長洲、元洲、流洲、生洲、鳳麟洲、聚窟洲；小陸塊另有蓬萊、方丈、岱輿、員嶠 | 《海內十洲記》十洲；三神山與五神山 |

規則：

1. 陸塊依面積由大到小排序。
2. 以種子決定起始的教（儒、釋、道其一），之後依序輪流：第 i 塊使用第 `(起始 + i) mod 3` 教的字庫。
3. 在該教字庫中不放回地抽取一個名字。
4. 面積 ≥ 陸地 5% 者稱「洲」（字庫名已含「洲」者照用）；較小者若屬道教則優先取三神山、五神山之名並稱「島」，否則以字庫名的首字加「島」。
5. 某教字庫用盡時，改用下一教。
6. 釋教四大部洲的方位字只是名字，不要求與實際方位一致。

## 三教混合原則

- 世界層級與地理層級的命名（大洲、世界名、洞天福地、山川）都混合三教意象，不偏一教。
- 勢力命名依其所屬：宗門偏道、寺院屬釋、書院屬儒、王朝國號屬儒家傳統（2.5）。
