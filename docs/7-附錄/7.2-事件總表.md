# 7.2 事件總表

本表列出模擬核心會寫入因果帳的每一種事件，包含重要度、顯示用的一句話模板、印章用字與是否觸發奇觀；新增事件時在此登記。

模擬核心寫入因果帳的所有事件種類。

- **文字**：由介面端依模板產生（不存在模擬中）。`{I}` 為人物的身分與姓名（見「傳聞的合成與標記」）；`{A}`、`{B}` 為人名；`{P}` 為州郡；`{F}`、`{G}` 為勢力；`{X}`、`{N}` 為依事件而定的參數。
- **填字**：模板由 `locale/code/event_text.gd` 填，字串在 `ui.zh-Hant.json` 的 `event_<代號>` 鍵；`{X}` 由代號換成介面用語（死因、境界、宿緣種類、去向、職分、天書條目）；`Tribulation` 的「{結果}」依結果為「結成金丹」（渡過，寫成就的境界）、「未成金丹，舍身兵解」「未成金丹，形神俱滅」（失敗，寫沒成的境界與結局）；`SectSplit` 的 `{F}` 為原門派、`{G}` 為新門派；`Rebirth` 的 `{X}` 為「人氏」；`ThreadResolved` 轉世未滿 2 次時省略「歷經{N}次轉世，」；`ProvinceLost` 有折損時句尾加「，溺斃{N}人」。
- **印**：方形單字印（8.8），每種事件一字，不重複。
- **`Born` 與 `Rebirth`**：`Born` 只用於新魂（3.4 補足、人間補魂、3.10 滋生）與開天；輪迴出生一律用 `Rebirth`。
- **奇觀**：見 5.6；「小」表示小型奇觀。

## 傳聞的合成與標記

傳聞簽（5.7）不把每筆事件各畫一張：例行事件合成統計，異常事件各自成則，每則帶身分與一個原因標記。規則由 `locale/code/event_text.gd` 判定，`hud/code/rumor_slip.gd` 執行。

**身分**（模板的 `{I}`）：`所屬門派 + 職分 + 姓名 +（境界）`，例「鶴微宗長老霍靜沉（元嬰）」。

| 職分 | 稱呼 | 來源 |
|---|---|---|
| 掌門 | 掌門 | 該勢力的 `leader` |
| 宗門成員 | 長老（事件當時境界 ≥ 金丹）、弟子 | 3.5「長老」的簡化：只看境界，不查徒弟數 |
| 無勢力的修士 | 散修 | — |
| 君主 | 君主（無門派、無境界） | 3.7 |
| 其他 | 僧人、儒士、魔修、妖、官員、將軍、宗室 | 身分 |

境界括號只給修士。渡劫與突破寫的是事件當時的境界，即新境界的前一階。橋接逐月推進並記下每筆事件主角當月月底的身分（門派、職分、境界），`drain_events` 取走時帶這份記錄，所以快轉一次推進多個月，顯示的仍是事件當時的樣子；掌門身死而同月繼任者已上位時，以「前任 Died」為因的繼任事件把死者補回掌門。讀檔重播的事件沒有記錄，取現況。空間不足時依序縮短：去門派、去職分、只留姓名，境界與結果不截；仍放不下才截姓名並加「…」。

**年月**：每則右端寫「71年3月」，年為紀元年，月由 `tick` 依 2.6 曆法算（tick 1 為一月，`(tick − 1) mod 12 + 1`）。

**例行與異常**：

| 類別 | 認定 | 處置 |
|---|---|---|
| 例行 | 渡劫成功且新境界 < 化神（金丹、元嬰）；突破且新境界 < 化神；結下宿緣（重要度 ≤ 2）；結為夫妻；境界 < 化神、非掌門非君主的身死，死因為壽終、突破失敗、渡劫身隕、兵解、天譴、戰死、染疫、饑荒、亡於量劫（死於天劫者的境界算他正要晉入的新境界）；劫雲預兆（境界 < 化神）；入道；遊歷 | 同月、同類（身死再按死因分）合成一則統計；該類該月只有一筆時維持單筆樣子 |
| 異常 | 其餘：被殺（有兇手與宿緣脈絡）、新境界或當事人境界 ≥ 化神的身死與渡劫失敗、創派、掌門或君主更替、掌門或君主身死、宿緣了結、世界大事、王朝事件（立國、崩潰、篡位、內戰、割據、封禪）、天災地變 | 各自成則，不合成；身死帶「亡」標記 |

門檻理由：本表重要度在新境界 4（化神）起由 2 升到 3，3.5 的目標分布又使每高一境人數約降為 0.3–0.6 倍，金丹與元嬰是每年成批出現的洗版來源，化神起每月已是稀有事件，值得單獨成則。入道與遊歷的重要度為 1，現行門檻（≥ 2 才進傳聞）下不會抵達傳聞簽，合成規則先備好。

**身死的統計**：低境界身死同月同死因合成一則，例「本月 5 人突破失敗而亡」「本月 3 人壽終」；名單每行是身分、姓名、死因與享年（例「散修霍靜沉（金丹）突破失敗而亡，享年 94」）。渡劫失敗時模擬先寫失敗的 `Tribulation` 再寫 `Died`（死因渡劫或兵解），兩筆是同一件事：低境界者合進身死統計，傳聞簽不另留單列的渡劫；新境界 ≥ 化神的渡劫失敗仍單列，其身死不重複。統計的重要度是成員最高者（身死為 2），因此只進展開清單；掌門、君主、高境界與被殺的身死各自成則（掌門、君主與高境界帶「亡」標記）。

**統計句**：「本月 12 人渡劫：9 人結成金丹，3 人成就元嬰」（依境界高到低列各階人數）；空間不足時縮成「本月渡劫 12：金丹 9、元嬰 3」。突破為「本月 N 人突破：K 人至{境界}」，其餘為「本月 N 對結下宿緣」「本月 N 對結為夫妻」「本月 N 人壽終」「本月 N 處山門劫雲將聚」。統計的重要度取成員最高者，因此渡劫統計（3）收合時也進簽，其餘例行統計只進展開清單。點一則統計攤開名單，每人一行：身分、姓名、境界、結果。突破緊接在渡劫之後的（新境界 ≥ 金丹）是同一件事，傳聞簽只記渡劫。

**收合的排序**：置頂的世界大事先，其次異常（新到舊），最後才是例行統計（新到舊）；展開的清單不分類，依時間新到舊。同一魂同一年的異常事件仍合成一簽，留重要度高者（同級留先到者）；例行事件不併，統計才數得準。

**原因標記**：每則至多一個，依序取第一個成立的。

| 順序 | 標記 | 條件 |
|---|---|---|
| 1 | 大 | 世界大事 |
