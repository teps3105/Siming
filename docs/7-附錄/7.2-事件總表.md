# 7.2 事件總表

本表列出模擬核心會寫入因果帳的每一種事件，包含重要度、顯示用的一句話模板、印章用字與是否觸發奇觀；新增事件時在此登記。

模擬核心寫入因果帳的所有事件種類。

- **文字**：由介面端依模板產生（不存在模擬中）。`{A}`、`{B}` 為人名；`{P}` 為州郡；`{F}`、`{G}` 為勢力；`{X}`、`{N}` 為依事件而定的參數。
- **印**：方形單字印（8.8），每種事件一字，不重複。
- **`Born` 與 `Rebirth`**：`Born` 只用於新魂（3.4 補足、人間補魂、3.10 滋生）與開天；輪迴出生一律用 `Rebirth`。
- **奇觀**：見 5.6；「小」表示小型奇觀。
