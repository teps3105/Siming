# 7.7 M5 司命之權

## 目標

玩家第一次真正「玩」：用天機牽動因果，並承擔天道業障。

## 範圍

- 4.2 全部權能、4.3 天機、4.4 天道業障。權能作為場的寫入者（2.7「司命與場」）：疫病、旱澇（`cap_mod`）、祥瑞經 `field::add`；移山、開脈、斷脈觸發 6.9 重算鏈（只重算受影響的格與州），並重新烘焙 `province_id` 與 `field`。
- 介面：
  - 權能印併入情境印環（5.7；不另設權能列）、目標選擇與範圍預覽（5.2）；天機數以小印掛在題簽右側，停留顯示收入明細（4.3）。
  - 確認框。
  - 天道之秤（M5 只顯示天道業障與天下業氣；量劫預測在 M6 加入）。
  - 輪迴台的引渡。
  - 關注的天機收入（4.7；關注、命牌與自動止已在 M2 U14a）。
- 司命落印奇觀；事件卡的漣漪總數。
- 天書：「一念之差」「逆天改命」（「無為而治」需要運評，移到 M6）。
- 第一次遊玩的節奏提示（4.1）。

## 驗收標準

- [ ] 每種權能可在桌面版與瀏覽器版發動，效果與天道業障符合 4.2。
- [ ] 天機收入在不干預與積極干預兩種劇本下，都落在 4.3 平衡目標內。
- [ ] 指令重播測試：每種權能各一次，雜湊相同。
- [ ] 試玩：3 位以上未接觸過專案的玩家，15 分鐘內能自行完成一次牽線並理解其結果（記錄於 7.9）。
