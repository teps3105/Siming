# 7.8 M6 量劫

## 目標

完整的「一運」體驗：累積、劫兆、量劫、結算、天書、分享。

## 範圍

- 3.11 量劫；4.5 天書（全部條目，含「無為而治」）；4.6 開局設定畫面；4.8 存檔與分享。
- 天道之秤加入量劫預測；劫煞衍生場 `kalpa_local`（2.7）：劫兆期在業氣模式疊加、劫兆天色依其強度；量劫的天災、損脈、業氣 ×0.3 經 6.9 的 `add` 與重算鏈。
- 全部平衡目標以「有量劫版本」重驗。
- 地圖：劫兆天色、量劫奇觀。
- 介面：結算畫面、天書冊頁、存檔欄位、分享碼匯入與匯出、觀看重播模式。

## 驗收標準

- [ ] 3 個種子各 3 運：量劫強度分布合理（各成數皆有出現）；評價分布不全為「平」。
- [ ] 分享碼：
  - 在另一台機器（或瀏覽器版）匯入後雜湊相同。
  - 觀看重播模式在每個司命事件處暫停。
- [ ] 天書條目可跨存檔累積；每條附帶的重播可播放。
- [ ] 完整遊玩 1 運（1× 速度約 36 分鐘）無崩潰、無明顯卡頓。
