# 7.11 M7 Steam Demo

## 目標

把 M1–M6 的成果包裝成可在 Steam 上架的 Demo（10.1）。

## 範圍

- 10.1 Demo 專屬功能：
  - 主選單、設定（含 4.7 自動暫停勾選）、新手引導（5.7 引導簽：依 4.1 節拍、做過即不再出現）、Demo 結束畫面、回饋連結、當機紀錄。
  - Demo 限制：中尺寸、中古、兩運。
- 10.2 Steamworks 整合：Overlay、願望清單、Cloud、Rich Presence、語言偵測。
- 10.3 攝影模式；商店頁素材與預告片。
- 10.4 Windows 建置、畫質設定、效能驗證。
- 10.5 簡體中文。
- 10.6 發行檢查清單（含 Steam Deck 驗證）。

## 前置條件

- M1–M6 完成。
- （擁有者）Demo App ID 已取得。在取得之前，以 Steam 的測試 App ID 480 開發與驗證。
- 產品名定案（1.7）。

## 驗收標準

- [ ] 10.6 發行檢查清單中，非「擁有者」項目全部勾選。
- [ ] 3 位以上未接觸過專案的玩家完整玩完 Demo：
  - 至少 2 位能說出「因果線是什麼」。
  - 記錄平均遊玩時間與是否點擊願望清單按鈕。
- [ ] Windows 最低配備：1080p 30 fps 以上（10.4）。
- [ ] Steam Deck：完整玩完 Demo 只用搖桿；800p 30 fps 以上；10.6「Steam Deck 驗證」全部勾選。

於 SDD 步驟②填寫（7.10）。
