# 7.4 M2 魂與道

## 目標

第一次看見因果：魂在輪迴中糾纏，修士在靈脈上修煉、渡劫、飛升。天書「三世血仇」能自然發生。

## 範圍

- 3.1 魂、3.2 六道輪迴、3.3 宿緣與因果帳、3.4 有名之人、3.5 道（含遊歷、斬妖除魔中與魔修相關的部分）。
- 僧與儒士在 M2 只有身分與壽元，不累積果位與三不朽（M3、M4 實作）。
- 魔修以「入魔後離開宗門的散修」簡化呈現；完整魔門在 M4。魔修不列入驗收，以單元測試強制入魔路徑驗證規則。
- 開天（4.6）中的宗門與修士部分。M2 的開天不建立王朝、寺院、書院（M3、M4 加入）；開局時代在 M2 只影響靈氣倍率、人口係數、宗門數、初始有名之人數。
- 畜生道暫行：畜生道且 W ≥ 30 的魂，一律「為獸」10–30 年；M4 加入妖後改回 3.2 原規則。天道在 M2 是不易觸發的分支，不列入驗收。
- 恩義線只來自開局宿緣；「救命、傳功」在 M2 不建立恩義線，其他來源在 M3–M5 加入。
- 教化：M2 只更新「道」的教化目標；釋、儒在 M3、M4 接上（2.3）。
- 指令與介面：`Command::Follow` 在 M2 實作（不影響天機，天機在 M5）；自動暫停使用 4.7 的預設值（設定頁在 M7）。
- 地圖：
  - 山門模型、劍光（5.5）。
  - 因果模式（5.4）：點擊魂光選取修士。
  - 三教模式先只顯示道（宗門勢力範圍虛線圈）；釋、儒在 M4 補上（5.4、7.6）。
  - 天劫、飛升、宿緣了結三個奇觀（5.6）。
- 介面：
  - 人物／魂卡、事件卡（溯因與漣漪）（5.8）。
  - 宗門勢力卡；州郡卡的「此地有名之人（前 10 名）」一列（原屬 M3 完整州郡卡，提前到 M2）。
  - 傳聞簽、命牌、原因簽與自動止／緩、情境印環（4.7、5.7；7.9 #36）。
  - 輪迴台（唯讀）。
- 天書偵測框架，加上五條：「三世血仇」「冤冤相報」「前世今生」「轉世大能」「再續前緣」；「首次達成給天機」在 M2 為空操作。
- 場域框架骨架（2.7、6.9；7.9 #33）：`FieldId`、`FieldSpec` 表、`field::{get, get_cell, add, gather, scatter}`、運算子 `decay`／`diffuse`／`drift`／`relax`／`clamp` 與單元測試；既有寫入（饑荒業氣）改經 `add`。**不改變任何行為**：季步（6.3 步驟 6）與年步衰減仍在 M4 接上；`downstream` 在 M4 加入。渲染端把 `field` 貼圖烘焙一般化為「依 `FieldId` 烘焙」並加墨分五色色階（靈脈模式沿用、因果模式加緣場底色）。

## 需在 M2 決定

- 年度系統分攤：已決定 M2 不分攤（7.9 #22）；驗收時量測年底月耗時，超標才改為只分攤步驟 10–12（6.8）。
- 3.5 境界數值的校準（`REALM_EXP`、`REALM_BT`、`REALM_LIFESPAN`），結果回寫 8.1。

## 驗收標準

- [ ] `siming-cli sim` 3 個種子各 3 運（無量劫版本）：
  - 在世有名之人落在 8.1 平衡目標內。
  - 首次飛升 ≤ 2 運；第 2、3 運每運飛升 1–3。若校準後做不到，依規格變更流程（7.10）修改目標並記入 7.9。
  - 修士境界分布每高一境約 ×0.3–0.6。指標定義：某一時刻在世的修士、散修、魔修依境界的人數；以第 2、3 運各 4 個取樣點的平均計。
  - 開局時代為中古。
  - 每運宿緣了結 30–120 條。
  - 至少一個種子觸發「三世血仇」。
- [ ] 確定性與存檔測試通過。
- [ ] 桌面版：
  - 點擊任一修士可看到前世今生與宿緣。
  - 因果模式可見線、魂光與了結奇觀。
  - 天劫與飛升奇觀可見。
- [ ] 效能符合 6.8。
- [ ] 場域骨架（U18、U19）：`gdd_6_9_*` 測試通過；接入骨架前後 3 個種子 × 1 運的世界雜湊相同（不改行為）；靈脈模式截圖為五階墨色。
