# 7.3 M1 山河

## 目標

看到一片會呼吸的山河：程序生成的大陸，以 2.5D 水墨地圖呈現，可以操作、可以切換地圖模式，時間會走。原生與瀏覽器都能跑。

## 範圍

| 包含 | 不包含 |
|---|---|
| 世界生成（2.2）、州郡與初始人口（2.3）、靈脈與靈氣（2.4） | 魂、有名之人、勢力（M2 起） |
| 曆法與時間控制（2.6）；每年人口成長 | 業氣、功德、正氣的來源（M3、M4） |
| 地形渲染、水墨著色器、古地圖化（5.3） | 建築模型、軍隊、奇觀（M2 起） |
| 地圖模式：山河、靈脈、天下（M1 以「州郡著色」示意，見下） | 三教、因果、業氣模式（M2、M4） |
| 鏡頭與操作（5.2）、州郡選取與州郡卡（簡版） | 權能列、傳聞欄、輪迴台、天書 |
| 頂欄（日期、時間控制）、底欄（地圖模式、圖例） | — |
| 字型子集化、egui 主題（5.7、9.x） | — |
| siming-cli `gen`、`sim`（只有人口） | — |
| WASM 建置 | — |

M1 的「天下」模式：尚無王朝，以每個州郡各自的淡彩呈現州郡劃分，驗證查表著色與國界描邊。

## 工作項目

1. **workspace 重整**：
   - 建立 `crates/sim`、`crates/app`、`crates/cli`。
   - 移除 v1 的 `crates/engine`，命名字庫移入 `crates/sim/data`。
2. **sim**：
   - `params.rs`：8.1 中 M1 所需的參數。
   - `worldgen`：雜訊、高度、氣候、地形、填窪與河流、州郡、靈脈、命名、品質檢查。
   - `calendar`：元會運世換算與顯示字串。
   - `Sim`：`new`、`step`（每年人口）、`world`、`hash`。
3. **cli**：`gen`（PNG 匯出各圖層）、`sim`。
4. **app**：
   - Bevy 骨架。
   - 地形網格與 LOD。
   - 地圖材質：WGSL，5.3 的步驟 1–8。
   - 貼圖與查表。
   - 鏡頭。
   - 州郡選取。
   - egui 主題與頂欄、底欄、州郡卡。
   - 時間控制。
   - 文字標籤：州郡、江河、山脈、洞天。
5. **素材**：字型子集化腳本與子集字型；程序紙紋與筆觸貼圖（9.3）。
6. **WASM**：`tools/build_web.sh`、`index.html`。
7. **測試**：worldgen 品質檢查（10 個種子）、確定性、`calendar` 單元測試。

## 驗收標準

- [ ] `siming-cli gen` 對 10 個種子都產出通過 2.2 品質檢查的星球；附 3 張 PNG。
- [ ] 同種子兩次生成的世界雜湊相同；`sim` 跑 1 運雜湊相同。
- [ ] 中尺寸世界生成 ≤ 1.5 秒（release）。
- [ ] 桌面版：
  - 開啟即見地圖。
  - 平移、縮放、旋轉流暢，60 fps。
  - 拉遠時呈現古地圖；再拉遠轉為可旋轉的星球；平面地圖東西無縫。
  - 山河、靈脈、天下三模式可切換，有圖例。
  - 州郡滑鼠停留顯示名稱，點擊開州郡卡（名稱、地形組成、人口、靈氣）。
  - 時間控制可暫停、切換速度；日期以元會運世顯示；人口隨年變化。
- [ ] 瀏覽器版：在 Chromium 中開啟同一張地圖；附截圖。
- [ ] 所有文字以霞鶩文楷顯示，無缺字方塊。
- [ ] 搖桿：可平移、縮放、旋轉、切換地圖模式、調整速度、以準星選取州郡並開啟州郡卡；1280×800 Deck 版面截圖無裁切（5.9）。
