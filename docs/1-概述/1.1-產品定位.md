# 1.1 產品定位

《司業命緣》是一款宏觀模擬 Roguelite：玩家扮演司命星君，俯瞰一個自行運轉的修仙世界，只能以牽線、點化等權能介入；一局一局重來的不是玩家，是世界裡的每一個魂。本節列出產品名、類型、平台與一句話賣點，是整份 GDD 的起點。

> 你是司命——執掌因果與輪迴的星君。
> 你不能操控任何人，只能牽線、點化、移山、引渡亡魂。
> 你種下的每一個因，都會在某一世結果——包括你自己的。

| 項目 | 內容 |
|---|---|
| 產品名 | 中文 **《司業命緣》**；英文 ***Siming: Karma & Fate***（2026-10-08 中英定案，見 [1.7](1.7-命名候選.md)）。專案代號 Siming（2026-10-10 起；舊代號 CF-LiGend 已封存，見 6.10 #38） |
| 類型 | 宏觀模擬 Roguelite：世界自動推進，Roguelite 的對象是世界裡的人物（見下「一世一局」） |
| 呈現 | 2.5D 水墨戰略地圖（CK3／三國志／信長之野望的地圖語言） |
| 平台 | Godot 4.7 加 Rust 模擬核心（6.1）：**Windows 桌機（鍵鼠）與 Steam Deck（搖桿）為主**，兩者分別優化（5.9）；不做瀏覽器版（9.4） |
| 發行目標 | Steam Demo（第 10 章、M7） |
| 單局長度 | 無盡沙盒；以「運」（360 年；1× 約 36 分鐘，可加速）為一個節奏單位 |
| 玩家角色 | 司命：不操控人，只牽動因果 |

## 司業命緣

整個作品圍繞這四個字。四字為「動、名、動、名」兩組動賓結構：

- **司業**：司掌業力。
- **命緣**：命定緣分。

每個系統、每個畫面，都要能說出它屬於哪一個字。

| 字 | 詞性 | 意義 | 在遊戲中 | 主要章節 |
|---|---|---|---|---|
| **司** | 動 | 司掌 | 玩家是司命，司掌天下業力與緣分；以權能牽動世界，但不操控任何人；權能必有代價 | 4.2、4.3 |
| **業** | 名 | 業力 | 功德與業障、州郡業氣、天劫凶險、天道業障、量劫清算 | 3.1、2.4、3.5、4.4、3.11 |
| **命** | 動 | 命定 | 依業力命定魂的六道去處、壽元與境界；王朝的天命；司命以牽線、賜福、降罰、引渡命定眾生之緣 | 3.2、3.4、3.7、4.2 |
| **緣** | 名 | 宿緣 | 魂與魂之間跨越轉世的因果線：相遇、了結、冤冤相報、再續前緣 | 3.3 |

## 這是什麼

世界是一整顆星球，有數個大洲與無數島嶼；它自己運轉：王朝興替、宗門爭鋒、寺院傳法、妖魔作亂、修士渡劫飛升。

與所有同類產品的根本差異：**模擬的基本單位不是「人」，而是「魂」。**
- 一個魂會轉世很多次。他這一世欠下的血債，會在下一世、下下世找上門。
- 他前世的師父，可能是今生的仇人。

玩家看到的不是一群隨機 NPC 的生滅，而是**跨越輪迴的因果糾纏**，並且能親手去牽動它。

## 一世一局

Roguelite 的四件事——每局條件不同、局內成長、死了重來、帶著累積再開——在本作發生在世界裡的每一個魂身上，同時有幾千局在地圖上進行：

| Roguelite | 在本作 |
|---|---|
| 一局 | 一個魂的一世：從出生到身死 |
| 開局條件 | 這一世的出身、資質與所在的州郡、勢力 |
| 局內成長 | 入道、拜師、突破、渡劫，以及這一世結下的恩怨 |
| 一局結束 | 身死；依功德與業障判入六道（3.2） |
| 跨局累積 | 魂帶進下一世的功德、業障、宿慧、道緣與宿緣（3.1、3.3） |
| 通關 | 超脫：飛升、涅槃、成聖，魂永久離開輪迴 |

玩家不下場打這幾千局，而是看著它們、挑幾局牽一條線。每一世在畫面上要看得出是「第幾世、帶著什麼來、這一世走到哪裡、留下什麼給下一世」。

一句話：**WorldBox 的「看世界自己長」＋ CK3 的「人物與王朝的故事」＋ 只有東方題材才有的「因果輪迴」。**

## 與同類產品的差異

| 對照 | 它們 | 本作 |
|---|---|---|
| WorldBox | 上帝玩具，破壞免費 | 破壞有業，會在輪迴中回來 |
| CK3 | 以家族血脈延續故事 | 以魂的輪迴延續故事，跨越家族與勢力 |
| 鬼谷八荒、了不起的修仙模擬器 | 扮演修士或經營宗門 | 不操控任何人，只牽動因果；修仙只是三條解脫之道之一 |
| 文字修仙模擬器 | 以文字敘述呈現 | 以地圖奇觀呈現；文字只在卡片中出現一句話 |
