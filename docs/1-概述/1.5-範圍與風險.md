# 1.5 範圍與風險

## 刻意不做（1.0 之前）

| 不做 | 原因 |
|---|---|
| 玩家扮演單一角色、經營宗門或國家 | 那是另一種遊戲，與「司命不操控人」衝突 |
| 戰術戰鬥畫面 | 戰爭在戰略地圖上以兵力推移呈現 |
| 功法、法寶、丹藥等物品系統 | 看不見、與魂無關（違反規則 1、2） |
| 連線、帳號、雲端存檔 | 分享以存檔碼完成即可 |
| LLM 生成敘事 | 文字只有一句話卡片，模板即可 |
| 音效與配樂 | M6 之後再評估 |
| 英文與其他語言 | Demo 只做繁中與簡中（10.5）；英文依 Demo 反應決定 |

## 風險

| 風險 | 機率 | 影響 | 對策 |
|---|---|---|---|
| 因果太抽象，玩家看不懂 | 中 | 高 | 因果模式是第一級公民；每條線點開就是一排轉世頭像加一句話；M2 先做出「三世血仇」一條完整體驗再擴充 |
| 系統太多做不完 | 高 | 高 | 依里程碑逐層疊加：先山河，再道與輪迴，再儒，再釋與魔；每個里程碑都是可展示的版本 |
| 湧現故事太少或太亂 | 中 | 高 | `siming-cli` 統計宿緣了結數、天書觸發數；平衡目標寫在 8.1 |
| 美術資源不足 | 中 | 中 | 全程序生成：地形網格、水墨著色器、低多邊形建築 |
| 確定性在 WASM 下破功 | 低 | 高 | 模擬單執行緒、固定順序浮點；原生與 wasm32 雜湊比對測試 |
| WASM 體積過大 | 中 | 中 | 字型子集化、裁剪 Bevy 功能、wasm-opt |
| 產品名撞名或商標衝突 | 中 | 高 | 1.7 定案流程；M7 商店素材前定案 |
| Steam 審核或新品節時程受阻 | 中 | 中 | 10.6 檢查清單；擁有者事項提早處理 |
