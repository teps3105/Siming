# 1.2 目標玩家與體驗

## 目標玩家

| 族群 | 他們喜歡 | 他們在本作找到 |
|---|---|---|
| 沙盒觀察者 | WorldBox、Dwarf Fortress、RimWorld | 一個會自己長出故事的世界 |
| 大戰略玩家 | CK3、三國志、信長之野望 | 疆域推移、王朝興替、人物恩怨 |
| 修仙與前世今生題材讀者 | 網文、仙俠劇 | 可以親眼看見的因果輪迴 |

## 玩家想看到什麼

依時間尺度分三層：

| 時間尺度 | 玩家想要 | 我們給的 |
|---|---|---|
| 秒 | 世界是活的、好看的 | 大軍行進、劍光掠過山脈、劫雲聚在山頂、飛升光柱貫天、屠城之地升起黑紅業氣、寺院四周泛著金光 |
| 分鐘 | 有人可以追、有懸念 | 點一個魂，看他身上的因果線連向誰；系統預告「赤線漸近」，讓人想守著看結局 |
| 小時 | 我的選擇改變了世界 | 你三百年前牽的一條線，讓兩個王朝世代為仇；你一次沒忍住的天罰，讓整片大陸墮入魔劫 |

## 體驗目標（可量測）

| 目標 | 指標 | 初值 |
|---|---|---|
| 一開局就好看 | 首次開局到看見第一個地圖奇觀的時間 | ≤ 60 秒（1× 速度） |
| 因果看得懂 | 新玩家在 15 分鐘內打開過一次因果模式並點開一條因果線 | ≥ 80% |
| 想再看一運 | 撐過第一次量劫後選擇繼續的比例 | ≥ 60% |
| 干預有回報 | 玩家牽的線在牽線後 90 年內了結的比例 | 40–60% |

## 我們不給的

- 大段文字流水帳（v1「仙史」的錯誤）。
- 一定要玩家操作才會前進的流程。
- 沒有代價的破壞。
