# 1.3 設計支柱

所有設計決策用以下支柱檢驗。前四條即產品名「司業命緣」（1.1）：司、命是司命的作為（動），業、緣是世界的實相（名）。彼此衝突時，依編號優先。

1. **司（司掌）——力量必有代價。** 司命不操控任何人，只能牽動因果；每一個干預都寫進天道的帳本，不公的干預會回來反噬世界。破壞不是免費的玩具。
2. **業（業力）——因果可見，業必有報。** 業不是隱藏數值，而是地圖上看得見的線、氣、光；善惡終會在天劫、六道、量劫中清算。
3. **命（命定）——魂是主角，肉身是過客；一世是一局。** 每個魂的一世是一局 Roguelite：開局條件各不相同，身死結束，帶著累積再入輪迴，超脫是通關（1.1）。業力命定魂的六道去處與壽元；司命可以命定緣分、改寫去處，但必有代價（支柱 1）。所有長線故事都掛在魂上，透過輪迴延續。
4. **緣（宿緣）——宿緣是故事的引擎。** 魂與魂之間的線，讓冤家路窄、恩怨跨世；新系統若不能產生或了結宿緣，先問它為什麼存在。
5. **三教是三種解脫之道，不是三種皮膚。** 道求長生飛升、釋求寂滅涅槃、儒求立德成聖；各有不同機制、不同的地圖存在方式，彼此衝突。
6. **世界自己會走。** 不干預也能看；干預是為了看到「本來不會發生的故事」。
