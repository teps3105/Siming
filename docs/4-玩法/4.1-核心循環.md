# 4.1 核心循環

```
        ┌──────────────┐
        │  觀：世界自轉  │◀──────────────────────┐
        └──────┬───────┘                       │
   奇觀、傳聞、預兆吸引注意                         │
        ┌──────▼───────┐                       │
        │  牽：司命之權  │  花費天機，記下天道業障   │
        └──────┬───────┘                       │
        數年到數世後                              │
        ┌──────▼───────┐                       │
        │  果：宿緣了結  │  回饋天機、奇觀、天書     │
        └──────┬───────┘                       │
        每運之末                                 │
        ┌──────▼───────┐                       │
        │  劫：量劫清算  │──── 結算後進入下一運 ────┘
        └──────────────┘
```

| 迴圈 | 時間 | 玩家在做什麼 | 回饋 |
|---|---|---|---|
| 微 | 秒～分 | 看地圖、點人物卡、追一條線 | 奇觀、前世今生 |
| 中 | 分～十分 | 牽線、點化、賜福、引渡 | 宿緣了結、天機 |
| 大 | 一運（1× 約 36 分；可加速） | 管理天道之秤、為量劫做準備 | 結算評價、天書條目 |
| 元 | 跨存檔 | 收集天書 | 解鎖條目、分享重播 |

**觀看本身就是玩法**：你牽的線越多、越有趣，了結時回饋越多（4.3）。
