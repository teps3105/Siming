# 4.7 傳聞與預兆

傳聞簽是世界主動告訴玩家「發生了什麼」的管道，預兆則提前透露即將發生的大事。本節定義哪些事件會通知、關注特定魂的方式、預兆的種類，以及哪些情況會自動暫停。

地圖之外唯一的資訊流，以圖示為主。

## 傳聞簽

- 位置：畫面右上，最多顯示 8 則；新到舊；可展開看最近 50 則（器物形式與版面見 5.7）。
- 每則：事件印（7.2「印」欄）+ 一句話（7.2 模板）+ 年份。點擊即飛到地點並開啟相關卡片；停留時浮出「飛」「溯」兩印。
- 入簽條件與分級（止／緩／簽／記）見 5.7「通知優先序」：importance ≥ 3，或牽涉玩家「關注」的魂（importance ≥ 2）。預跑期間的事件不入簽。
- 同一魂同一年的多筆事件合併為一簽。

## 關注

- 玩家可以在任何人物卡上按「關注」；關注的對象是魂，跨越轉世。勢力卡上的關注只影響傳聞，不影響模擬。
- 被關注者的所有事件（importance ≥ 2）都會入傳聞簽（左緣朱記），並在地圖上加上標記；被關注者列在左緣的命牌（5.7），牌上顯示今生狀態與提醒點，跨越轉世。
- 關注魂會影響天機收入（4.3），因此「關注／取消關注魂」是指令（6.2 `Command::Follow`），會寫入指令紀錄。
- 同時最多關注 12 個魂。
- M2 實作 `Command::Follow` 與關注集合（`World.follows`，6.2）；關注不影響天機，天機收入在 M5 接上（見路線圖）。

## 預兆

| 預兆 | 條件 | 表現 |
|---|---|---|
| 赤線漸近 | 3.3 預兆條件 | 傳聞 + 因果模式中該線閃爍 |
| 劫雲將聚 | 修士修為已滿、突破冷卻將結束，境界 ≥ 元嬰；在 6.3 步驟 11 末尾判定，寫入 `TribulationOmen` 事件 | 山門上方淡淡雲氣 |
| 天命將盡 | 王朝天命 < 25 | 都城旗幟褪色 |
| 量劫將至 | 進入劫兆 | 頂欄量劫預測、天色變化（3.11） |

## 自動暫停（設定頁可勾選）

設定頁在 M7 之前不實作，M7 之前一律使用下表預設值。暫停時天時儀轉「止」並掛原因簽（5.7）：〔Enter／A 飛往〕〔Space／☰ 續行〕；兩端在地圖上以朱環標 2 秒。另有「緩」一級（importance 5 的世界事件而不牽涉關注者）：只降到 1× 不暫停。同一年只自動止一次。

| 事件 | 預設 |
|---|---|
| 宿緣了結（司命所牽） | 開 |
| 赤線漸近（司命所牽或關注） | 開 |
| 超脫 | 開 |
| 改朝換代 | 關 |
| 量劫開始、結算 | 開（結算一律暫停） |
| 被關注者死亡 | 開 |
