# 4.4 天道業障

天道業障是玩家濫用權能所累積的全域代價，數值越高量劫越強。本節定義它的來源、門檻效果與消減方式。

整個系統的良心：力量有代價。

- **天道業障**是一個全域數值 ≥ 0，記在 0 號魂「天道」上，介面顯示為「天道之秤」。
- **來源**：各權能的業的代價（4.2）。
- **效果**：
  - 量劫強度 + 天道業障 / 200（3.11）。
  - 天道業障 ≥ 100 時「天怒人怨」：所有州郡濁氣門檻 −0.1；魔勢計算時分子 × 1.2（3.10）。由下而上跨過 100 時，寫入「天怒人怨」事件。
  - 對天道的怨線有兩個來源：
    - 天雷擊殺淨業力 ≥ 0 的人：死者的魂建立一條。
    - 疫病：每 2 萬死者產生一個怨靈，各帶一條。
  - 這些線無法了結，只會在量劫的劫後清算中消散（3.11）。
  - 帶有對天道怨線的魂轉世時，判入阿修羅道（3.3）。
- **減少**：
  - 量劫後 × 0.5。
  - 每次有魂超脫 −2。
- **地圖表現**：
  - 天道之秤是頂欄的一座天秤圖示。左盤是天下功德與正氣，右盤是天下業氣加上天道業障，傾斜程度即量劫預測。
  - 天道業障 ≥ 100 時，地圖邊緣出現暗紅雲紋。

## 設計意圖

你可以像 WorldBox 一樣一手毀掉一座城。但：
- 血債記在天道帳上，下一次量劫因此加劇。
- 死者的魂帶著怨念回到人間，其中一些成為魔頭。

**破壞的樂趣保留，而且會變成新的故事。**
