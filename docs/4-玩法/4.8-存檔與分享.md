# 4.8 存檔與分享

一局遊戲可以存檔、讀檔，也可以匯出成一段分享碼讓別人重現同一個世界。本節定義存檔的數量與位置、分享碼的內容與限制。

## 存檔

- **自動存檔**：每世一次，保留最近 5 個。
- **手動存檔**：10 個欄位。
- **格式與載入**：見 [6.5 確定性與存檔](../6-開發/6.5-確定性與存檔.md)。
- **存放位置**：
  - Godot 的使用者資料夾 `user://saves/`（Windows 為 `%APPDATA%\Godot\app_userdata\司業命緣\saves\`，可在專案設定改為自訂資料夾名）。

## 分享碼

- 內容：版本、種子、開局設定、指令紀錄、目標 tick。
- 編碼：bincode 序列化 → deflate 壓縮 → base64url。前綴 `SMG1-`。
- 長度：一般遊玩一運約 0.5–2 KB。
- 匯入：輸入分享碼 → 重建世界 → 快轉到目標 tick。快轉時顯示進度條，不渲染。
- **觀看重播模式**：從開天開始以 20× 播放，並在每個司命事件處暫停，讓觀看者看見「司命做了什麼」。
- 天書條目內建分享碼（4.5）。

## 版本相容

- 模擬規則變更會改變重播結果，因此分享碼帶有模擬版本號。
- 版本不符時提示「此天機出自不同的天道」，仍允許以舊版本號載入（若程式內仍保留該版本規則則可重播，否則拒絕）。
- 1.0 之前不保證跨版本相容。
