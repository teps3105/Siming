# 4.3 天機

司命的資源。收入刻意綁在「司命在意的因果」上，讓觀看與牽線成為玩法，而不是被動累積。

## 收入

| 來源 | 天機 |
|---|---|
| 開天 | 10（初始） |
| 每世（30 年）基本收入 | +2 |
| **司命所牽**的線了結 | `2 × (1 + lives + 強度 / 50)`，取整 |
| **關注對象**（4.7）的線了結 | `1 + lives + 強度 / 50`，取整 |
| 其他宿緣了結 | 0 |
| 超脫 | +1；超脫者是關注對象或曾被司命牽線者時 +3 |
| 本世界首次達成某天書條目（4.5） | +5 |

- 上限 99。
- 頂欄顯示天機數；滑鼠停留時顯示本世的收入明細。
- 一條線若同時符合「司命所牽」與「關注對象」，只以司命所牽計。

## 平衡目標

| 遊玩方式 | 每運天機 |
|---|---|
| 不干預、不關注 | 25–40（基本收入 24 + 少量超脫與天書） |
| 積極牽線與關注 | 60–100 |

大致相當於每 10–30 年可發動一次中等權能。
